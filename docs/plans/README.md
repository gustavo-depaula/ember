# Plans

Designs for things that are not built yet, parked here untouched. Read one only when you are about to work on that feature.

They were written under an older docs-first workflow. Ignore any instruction in them to write a spec first, update `docs/journal.md`, or keep a doc in sync — those files are gone (see git history if you need one). Status lines inside these docs are unreliable; check the code.

When a plan ships, delete it rather than updating it.

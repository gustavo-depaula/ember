# Capítulo XI. Continuação da consideração de Deus

Talvez te enfades se continuamos ainda a perguntar o que é Deus, quer porque já tantas vezes se perguntou, quer porque desconfias de que se venha a encontrar. Digo-te, Pai Eugênio: só Deus é aquele que nunca pode ser buscado em vão, nem mesmo quando não pode ser encontrado. Ensine-te isto a tua experiência; ou, se não, crê no experiente, não em mim, mas no santo que diz: *Bom sois, Senhor, para os que esperam em vós, para a alma que vos busca* (Lamentações 3:25). Que é, pois, Deus? Quanto ao universo, o fim; quanto à eleição, a salvação; quanto a si, ele o sabe. Que é Deus? Vontade onipotente, virtude benevolentíssima, luz eterna, razão imutável, suma bem-aventurança, que cria as mentes para participarem dele, vivifica-as para sentirem, afeta-as para desejarem, dilata-as para receberem, justifica-as para merecerem, acende-as para o zelo, fecunda-as para o fruto, dirige-as para a equidade, forma-as para a benevolência, modera-as para a sabedoria, robustece-as para a virtude, visita-as para a consolação, ilumina-as para o conhecimento, perpetua-as para a imortalidade, enche-as para a felicidade, rodeia-as para a segurança.

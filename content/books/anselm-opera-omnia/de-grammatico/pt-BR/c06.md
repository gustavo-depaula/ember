# Capítulo VI. Examina-se o outro sofisma à luz do que foi dito

DISC. Entendo o que dizes.

MESTRE. Se entendes bem o que disse, dize como resolverias este silogismo, se alguém o formulasse assim: *Todo gramático é dito quanto ao que é qual; nenhum homem é dito quanto ao que é qual; portanto, nenhum homem é gramático*.

DISC. Isso me parece equivalente a dizer: *Todo racional é dito quanto ao que é qual; mas nenhum homem é dito quanto ao que é qual; portanto, nenhum homem é racional*. Nenhuma prova, porém, pode tornar verdadeiro que racional não se predique de homem algum. De modo semelhante, aquele silogismo que acabas de apresentar não conclui necessariamente que gramático não se predica de homem. Com efeito, suas proposições, se as entendemos segundo a verdade, significam o mesmo que se se dissesse assim: *Todo gramático é dito gramático quanto ao que é qual; nenhum homem é dito homem quanto ao que é qual*. Dessas duas proposições, porém, de modo algum se segue: *Nenhum gramático se predica de homem*, pois não é o mesmo termo que se afirma de gramático e se nega de homem. Haveria nelas, porém, um termo comum, e imporiam uma conclusão necessária, se, mantendo-se a premissa maior tal como foi enunciada, a menor se tornasse verdadeira assim: *Nenhum homem é dito gramático quanto ao que é qual*; ou se, mantendo-se a menor, a maior fosse verdadeiramente proposta assim: *Todo gramático é dito homem quanto ao que é qual*. Pois de cada uma dessas combinações resultaria que gramático não se predicaria de homem algum. Mas, se alguém quiser entender o que se diz, *homem não é gramático*, como se se dissesse *homem não é o mesmo que gramático* — assim como, se eu disser que fulgor é esplendor ou que fulgor não é esplendor, quero dizer que fulgor é a mesma coisa ou não é a mesma coisa que esplendor —, se alguém, digo, entender assim o que se diz, homem não é gramático, segundo esse sentido se segue daquelas proposições, se sua força for bem considerada, que nenhum homem é gramático. Pois, para provar que a essência do homem não é a essência do gramático, a significação delas tem um termo comum.

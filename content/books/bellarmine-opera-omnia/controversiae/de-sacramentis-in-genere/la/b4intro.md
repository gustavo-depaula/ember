# Praefatio

Tres sunt hujus Controversiae partes. Prima: An sacramenta novae legis sint verae causae justificationis ex opere operato. Secunda: An id sit proprium Sacramentis novae legis, an vero commune cum Sacramentis legis veteris. Ter lia: An Sacramenta novae legis imprimant animae characterem.

Prima qua*stio in quatuor capita dividetur. Primum explicabitur status quaestionis. Secundo adferentur sententiae haereticorum. Tertio confirmabitur veritas. Quarto solventur objectiones.

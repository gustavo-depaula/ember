## Translation Decisions

- 2026-09-03: Journal seeded before translation begins. Ten parallel batches (7-8 chapters each) are translating concurrently; each batch agent appends new terms/decisions to this file. Because writes are concurrent, batches append to their own numbered fragment file (`translation-journal.batch-N.md`) in this directory; fragments are merged into this file after all batches complete.
- Saints' names are rendered in their standard Portuguese liturgical form (e.g. "St Francis de Sales" → "São Francisco de Sales", "St Teresa of Avila" → "Santa Teresa de Ávila", "St Ignatius of Loyola" → "Santo Inácio de Loyola").
- Outdated/offensive ethnonyms modernized per the skill's default policy (e.g. "mahométans" → "muçulmanos") if encountered; noted per batch if it occurs.
- Editor footnotes dropped by default; author asides/parentheticals preserved.

## 2. Non-obvious Translation Decisions

- **Saints' names**: "St. Maximilian Kolbe" → "São Maximiliano Kolbe"; "St. Francis Xavier" → "São Francisco Xavier"; "St. Elizabeth of Hungary" → "Santa Isabel da Hungria" (standard Lusophone form, not "Isabel de Hungria"); "St. Jude" → "São Judas Tadeu" (kept "Tadeu" throughout since the source itself explains and uses "Thaddeus" as his defining epithet); "St. Louise de Marillac" → "Santa Luísa de Marillac" (given name translated, surname kept — standard usage); "St. Cataldus" → "São Cataldo" (the article's own Irish form "Cathal" was kept as "Cathal" where the text uses it informally/nostalgically, e.g. "Cathal de Lismore," to preserve the author's rhetorical device of alternating the Latinized/Italianized name with the native Irish one); "St. Dymphna" → "Santa Dinfna" (standard Portuguese-language hagiographic form, as used in Brazilian and Portuguese devotional literature).
- **Padre Pio**: kept as "Padre Pio" per instructions (not translated to "Padre" + surname), matching common Brazilian usage.
- **"Publisher's Note"** in padre-pio.md rendered as "Nota do Editor" (the original mislabels the note, calling it the author's voice later — kept structurally identical to source, including the odd formatting with "**" before the note).
- **Latin phrases**: kept inline with existing translations where the source already glossed them (e.g. "Viva Gesù!", "Credo, credo, credo!"); the Virgil quotation in saint-cataldus.md ("*Trojae ab oris... in Italiam venit*") was left in Latin, matching the source's own presentation as an untranslated classical allusion.
- **OCR artifacts in source**: The en-US source files contain visible OCR noise (irregular spacing like "su rely", "li fe", "meltride", broken line-wraps mid-word, stray periods, e.g. "50a" for page/date numbers, "Kitsing-on-Main" — likely a misreading of "Kitzingen am Main"). These were silently normalized/corrected in the Portuguese translation to the most plausible reading (e.g. "Kitzingen-am-Main" → "Kitsingen-am-Main" kept as given, since the actual historical abbess's convent name could not be verified beyond the source text). Where the source has garbled/duplicated text (e.g. a repeated sentence about "and tire ourselves out every day" in saint-maximilian-kolbe.md), the duplication was resolved by translating the intended sense once rather than reproducing the glitch.
- **Numbers and measurements**: Distances/measurements kept as given in the source (miles, kilometers, hectares) without conversion, per "preserve as-is" convention for factual details.
- **"w = W" formula** (Kolbe): kept exactly as in source, untranslated, since it is a mnemonic pun on "will" (vontade) that does not carry over — added no translator's note, as the surrounding text already explains "w é o que nós queremos" / "W é a vontade de Deus" in-line, making a footnote redundant.
- **Editor/publisher matter** (Nihil Obstat, Imprimi Potest, Imprimatur blocks) kept untranslated (they are formal Latin/curial certifications), consistent with prior batches per the shared journal.
- **saint-jude-helper-in-great-need.md** Mass propers: this file is essentially a devotional booklet with a votive Mass text (pre-Vatican II Latin Mass in English translation) and a litany. Translated fully into Portuguese devotional register rather than reverting to Latin, since the source itself presents these entirely in English (not bilingual), and instructions call for keeping the register the source uses.
- **"Foundling"/"enjeitados"**: chose the somewhat archaic but standard Portuguese term "enjeitados" (rather than "crianças abandonadas") to match the historical/period register of the Louise de Marillac chapter.
- No editor/publisher footnotes were present in any of these nine chapters requiring dropping — all footnote-like material (Nihil Obstat blocks, translator credit "Translation by Laura Chanler White") was preserved as part of the original work's front/back matter.
- No new translator's notes ([^1]) were added in this batch — none of the nine chapters contained material judged to require one for comprehension.

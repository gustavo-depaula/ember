# Sobre as coisas que se devem crer

**48.** São três os gêneros das coisas críveis. Umas são as que sempre se creem e nunca se entendem, como é toda a história que percorre os feitos temporais e humanos;

outras, as que se entendem logo que são cridas, como são todos os raciocínios humanos, quer sobre os números, quer sobre quaisquer disciplinas;

o terceiro gênero são as que primeiro se creem e depois se entendem, tais como aquelas coisas que, acerca das realidades divinas, não podem ser entendidas senão por aqueles que são puros de coração, o que se dá quando se guardam os preceitos que se recebem acerca do bem viver.

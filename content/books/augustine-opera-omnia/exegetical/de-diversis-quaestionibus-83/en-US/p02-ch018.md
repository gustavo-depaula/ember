# On the Trinity

**18.** Everything that is is one thing in that of which it consists, another in that by which it is distinguished, another in that by which it is in harmony.

The whole of creation, therefore, if it both exists in some way, and is most far removed from that which is utterly nothing, and is in harmony with itself in its own parts, must also have a threefold cause: that by which it is, that by which it is this, and that by which it is at peace with itself. But the cause of creation—that is, its author—we call God.

There must be, then, a Trinity, than which perfect reason can find nothing more excellent, more intelligent, and more blessed. And so too, when truth is sought, there can be no more than three kinds of questions: whether a thing exists at all, whether it is this or something else, and whether it is to be approved or disapproved.

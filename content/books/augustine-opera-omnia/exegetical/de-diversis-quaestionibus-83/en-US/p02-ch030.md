# Whether All Things Have Been Created for the Use of Man

**30.** As there is a difference between "the honorable" and "the useful," so there is also between what is to be enjoyed and what is to be used.

For although it can be subtly defended that everything honorable is useful and everything useful is honorable, nevertheless, because "honorable" is more properly and more usually said of what is to be sought for its own sake, and "useful" of what is to be referred to something else, we now speak according to this distinction—keeping in mind, of course, that the honorable and the useful are in no way opposed to each other.

For these are sometimes thought, by the unskilled and in common speech, to be opposed to each other. We are said, then, to enjoy that thing from which we take pleasure; we use that which we refer to that from which pleasure is to be taken. And so all human perversity, which is also called vice, is to wish to use the things to be enjoyed and to enjoy the things to be used; and, again, all right ordering, which is also called virtue, is to enjoy the things to be enjoyed and to use the things to be used. Now the honorable things are to be enjoyed, but the useful things are to be used.

By "honorableness" I mean intelligible beauty, which we properly call spiritual; by "usefulness," divine providence. Wherefore, although there are many beautiful visible things, which are less properly called honorable, beauty itself, from which whatever things are beautiful are beautiful, is in no way visible.

Likewise there are many useful visible things, but usefulness itself, from which whatever things profit us profit us, which we call divine providence, is not visible. Let it be known, of course, that by the name "visible" all corporeal things are included.

We ought, therefore, to enjoy the invisible beautiful things—that is, the honorable ones; but whether all of them, is another question, although perhaps it is fitting to call honorable only those which are to be enjoyed. But all useful things are to be used, in whatever way there is need of them.

And to enjoy food and any bodily pleasure is not so absurdly thought to be done even by beasts; but to use a thing cannot be done except by an animal that shares in reason. For to know to what each thing is to be referred is not given to those devoid of reason, nor even to the rational who are foolish.

Nor can anyone use a thing of which he does not know to what it is to be referred; and no one can know this except the wise. Wherefore those who do not use well are more rightly said to misuse. For nothing is of profit to anyone when he uses it badly; and what is not of profit is surely not useful. But whatever is useful is useful in the using; and so no one uses anything but the useful. He does not, therefore, use, whoever uses badly.

The perfect reason of man, then, which is called virtue, uses first itself for understanding God, so that it may enjoy him by whom it was also made; it uses also the other rational living beings for fellowship, and the irrational ones for preeminence.

It refers even its own life to this: that it may enjoy God; for thus it is happy. It therefore uses also itself. And this assuredly begins its wretchedness through pride, if it is referred to itself and not to God.

It uses also certain bodies, by giving them life, for beneficence; for so it uses its own body. It uses some bodies, by taking them up or rejecting them, for health; some, by enduring them, for patience; some, by ordering them, for justice; some, by considering them, for some lesson of truth; it uses also those from which it abstains, for temperance.

Thus it uses all things, both those that are felt and those that are not felt, and there is no third kind. But it judges concerning all the things it uses; concerning God alone it does not judge, because it judges concerning the rest according to God.

Nor does it use him, but enjoys him; for God is not to be referred to anything else, since everything that is to be referred to something else is inferior to that to which it is to be referred, and there is nothing superior to God—not in place, but in the excellence of his nature.

All things, therefore, that were made were made for the use of man, because reason, which was given to man, uses all things by judging them.

And before the fall, indeed, it did not use the things to be endured; nor after the fall does it use them except when converted, and though before the death of the body, yet already, as far as it can, a friend of God, because willingly his servant.

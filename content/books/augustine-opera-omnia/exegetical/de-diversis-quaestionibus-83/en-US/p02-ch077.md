# On Whether Fear Is a Sin

**77.** Every disturbance is a passion, every desire is a disturbance; therefore every desire is a passion. But every passion, when it is in us, we undergo by the passion itself, and we undergo it insofar as it is a passion; therefore every desire, when it is in us, we undergo by the desire itself, and we undergo it insofar as it is a desire. But every passion, insofar as we undergo it by the passion itself, is not a sin.

So too, if we undergo fear, it is not a sin. As if it were said: "if it is two-footed, it is not a beast." If, then, this does not follow, because there are many two-footed beasts, then that too does not follow, because there are many sins that we undergo. For the objection is that it does not follow that, if we undergo fear, it is therefore not a sin. But you say that it does follow that, if we undergo fear, it is not a sin; though you nevertheless concede that there are some sins that we undergo.

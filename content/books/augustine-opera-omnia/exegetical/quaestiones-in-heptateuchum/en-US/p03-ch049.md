# That all things ought to be done which can rightly be done by deliberation.

**49.** (13, 18) *And when Pharaoh let the people go, God did not lead them by the way of the land of the Philistines, because it was near. For God said*: '*lest perhaps the people repent when they see war, and return to Egypt.*' Here it is shown that all things ought to be done which can rightly be done by deliberation, to avoid what is adverse, even when God is most openly the helper.

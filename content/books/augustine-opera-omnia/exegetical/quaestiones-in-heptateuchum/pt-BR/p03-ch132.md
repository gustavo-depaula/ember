# Que é "e serão arcos para os varais".

**132.** (30, 4) *E serão arcos para os varais, de modo que por eles se leve.* Àquilo que chamara *argolas,* chama *arcos.* Pois pôs *argolas* por "asas redondas". E que outra coisa é uma argola ou um círculo, senão um arco por todos os lados? Por isso alguns, não querendo dizer *arco,* traduziram por *bainhas,* nas quais se introduzissem os varais, dizendo: *e haverá bainhas para os varais;* como se o grego não pudesse dizer isso, sendo *bainhas* também uma palavra grega; mas ele disse *ψαλίδες,* que se traduz por *arcos.*

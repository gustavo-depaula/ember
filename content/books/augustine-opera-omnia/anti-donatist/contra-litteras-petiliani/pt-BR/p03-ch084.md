# O sacrifício se torna para cada um tal qual é quem se aproxima para oferecê-lo.

**52.** 120. AGOSTINHO respondeu: Nós dizemos que o sacrifício se torna para cada um tal qual é quem se aproxima para oferecê-lo, e tal qual é quem se aproxima para recebê-lo; e que comem dos sacrifícios de tais homens aqueles que a eles se aproximam sendo tais quais também eles são; e assim, se um mau oferece a Deus e um bom dali recebe, ele se torna para cada um tal qual cada um tiver sido; porque também está escrito: *Todas as coisas são puras para os puros*[^1].

Por esta sentença veraz e católica, também vocês não estão poluídos pelo sacrifício de Optato, se os feitos dele lhes desagradavam. Pois certamente o pão dele era pão de luto, ele sob cujas iniquidades toda a África se lamentava; mas o pão de luto comum a todos vocês é o mal do cisma de todos vocês. Pois, segundo a sentença do concílio de vocês, Feliciano de Musti derramou sangue humano.

Com efeito, vocês disseram, ao condená-los: *Os seus pés são velozes para derramar sangue*[^2]. Veja, pois, que espécie de sacrifício oferece aquele que vocês têm por sacerdote, uma vez que o condenaram como sacrílego; e, se julgam que isso em nada os prejudica, pergunto-lhes: em que a vaidade das calúnias de vocês prejudicará o orbe da terra?

[^1]: Tt 1,15.
[^2]: Sl 14,3 (13,3); Rm 3,15.

# Cristo, ao morrer, instituiu uma forma de morrer, não de matar.

**87.** 192. PETILIANO disse: *Advertimos vocês, pois, se de bom grado o ouvem; e, se não o recebem de bom grado, os admoestamos; porque o Senhor Cristo instituiu para os cristãos uma forma não de matar, mas de morrer. Pois, se assim amasse os que se lhe opunham, não teria querido ser morto por nós.*

# 3. Do tesouro das palavras divinas

Eu me alegrarei com as vossas palavras: como quem encontra muitos despojos. Onde? Em nossa biblioteca, ornada de muitos códices sagrados. Pois os livros dos doutores são os tesouros dos clérigos. Ensinam os ignorantes, repreendem os ociosos; despertam os entorpecidos, estimulam os adormecidos: corrigem os que erram, levantam os que caem; atemorizam os que riem, consolam os que choram: louvam os humildes, censuram os soberbos; fortalecem os fracos, refreiam os presunçosos: reconciliam os que contendem, acalmam os perturbados; alegram os tristes, escarnecem dos que se vangloriam: justificam os piedosos, condenam os perversos; curam os enfermos, salvam os penitentes: honram os verazes, envergonham os fingidos e os mentirosos; defendem os justos e os misericordiosos: castigam todos os que praticam a iniquidade, como está escrito no salmo: “Odiastes todos os que praticam a iniquidade: destruireis todos os que falam a mentira”. Que Jesus Cristo, nosso Senhor, sempre nos guarde desses males. Amém.

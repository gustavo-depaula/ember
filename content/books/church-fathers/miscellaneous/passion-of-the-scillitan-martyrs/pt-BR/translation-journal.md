## Proper Names

The trial record names twelve martyrs plus the proconsul and the two consuls used for dating. None have an attested standard Portuguese hagiographic form (this group is far better known in the Spanish-speaking world — *Mártires Escilitanos* — than in Portuguese), so names were adapted from Latin using regular Latin→Portuguese sound-change patterns, the same patterns that produced the existing Portuguese words/names cited below:

| Latin/English | Portuguese | Reasoning |
|---|---|---|
| Speratus | Esperato | Portuguese disallows word-initial *sp-*; a prosthetic *e-* is added (cf. *spiritus* → *espírito*, *specialis* → *especial*), plus the regular *-us* → *-o*. |
| Nartzalus | Nartzalo | Punic name, no sound change beyond *-us* → *-o*. |
| Cittinus | Citino | Portuguese doesn't double consonants like Latin *-tt-*; *-us* → *-o*. |
| Donata | Donata | Already a regular Portuguese feminine name-shape; unchanged. |
| Secunda | Segunda | Latin intervocalic *-c-* lenites to *-g-* in Portuguese — this is the exact etymology of the ordinal *segundo/segunda* itself, so the name and the common word converge. |
| Vestia | Vestia | Unchanged; default Portuguese stress (paroxytone) already lands correctly on the first syllable. |
| Saturninus | Saturnino | Standard *-us* → *-o*, well-attested name. |
| Veturius | Vetúrio | *-ius* → *-io*; accented to fix the stress on *-tú-*, avoiding a hiatus misreading (cf. *Vitório*). |
| Felix | Félix | Existing standard Portuguese name, always accented. |
| Aquilinus | Aquilino | Standard *-us* → *-o*. |
| Lætantius | Letâncio | *æ* → *e*; Latin *-antius* → Portuguese *-âncio* is a regular, attested pattern (cf. *Constantius* → *Constâncio*). |
| Januaria | Januária | Existing standard Portuguese name. |
| Generosa | Generosa | Already a regular Portuguese-shaped word/name; unchanged. |
| Præsens (consul) | Praesens | Kept as in the Latin (minus the æ ligature) — a personal cognomen with no attested Portuguese form; forcing a translation ("Presente") would read as the common adjective and mislead. |
| Claudianus | Claudiano | Standard, well-attested Latin-name adaptation. |
| Cæsar | César | Standard Portuguese form of the name, used throughout the corpus (not the æ-ligature spelling). |

## Translation Decisions

- **Scripture references**: book names translated to their standard Portuguese form (*1 Timóteo*, *Romanos*), matching the convention already used across the pt-BR corpus (e.g. *Gênesis*, *João*, *Atos*). The 1 Timothy 6:16 quotation is rendered close to the standard Catholic Portuguese Bible phrasing ("a quem nenhum homem viu, nem pode ver") rather than a fresh literal gloss.
- **"Honour to Cæsar as Cæsar: but fear to God" (Donata)** is the martyr's own paraphrase, not a verbatim quotation of Romans 13:7 — translated as ordinary dialogue, not against an official Bible translation.
- No footnotes in the source (no editor apparatus to drop).
- Formal, slightly archaic legal-transcript register preserved throughout (*vós*/imperative forms for the proconsul's commands, "vós deveis fazer" etc.), mirroring the source's own courtroom-Latin-via-Elizabethan-English register.

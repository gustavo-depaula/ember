# Articulus 14

QUALIBUS FORMIS THEOLOGI PRISCI COELESTIA AUT SUPERCOELESTIA VESTIRE SEU LAUDARE SOLITI.

HÆC mysticos theologos inveniemus, non solum cœlestium dispositionum declarationibus mirabiliter circumformantes : hoc est, nos « inveniemus » in Scripturis « theologos mysticos », id est profundos, sanctos et sapientes Apostolos ac Prophetas, « circumformantes », id est, circumvestientes et applicantes, « mirabiliter », id est valde artificialiter atque utiliter, « hæc », id est similitudines, proprietates et formas has a sensibilibus sumptas, « non solum declarationibus », id est notificationibus, « dispositionum cœlestium », id est angelicorum chororum pulcherrime dispositorum supernorum ornatum, utpote ad notificandum illa suprema per ista inferiora; sed et ipsi  *aliquando thearchicis*  manifestationibus, id est, theologi interdum laudant « manifestationibus thearchicis », id est descriptionibus divinis ac principalibus, ipsam videlicet Deitatem. Thearchicum autem dicitur a Θεός, quod est Deus, et ἀρχός, princeps : inde Thearchia, id est principatus Dei, aut Deitas princeps.

Addam vero quod  *omnium vilius esse et magis significare visum est : id est, præinductis « addam » unum « quod » inter prædicta videtur « vilius esse » et minus congruere Deo, « et » quod « visum est magis significare », id est apertius ad significandum ea quæ Dei sunt, quoniam dictum est quod per abnegationes et viliora convenientius notificantur divina; quoniam* et vermis specie ipsam se ipsam circumformantem divina sapientes tradiderunt : hoc est, « quoniam sapientes divina », puta theologi, qui sapiunt et cognoscunt divina, « tradiderunt », id est docuerunt, « ipsam » Sapientiam incarnatam « circumformantem », id est, symbolice designantem, « se ipsam specie », id est similitudine, « vermis » : juxta illud in Psalmo, Ego autem sum vermis, et non homo.

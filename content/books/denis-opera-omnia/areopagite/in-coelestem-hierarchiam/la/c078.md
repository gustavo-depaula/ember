# Articulus 61

ELUCIDATIO INITII CAPITULI HUJUS DECIMI TERTII : PRIMA OPINIO CUR UNUS DE SERAPHIM DICATUR MISSUS AD PURGANDUM ISAIAM.

MOVIT sanctus hic auctor, cur ad Isaiæ purgationem dicatur unus de Seraphim missus : quod videtur præinductis contrarium, in quibus præhabitum est quod spiritus primæ hierarchiæ non mittantur ad exteriora agenda.

Age, id est eia, et hoc secundum virtutem inspiciamus, id est, pro posse consideremus, ut quid a theologis Seraphim missus fuisse dicitur. Lincolniensis ponit sic : Cujus gratia ad unum theologorum Seraphim missus esse dicitur. Sic enim in Isaia habetur : Volavit ad me unus de B Seraphim.[^1] Etenim responderit quisquam, id est, ad hoc forsitan aliquis poterit respondere, quia, id est quod, non superpositorum quis  *angelorum, id est non aliquis angelorum superiorum, qui scilicet fuerit de prima hierarchia, et de primo ordine ejus, qui Seraphim appellatur, unus vero*  quidam ex maximis essentiis in numeris purgat sacerdotem, id est, « unus quidam » directus « ex maximis essentiis », id est ab aliquo supremorum spirituum, contentus « in numeris », id est in numero inferiorum, « purgat sacerdotem », id est Isaiam prophetam.[^2] Porro aliqui habent sic : Quia non suppositorum quis angelorum, id est quod non aliquis angelorum inferiorum, sed unus ex maximis essentiis, id est unus supremorum, in illorum numero collocatus seu eis annumeratus, purgat Prophetam. An vero Isaias fuit sacerdos, apparet incertum : quia ut dicunt Hebræi, et sanctus attestatur Hieronymus, Isaias fuit de stirpe regali, et cognatus regis Ezechiæ, et per consequens ex tribu Juda, ex cujus tribu nemo præsto fuit altari, secundum Apostolum ad Hebræos. Verumtamen tribus regalis et sacerdotalis communiter consociatæ erant connubio. Poterat forsitan ex uno latere esse de stirpe sacerdotali. Si autem non fuit sacerdos legalis de tribu Levi proprie dictus, dicendum quod metaphorice vocatur sacerdos, quoniam sacra dans, et sancta docens. Unde in isto volumine sancti angeli quandoque sacerdotes vocantur, et juxta Joannem Sarracenum et Scotum, hierarchia interpretatur cœleste sacerdotium seu pontificium.

Quidam ergo aiunt, quia juxta jam ante redditam cunctorum intellectuum societatis definitionem : id est, aliqui dicunt, quod « juxta definitionem societatis intellectuum cunctorum », id est juxta prædeterminatam doctrinam et explanationem societatis, id est communionis et convenientiæ, omnium spirituum supernorum, quos diximus in aliquibus proprietatibus, viribus et actibus convenire : definitionem, inquam, « redditam ante », id est præcedenti capitulo assignatam a nobis ; non unam circa Deum primarum mentium nominat eloquium in theologi purgationem venisse, id est, quod « eloquium », utputa sermo Isaiæ prætactus, « nominat », id est affirmat, « venisse in purgationem theologi », id est ad purgandum peccatum Isaiæ loquentis de Deo, « non unam mentium », id est intellectualium substantiarum, exsistentium « primarum circa Deum », id est adsistentium Creatori et proximarum eidem, videlicet in ejus vestibulis collocatarum, ut septimo capitulo expositum est ; quemdam vero nobis præstantium angelorum, id est unum angelorum infimæ hierarchiæ præsidentium hominibus et præstantium eis illuminationes; vel, « præstantium », id est[^3]

D digniorum eis; *sacrificantem Prophetæ* *, ignis contactum describitur facta;[^4] et cœlestis, quoniam ministerio cœlestis nuntii, scilicet angeli, facta est;* et purgati in divinam obedientiam resuscitationem*, id est ob hoc quod angelus per præfatam purgationem resuscitavit et reaccendit Isaiam, ad obediendum Deo prompte ac fervide in legatione ei commissa.[^5]* *Seraphim æquivoce vocatum* *, id est alia ratione quam spiritus primi et summi chori ita vocantur, qui ab excessu caloris divini amoris, Seraphim nuncupantur.[^6] Iste vero angelus dictus est Seraphim improprie et extense, propter participationem et similitudinem actus sui cum actu seraphico: quemadmodum etiam homines in divino amore præfervidi, ac alios eodem inflammantes, dicuntur seraphici, sicut hic ipse magnus Dionysius, Augustinus, Franciscus. Hinc subditur:* propter igneam et cœlestem dictorum ablationem peccatorum*, id est « propter ablationem igneam et cœlestem peccatorum dictorum », id est culparum verborum Isaiæ: quarum culparum in verbis consistentium purgatio dicitur ignea, quia per*

Is. vi, 6, 7.

*Et eloquium, unum ex Seraphim simpliciter dixisse aiunt*, id est, isti dicunt « eloquium », id est scripturam Isaiæ præallegatam, « dixisse simpliciter unum ex Seraphim » venisse ad Isaiam, *non circa Deum collocatarum* *, sed nobis præstantium purgativarum virtutum, id est « non » unam « virtutum purgativarum collocatarum circa Deum », id est non unam mentium supernarum sublimiorum, quæ purgativæ sunt inferiorum, « sed » unam virtutum, id est unum angelorum, « præstantium nobis »: sicut expositum est. Verumtamen hoc expresse non dicit scriptura illa Isaiæ; sed præsupposito seu ostenso quod angelus ille non fuit de ordine Seraphim, elicitur ex prædictis quod fuit de infima hierarchia.* *collocatorum*

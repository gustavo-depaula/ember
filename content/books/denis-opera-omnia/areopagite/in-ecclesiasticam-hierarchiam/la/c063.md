# Articulus 55

### MYSTERIUM MONASTICÆ INSTITUTIONIS, CONSECRATIONIS ET CONSUMMATIONIS.

*SACERDOS quidem stat in conspectu divini altaris, monachicam invocationem psallens*, id est, psalmos decantans qui magis pertinore videntur ad actum consecrationis illius.

*Consummandus autem*, id est perficiendus et consecrandus in monachum, *retro sacerdotem stat, non utrumque pedem inclinans*, id est, non ambo genua flectens coram altari, sicut sacerdos, *non unum de pedibus*, id est, nec unum genu flectens, sicut diaconus, *non super caput habens Deo tradita Eloquia*, id est librum sacræ Scripturæ, ut pontifex; *tantum vero sacerdoti adstans psallenti super ipso mysticam invocationem*, id est psalmodiam et precem includentem sensum arcanum et spiritualem.

*Perficiens autem eam*, videlicet mysticam invocationem seu monachalem consecrationem, *sacerdos, ad perficiendum veniens*, id est ad consecrandum in monachum, *interrogat primum hoc*, id est, istud primo inquirit a perficiendo, *si primum abrenuntiat divisis non solum conversationibus, sed et phantasiis*, id est non solum actionibus terrenis inordinatis a Deo dividentibus, vitiosis, carnalibus, imo etiam vanis apprehensionibus, phantasticis cogitationibus, consensui illicito, cunctis affectibus pravis.

*Deinde perfectissimam ei vitam narrat*, id est, sacerdos commemorat perficiendo conversationem valde perfectam quam aggreditur, *testimonium ei perhibens*, id est, ei protestans, *quia oportet media eum superadstare*, id est, quod oporteat eum multo perfectius et spiritualius conversari quam fideles sæculares, qui sunt in medio gradu ac ordine perficiendorum.

*Hæc autem omnia perficiente intentiusque confitente*, id est, consecrando in monachum dicente se esse paratum ad omnia ista, et « confitente », id est, promittente (ut alia littera habet) quod ea servabit, *cruciformi similitudine*, id est signo crucis, *signans eum sacerdos tondet*, capillos abradens, *trinam divinæ beatitudinis invocans substantiam*, id est Deum felicitatis æternæ et increatæ, trinum in personis, unum in essentia; *et vestem omnem exuens*, id est, vestimenta priora exuens illum, *alteram*, scilicet monasticam vestem, *induit illum*; *et cum aliis sacerdotibus viris quicumque adsunt salutans eum*, id est, osculans cum imprecatione et desiderio suæ salutis, ut prosperetur in sancta religione, et valedicens ei tanquam jam morienti huic sæculo nequam, *socium perficit divinorum mysteriorum*, id est sacræ communionis.

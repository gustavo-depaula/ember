# Articulus 47

THEORIA RITUS PRÆSCRIPTI : ET PRIMO QUID SIT COMMUNE IN CONSECRATIONE OMNIUM, QUID PROPRIUM.

PRIMO hic tangitur in quibus præinductæ consecrationes conveniant, deinde in quibus ab invicem distinguantur.

Communia quidem sunt summis sacerdotibus, et sacerdotibus, et ministris, id est, episcopis, et inferioribus presbyteris, itemque diaconis, ista sunt communia, in sanctificativis eorum consummationibus, id est in eorum consecrationibus: ad divinum altare accessus et inclinatio, id est genuflexio; hierarchicæ manus impositio, id est impositio manus episcopi consecrantis super eorum capita; cruciforme signaculum, id est impressio signi crucis; præconium, id est prætacta recitatio ejus ex nomine, vel attestatio de sua idoneitate; consummativa salutatio modo exposita.

Separata autem et discreta, id est propria singulis ordinum, sunt hæc: summis quidem sacerdotibus, id est, episcopis propria est, Eloquiorum super caput impositio, id est positio libri sacræ Scripturæ super caput, non habentibus hoc minoribus ordinibus: quia nec sacerdoti, neque diacono fit hoc. Sacerdotibus vero, ambobus pedibus inclinatio, id est, sacerdotibus competit in sua ordinatione flectere genu utrumque, non habente hoc ministerium consummatione, id est ipsis diaconis in eorum ordinatione. Ministri enim, ut dictum est, id est diaconi, unum inclinant de pedibus tantum, id est unum genu dumtaxat.

Sequitur de horum significatione.

# Articulus 46

DE MYSTERIO CONSECRATIONIS SACRORUM ORDINUM.

SEQUITUR mysterium sanctificantium consummationum.

Summus quidem sacerdos, id est ordinandus et consecrandus in summum sacerdotem, *ad hierarchicam consummationem*, id est episcopalem consecrationem, *accedens, utroque pede inclinans ante* conspectum divini altaris. Alia translatio habet: Utroque genu posito ante altare. Ideo sensus est, quod utroque genu flexo coram altari, *super caput habet a Deo tradita Eloquia*, id est librum aliquem sacræ Scripturæ. Una autem littera habet: Evangelia. *Et hierarchicam manum*, id est manum episcopi consecrantis. Et hoc modo a perficiente eum, utputa consecrandum, summo sacerdote, id est episcopo consecrante, sanctissimis invocationibus, id est devotissimis precibus, consummatur, id est, ordinatur in præsulem.

Sequitur de consecratione sacerdotis. Sacerdos autem utroque pede inclinans, id est, ordinandus in sacerdotem ambo genua flectens, in conspectu divini altaris, super caput habet hierarchicam dexteram, id est manum dexteram episcopi ipsum consecrantis; et hoc modo a perficiente eum summo sacerdote sacrificis  *invocationibus, id est orationibus, quæ Deo instar sacrificii offeruntur, juxta ilud Psalmi, Dirigatur oratio mea sicut incensum in conspectu tuo, sanctificatur, id est, in sacerdotem ordinatur.[^1][^2]*

Sequitur de ordinatione diaconi. Minister vero, id est in diaconum ordinandus, unum de pedibus inclinans, id est, unum genu flectens, in conspectu altaris, super caput habet perficientis, id est ordinantis, eum summi sacerdotis dexteram, consecrandus  *ab ipso ministrantium consummativis invocationibus, id est per orationes quæ dicuntur in consummativa ordinatione diaconorum.[^3]*

Unicuique autem eorum, id est tam consecrando in episcopum, quam consecrandis in sacerdotem atque diaconum, cruciforme signatur, id est, signaculum crucis imprimitur, a perficiente, id est consecrante, summo sacerdote, signaculum; et per unumquemque prædicatio sacra fit, id est, uniuscujusque istorum nomen recitabatur, ut notificaretur ordinatio ejus: et forsan ab episcopo unusquisque illorum admonebatur ad conversandum condigne suscepto officio; et consummativa salutatio, id est valde caritativa salutis imprecatio cum deosculatione, salutante omni divino præsente viro, id est toto choro promotum, et consummante summo sacerdote ad aliquid dictarum divinarum ordinationum consummatum, id est, episcopo consecrante, complente consecrationem ejus qui ad aliquem horum ordinum provehebatur.

Denique S. Dionysius breviter ista recitat et conscribit, nec omnia exprimit quæ in horum consecratione fiebant, nec formas sacramentalium verborum, nec sensibilia symbola quæ tangebantur. Atque ut ex superficie litteræ hujus apparet, ab uno solo episcopo tunc poterat episcopus consecrari: quod et aliqui hic affirmant. Nec exprimitur hic, an episcopus consecrans archiepiscopus fuerit. Verumtamen in Summis quibusdam habetur quod ternarius numerus episcoporum, est de substantialibus consecrationis, ita quod si a paucioribus consecraretur, nil ageretur.

[^1]: Ps. cxl, 2.
[^2]: \* sacris
[^3]: \* perficiendus

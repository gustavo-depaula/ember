# Articulus 30

ELUCIDATIO PARTIS PRIMÆ HUJUS CAPITULI QUARTI: QUOD UNGUENTI MYSTERIUM SIT AFFINE VENERABILI EUCHARISTIÆ.

POSTQUAM præhabito immediate capitulo actum est de Eucharistiæ sacramento, celebratione rituque seu actibus hierarchicis circa illud, hic idem jam agitur de sacramento Confirmationis.

Tanta sanctissimæ synaxeos sunt, id est, tam magna sunt mysteria « synaxeos sanctissimæ », id est sacratissimæ communionis, quæ et synaxis vocatur, ut patuit, et sic bona invisibilia ad unum nobis, sicut sæpe diximus, hierarchice sacrificantia societatem et coordinationem: id est, invisibiles effectus sacramenti istius, ut sacramentalis gratia et efficacia ejus, sunt sacrificantes, id est, sacram facientes, « societatem et coordinationem » nostram « hierarchice », id est ecclesiastice, puta secundum doctrinam observantiamque Ecclesiæ sanctæ, « ad unum », id est reducendo nos ad Deum, qui per hoc sacramentum spiritualiter nos confortat ad præliandum contra divini honoris et nostræ salutis hostes in campo cursus et luctæ præsentis, « sicut sæpe » jam « diximus », quod scilicet per sensibilia symbola sacramentorum, ad invisibiles gratias pervenimus, et ad omnium fontem reducimur.

Sed est hujus æquipotens altera perfectiva operatio, id est, aliud quoque opus et donum Dei est, perficiens ipsos fideles in peregrinatione hac laboriosa, « æquipotens », id est æqualiter potens auxiliari. Æquipotens dico, in genere : absolute namque loquendo, sacramentum Eucharistiæ est isto potentius. Juxta quem modum dictum est libro præcedenti, quod angeli diversorum chororum seu ordinum, sunt æquipotentes. *Chrismatis hostiam duces nostri quam nominant*, id est, « quam » operationem seu Dei effectum, « duces nostri », id est Apostoli et apostolici viri, « nominant hostiam chrismatis », id est sacramentum Confirmationis, quo consecramur ac deputamur Domino Deo nostro in milites ac pugiles spirituales.

*Partes itaque ejus in ordine secundum* sacras imagines intendentes, id est, nos considerantes, « partes ejus », id est varias operationes sacramenti istius, « in ordine », id est per ordinem seu ordinate, « secundum sacras imagines », id est penes sensibilia signa et facta quæ adhibentur in Confirmatione; *sic ad unum ipsius per partes hierarchicis contemplationibus ascendemus*, id est, consurgemus « contemplationibus hierarchicis », id est considerationibus consonis doctrinæ ipsius Ecclesiæ, « per partes », id est per speculationem actuum Confirmationis, « ad unum ipsius », id est ad principalem ejus effectum; vel, « ad unum ipsius », id est ad contemplationem institutoris ipsius.

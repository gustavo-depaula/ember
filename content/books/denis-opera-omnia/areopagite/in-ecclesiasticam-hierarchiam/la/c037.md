# Articulus 31

### MYSTERIUM TELETÆ MYRI, SEU FORMA RITUSVE CONSECRANDI CHRISMATIS.

DEINDE tangitur ritus seu forma consecrationis chrismatis.

*Juxta eumdem synaxeos modum, imperfectorum absolvuntur ordines* : hoc est, « ordines imperfectorum », id est congregationes imperfectorum, qui nondum aptati sunt personaliter adesse consecrationibus sacramentorum, « absolvuntur », id est excluduntur a chrismatis consecratione, « juxta modum eumdem » quo excluduntur a templo in consecratione « synaxeos », id est sacramenti Eucharistiæ, Evangelio scilicet lecto, ut in capitulo dictum est præcedenti. *Accedentibus scilicet et hierarchico in omne templum bene olenti ambitu, et psalmica sacra cantione, et divinissimorum Eloquiorum lectione* : id est, ipso hierarcha seu præsule procedente « in omne templum », id est per totam ecclesiam, « ambitu bene olenti », id est circuitione fragranti, videlicet cum thurificatione, « et cantione sacra psalmica », id est cum devota cantione psalmorum, quos cecinit clerus, « et lectione divinissimorum Eloquiorum », id est lectione aliqua sumpta ex sacra Scriptura. His itaque accedentibus, excludebantur præfati.

*Deinde chrisma summus sacerdos accipiens, superponit divino altari circumvelatum a duodecim pennis sacris*, id est, illis peractis, præsul sumpsit chrisma mox consecrandum, superponens illud altari, obtectum et circumopertum duodecim pennis, in signum quod in Isaia fit mentio de totidem pennis, ubi de Seraphim legitur : *Sex pennæ uni, et sex pennæ alteri.[^1] Reboantibus simul omnibus sanctissima voce sanctum Deo acceptabilium Prophetarum inspirationis melodema* : id est, cunctis illis ministris devotissime concinentibus « melodema sanctum », id est canticum sacrum aliquod, « inspirationis », id est divinitus inspiratum : canticum, inquam, « Prophetarum acceptabilium Deo », id est alicujus illorum qui Deo accepti fu-

Is. vi, 3. erunt, ut est canticum illud Isaiæ : Sanctus, Sanctus, Sanctus, etc. Et in ipso perficientem orationem complens, id est, episcopus « complens orationem perficientem », id est, concurrentem et cooperantem ad perfectionem seu consecrationem tam plebis quam chrismatis, in sanctissimis consecrandorum hostiis, id est in materiis consecrandis divino cultui dedicatis, quæ per orationes et benedicti-ones consecrantur, eo utitur ad omnem fere hierarchicam perfectivam operationem, id est, utitur chrismate consecrato in cunctis quasi actionibus quibus perficit alios per sacramenta : utputa circa baptizatos et confirmatos ; verumtamen non in Matrimonio et aliquibus aliis. Propterea dicit, « fere ».

[^1]: Is. vi, 2.

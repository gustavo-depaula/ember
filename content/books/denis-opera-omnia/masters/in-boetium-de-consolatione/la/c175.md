— Tum illa inquit, id est, tunc Philosophia respondit : Ego festino absolvere, id est persolvere, exsequi et implere, debitum promissionis, id est debitam promissionem, seu debitum ad quod obligor ex C promissione, juxta illud : Omne promissum cadit in debitum. Hoc vero promissum, est declarare adhuc aliqua providentiam concernentia, atque quod subditur : et aperire tibi, id est docere te clare, viam, id est doctrinam, virtutem, modum ac medium, qua reveharis, id est revertaris, patriam, id est paradisum cœlestem, seu mentis tranquillitatem æternitatisque pacem. Hæc autem, etsi perutilia cognitu, id est, ista quæ quæris de casu, quamvis sint multum utilia ad sciendum, ne quis D putet providentiam seu fatum excludere fortunam et casum, tamen a propositi nostri tramite paulisper aversa sunt, id est, aliena sunt a processu et via nostri principalis intenti, quod fuit ea describere quæ consolatoria sunt afflictis; verendumque est, id est formidandum, ne deviis fatigatus, id est, ne tu lassatus quæstionibus et responsionibus impertinentibus huic proposito et abducentibus a principali intento, ad emetiendum rectum iter sufficere non possis, id est, non valeas satis fortis consistere ad pertranseundum « rectum iter », id est investigationem et apprehensionem pertinentium ad principale propositum.

— Ne id (inquam) prorsus vereare, id est, ego Boetius dico, Philosophia, ne verearis hoc prorsus, id est, omnino non timeas hoc. Nam ea quibus maxime delector, agnoscere, hoc est, scire ea in quibus præcipue delector interiori lætitia, fuerit, id est erit, mihi loco quietis, id est quies B et repausatio, non labor. Consideratio enim veritatis, per se delectat. Ideo Seneca dixit : Qui sine tristitia vivere cupit, philosophiæ insistat. Simul quum omne disputationis tuæ latus, id est, quia etiam id quod ad tuam disputationem collateraliter, incidentaliter seu correlative se habet, indubitata fide constiterit, id est, certum mihi erit « fide indubitata », id est firmo consensu (sicque fides hic sumitur non prout est theologica virtus, aut evidentiam veritatis excludens, sed pro firmo assensu communiter, sive innitatur auctoritati sive rationi : sicut quum dicitur, Argumentum est ratio, rei dubiæ faciens fidem), nihil de sequentibus ambigatur, id est, idcirco nil dubitetur « de sequentibus », id est de dicendis a te, quin ea diligenter advertam.

— Tum illa inquit, id est, Philosophia dixit : Geram tibi morem, id est, faciam tibi ut consuetum est mihi, et conformabo me tuo affectui condescendamque tibi quantum fas est, quum similitudo sit causa amoris. Simulque sic exorsa est, id est, incepit pariter sic loqui :

Si quidem (inquit) aliquis casum esse definiat, id est, « si aliquis » affirmet « casum esse », eventum, id est effectum, productum motu temerario, id est processu inordinato, improvido, et connexione causarum nulla, id est absque omni connexione et ordine causarum; nihil omnino casum esse confirmo, id est, casum sic definitum et sumptum dico non esse aliquid in re, et præter rei subjectæ significationem, inanem prorsus vocem esse decerno, id est, judico casum sic definitum, « esse vocem prorsus inanem », id est nomen cui nil correspondet in re : ideo additur, « præter rei subjectæ significationem », id est nomen carens significatione rei substratæ et correspondentis significationi, ut hoc nomen, Chimæra. Sicque Epicurei definierunt et esse dixerunt casum. Contra quos subditur :

Quis enim potest esse ullus (id est aliquis) locus reliquus, id est residuus, temeritati, id est inordinato temerarioque eventui, et hoc dico, Deo per suam providentiam coercente (id est, constringente et comprehendente) cuncta quæ fiunt in ordinem, id est sub ordinata et justa seu condecente causarum coordinatione et connexione, quoad suam prævisionem? ut paduit prosa sexta libri quarti.

Nam nihil ex nihilo exsistere, vera sententia est, id est, vera doctrina est quod « nihil » constat « ex nihilo », id est, quod res nulla producta est a non ente seu non causa : imo producere seu causare præsupponit esse. Cui nemo unquam veterum, id est antiquorum philosophorum, refragatus est, id est, restitit aut contradixit huic sententiæ. Unde primo Physicorum habetur, quod philosophantes maxime horruerunt concedere ex nihilo aliquid fieri : imo effectus et causæ dicuntur ad invicem relative, sicut Creator et creatura. Philosophi tamen hoc intellexerunt de causa materiali, non de causa efficiente. Ideo subditur : quanquam, id est quamvis, illi antiqui id jecerint, id est, hoc dictum, utpote ex nihilo nihil fieri, posuerint, quasi quoddam fundamentum omnium rationum de natura, id est argumentationum et inquisitionum quæ fiunt et sunt « de natura », id est de naturalibus rebus ; seu, « omnium rationum », id est scientiarum, « de natura », id est naturalium ; non de principio operante, id est non de causa efficiente, sed de materiali subjecto, id est de materia prima seu proxima, quæ est subjectum materiale in quod et circa quod et ex quo agit causa efficiens. Quod etiam verum est loquendo de operatione seu actione quæ fit per motum, non de ea quæ est per primam et simplicem emanationem, quæ non præsupponit nisi causam efficientem, ut Avicenna et Algazel in pluribus locis scripserunt. Unde et Plato in primo Timæi fatetur : Nihil fit cujus ortum legitima causa et ratio non præcedat. In Job quoque habetur : Nihil in terra sine causa fit.

At si nullis ex causis aliquid oriatur, id est, « si aliquid » producatur « ex nullis causis », id est sine omni causa, præsertim efficiente, de qua jam est sermo, id de nihilo ortum esse videbitur, id est sine effectivo principio. Quod si hoc fieri nequit, id est, quia impossibile est hoc accidere, nec possibile est quidem, id est certe, casum esse hujusmodi, id est talem esse, qualem paulo ante definivimus eum esse, hoc est, qualem nunc in prosa hac ipsa diximus eum ab Epicureis definiri, utpote quod sit eventus temerario motu sine causarum connexione productus : ita quod motus ille dicatur temerarius, quum non dirigatur aliqua causa sapienter ac ordinate agente, quia a tali causa negat Epicurus mundum gubernari, seu etiam esse productum, sed potius ex fortuitu atomorum concursu.

Ad hæc Boetius : Quid igitur? inquam, id est, quæro quid ergo dicis esse casum. Nihilne est, id est, an sit aliquid, quod vel casus vel fortuitum jure appellari queat, id est, quod rationabiliter possit vocari casus seu casuale? An est aliquid cui vocabula ista conveniant, id est, utrum sit « aliquid » in rerum natura seu aliqua res « cui conveniant ista vocabula » casus et casuale, tametsi, id est quamvis, lateat vulgus, id est vulgares et imperitos ?

Ad quod Philosophia : Aristoteles meus, id est inter alumnos et professores meos præcipuus, id (inquit) definivit, id est, determinavit « id » quod quæris, in Physicis, secundo videlicet Physicorum, ratione, id est descriptione, *et brevi et veri propinqua*, id est vicina veritati : non quod ratio Aristotelis in hac re aliquid contineat falsitatis, sed quoniam non est satis perfecta, exponendo qualiter fortuna seu casus in divina providentia certam habeat connexionem causarum. — *Quonam (inquam) modo?* id est, ego Boetius dico et quæro « quonam modo », id est, quo utique modo Aristoteles casum definivit.

— *Quoties (ait) aliquid cujuspiam rei gratia geritur*, id est, Philosophia ait, Quoties agitur aliquid causa seu intentione alicujus rei, *aliudque, quibusdam de causis, obtingit*, id est, et alter effectus consequitur et contingit, *quam quod intendebatur, casus vocatur*, id est, causa per accidens illius effectus dicitur casus ; vel, « casus », id est casualis effectus, « vocatur » effectus ille non intentus. Quemadmodum autem fortuna quandoque accipitur pro effectu fortuito, quandoque pro causa per accidens illius effectus, ita et casus. Deinde subditur horum exemplum notorium et commune. *Ut si quis fodiens humum*, id est, sicut si aliquis fodiens terram, *causa agri colendi*, id est intentione seminandi fecundandique agrum, *inveniat pondus auri defossi*, id est occultati sub terra.

*Hoc igitur fortuito quidem creditur accidisse*, id est, inventio ista thesauri putatur evenisse fortuitu, casualiter : imo et ita est respectu ejus qui per intentionem propriam thesaurum hujusmodi abscondit. *Verum non de nihilo est*, id est, inventio illa non est sine causa, imo nec sine causa certa ac præintenta, respectu providentiæ Dei omnia ordinantis et præintuentis et connectentis. *Nam proprias causas habet*, utpote auri absconsionem in agro, et fossionem agri in loco illo, *quarum concursus*, scilicet causarum connexio (quamvis una præteriit quantum ad suum esse reale et actuale, puta defossio; virtualiter tamen manet, præsertim in intellectu divino omnia disponente), *improvisus*, id est non præcognitus neque intentus ab inventore pecuniæ, et *inopinatus*, id est insperatus nec præcogitatus, *casum videtur operatus*, id est, causa est ipsius casus seu casualis effectus. Casus quippe pro fortuna acceptus, est realiter practicus intellectus, qui est causa per se fossionis, et causa per accidens inventionis thesauri, ut dictum est supra. *Nam nisi cultor agri humum foderet*, id est, nisi agricola seu arator everteret terram, et *nisi depositor*, id est absconditor thesauri, *pecuniam suam eo loci obruisset, aurum non esset inventum*, id est thesaurus ille, tam improvise.

B Hæ sunt igitur fortuiti causæ compendii, id est, istæ sunt causæ effectus celeriter provenientis et expedite, hoc est repente et improvise, *quod compendium casuale provenit*, id est, oritur et causatur, *ex causis obviis sibi*, id est mutuo obviantibus modo præfato, *et confluentibus*, id est concurrentibus actualiter aut virtualiter, aut quantum ad suos effectus, sicut effectus defossionis est situatio thesauri sub terra, *non ex intentione gerentis*, id est non ex proposito invenientis thesaurum, seu particularis agentis. *Neque enim vel qui aurum obruit*, id est, sub terra abscondit, *vel qui agrum exercuit*, id est, evertit, aravit seu fodit, *ut ea pecunia reperiretur intendit*, id est, nullus eorum intendebat ibi inveniri pecuniam occultatam : quamvis interdum ex intentione pecunia quæratur et inveniatur sub terra ; sed tunc non est casualis effectus. *Sed uti* (id est sicut) *jam dixi, convenit*, id est, in unum seu pariter venit, *atque concurrit, hunc fodisse* in loco *quo ille*, id est alius, *obruit*, id est, gazam celavit.

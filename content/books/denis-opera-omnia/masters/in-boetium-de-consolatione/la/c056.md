# Articulus 10

### EXPOSITIO METRI HUJUS TERTII.

IN hoc tertio hujus secundi voluminis in quantum sine labore et fatigatione movetur, quemadmodum qui sedet in curru currente. Equi vero currus illius intelligi potest vis motiva exsistens in partibus sphæræ anterioribus. Quidam per equos hos intelligunt quatuor diversitates in quibus sol a terrigenis cernitur : quoniam in aurora videtur rubere, hora tertia pallere ; in meridie fervere, ad vesperam tepere videtur. Quadrigam quoque soli attribuunt propter quatuor diversitates anni, quæ varios accessus et recessus solis sequuntur : et de his dictum est libro primo, metro secundo.

Quum Phæbus, id est sol, cæperit polo, id est ex orbe suo cœlesti, spargere, id est hinc inde diffundere, lucem quadrigis roseis, id est vehiculis rubicundis, quia diluculo seu aurora sol rubeus apparet ut rosa; stella, utputa matutina, seu quælibet stella, pallet hebetata, id est offuscata pro parte lumine clariori, hoc est flammis prementibus, scilicet radiis solis prævalentibus : qui radii flammæ vocantur, non quod in se ignei æstimentur, sed quia ex forti repercussione ipsorum igneus calor generatur inferius.

Denique sol metaphorice currum et equos habere fertur, juxta modum loquendi poeticum, sicut et terra dicitur fundamenta habere, juxta illud Job :[^1] Ubi eras quando ponebam fundamenta terræ? Sequitur similitudo secunda. Quum nemus, id est rosetum seu frutex, irrubuit, id est, rubicundum fuerit, rosis vernis, id est splendidis, flatu, id est cooperante perflatione, Zephyri, id est venti occidentalis sic appellati, tepentis, id est modice calidi, Auster, id est ventus hujusmodi, nebulosus, id est nebularum adductivus, spiret, id est, si spiraverit seu flaverit, insanum, id est immoderate et acriter, dercus, id est ornatus rosarum, abeat jam, id est, mox recedet, a spinis, id est a ligno spinoso in quo rosæ nascuntur. De ventis et eorum distinctione ac efficientia dictum est supra.[^3]

rum, utpote diaphanum atque perspicuum instar vitri, *tranquillo*, id est tempore tranquillitatis, *sereno*, id est puro a caligine nubium et vaporum obscurantium aerem et impedientium eum a receptione radiorum solis, ex quibus aqua maris splendidior redditur. Quod etiam fit *fluctibus* maris *immotis*, id est non concitatis ad motum impetuosum, quamvis jugiter sint in motu, juxta illud in Isaia:[^4] Impii quasi mare fervens, quod quiescere non potest. Quod etiam ad influentiam lunæ stellarumque Pleiadum movetur et fluit ac refluit, ut supra dictum est plenius. *Aquilo*, id est ventus septentrionalis, *concitat sæpe procellas ferventes*, id est, impetuose erumpentes, ascendentes ac descendentes, *æquore verso*, id est ipso mari a tranquillitate ad tempestatem inquietudinemque mutato; vel « verso », id est ejecto ex fundo vi tempestatis.

Si (pro Quia) *mundo*, id est creaturis mundi inferioris, videlicet elementis et elementatis, *sua forma*, id est habitudo et species, *constat*, id est, constans est, seu consistit et posita est, *rara*, id est instabilis et incerta, raroque diu durans (propter quod ad Corinthios scribit Apostolus: Præterit figura hujus mundi;[^5] et juxta

A Philosophum, Omnia quæ sunt in tempore, tempore decidunt et tabescunt), *si* (pro Quia) mundus *variat tantas vices*, id est, tantas vicissitudines variationum ac motuum recipit; *crede fortunis hominum caducis*. Istud ironice dicitur, ut sit sensus: Quum ita sit, merito credere non debes nec te ipsum committere « fortunis », id est fortunatis factis atque eventibus, « hominum caducis », id est transitoriis. *Crede*, id est, innitere et inhære, intelligendo ironice, *bonis fugacibus*, id est incessanter ad occasum tendentibus, ita quod recedunt et fugiunt a permanentia mundi et a duratione ac veritate proprii esse: ideo stultum est talibus inhærere. Propter quod sanctus ait Gregorius: Fugientem mundum sequimur, labenti inhæremus; et quia labentem tenere non possumus, cum ipso cadimus quem tenemus.

Constat, id est, manifestum est, *legeque æterna positum est*, id est divinitus institutum ac lege increata seu divina providentia ordinatum, *ut nihil genitum*, id est nulla res mixta et generata de novo, *constet*, id est, firmiter duret incorruptibiliterque subsistat: imo, ut probat libro de Generatione Philosophus, omne generatum est corruptibile.

# Articulus 14

### EXPOSITIO METRI HUJUS QUINTI.

FREQUENTER in hoc libro metra correspondent sententiis prosarum immediate præcedentium: ita et metrum hoc. Dictum est enim in fine prosæ mox antecedentis, mirum non esse si ea quæ fiunt in mundo, videantur aliquando confusa et insipienter provenientia, ei qui nescit causam eventus rationemque entis: quia (ut tactum est ibi) admiratio oritur, dum effectus videtur cujus causa nescitur. Propter quod, secundum Philosophum, propter admirari, id est ex admiratione, cœperunt homines philosophari. Hic ergo ponit Philosophia de hoc duo exempla; deinde subjungit exempla duo, quod nemo miratur de hoc cujus scit causam. Itaque ait:

Sequuntur duo exempla seu opera in quibus homines non mirantur. *Nemo miratur flamina*, id est commotiones et impulsiones, *Cauri*, id est venti impetuosi sic appellati, *tundere*, id est percutere, *littus* maris *fluctu frementi*, id est aquis impulsis usque ad littus. *Nec* quisquam miratur *molem nivis duram frigore*, id est grandem massam nivis frigore induratam, *solvier*, id est dissolvi ac liquefieri, *æstu Phæbi fervente*, id est forti solis calore. In quibus verbis « solvier » ponitur pro solvi seu resolvi, causa metri, per figuram quæ dicitur paragoge. *Hic enim*, id est in duobus istis operibus seu exemplis, *cernere* (id est cognoscere) *causas eorum promptum est*, id est facile ; *illic*, id est in duobus illis exemplis, *causæ latentes*, id est incognitæ, hoc est ignorantia causarum, seu desiderium cognoscendi incognita, *turbant pectora*, id est, sollicitant mentes ad inquirendum : nam omnes homines naturaliter scire desiderant, secundum Philosophum.

In præinductis tangitur duplex causa admirationis: una est ignorantia causæ; alia est novitas seu inconsuetudo magnitudove rei. Nempe, ut super Joannem asserit Augustinus: Surrexit unus mortuus, et admirati sunt omnes, quum nemo miretur quotidie generari quæ antea non fuerunt. Quotidiana autem Dei miracula (hoc est magnifici ejus effectus in regimine universi, in rerum naturis, in productionibus rerum) non eorum facilitate, sed assiduitate, hominibus viluerunt. Interea, quamvis omnium rerum causas cognosceremus, adhuc tamen effectus et opera Omnipotentis videremus esse præclara, ita quod diceremus:[^1] Non est similis tui in diis, Domine, et non est secundum opera tua.

[^1]: Ps. LXXXV, 8.

# Articulus 14

### EXPOSITIO METRI HUJUS QUINTI.

FREQUENTER in hoc libro metra correspondent sententiis prosarum immediate præcedentium: ita et metrum hoc. Dictum est enim in fine prosæ mox antecedentis, mirum non esse si ea quæ fiunt in mundo, videantur aliquando confusa et insipienter provenientia, ei qui nescit causam eventus rationemque entis: quia (ut tactum est ibi) admiratio oritur, dum effectus videtur cujus causa nescitur. Propter quod, secundum Philosophum, propter admirari, id est ex admiratione, cœperunt homines philosophari. Hic ergo ponit Philosophia de hoc duo exempla; deinde subjungit exempla duo, quod nemo miratur de hoc cujus scit causam. Itaque ait:

*Si quis nescit sidera Arcturi,* id est stellas Ursæ majoris, quæ Currus seu Plaustra vocatur, labi, id est sua circumvolutione descendere, *propinqua cardine summo,* id est polo arctico, qui est polus superior quantum ad nos, respectu quorum jugiter elevatus est. De hoc Arcturo quære supra, metro quinto primi libri, ubi de eo plura conscripta sunt.[^1] Item, si quis nescit *cur Bootes*, id est stella illa apparatu pusilla, et quasi residens super stellam illam majorem quæ dicitur medius equus ipsius currus, atque a vulgaribus vocatur Auriga, *regat*, id est ducat, *plaustra*, id est Ursam illam, ponendo plurale pro singulari, *tardus*, id est non ita velociter procedens et motus ut stellæ a polo distantiores ; et cur Bootes *mergat*, id est, deprimere videatur, *æquore*, id est in mari Oceano, *flammas seras*, id est splendidas Ursæ majoris stellas, quæ tarde moventur et circulum parvum describunt propter vicinitatem suam ad polum. Loquitur quoque Philosophia more vulgi secundum apparentiam, judiciumque vulgarium, qui stantes in ripa maris, et præter cœlum et aquas nil ultra videntes, putant et judicant stellas et planetas in aquas descendere, ut dictum est sæpe. *Quum* tamen Bootes *explicet*, id est, agat et ostendat, *ortus nimis celeres*, id est, valde mane videatur oriri et de occasu suo erumpere. Denique Philosophia loquitur hic quoad eos qui in climate primo aut secundo vel circiter commorantur : quibus stella hæc occidit, et sub horizonte eorum deprimitur ; nobis autem eminet semper. Itaque qui hæc nescit, *stupebit legem*, id est dispositionem et cursum, *ætheris alti*, id est cœli stellati : cur scilicet in eodem quædam stellæ velocissime moveantur motu sui orbis, quæ remotissime distant a polo ; quædam tardissime, quæ sunt propinquissimæ polo eidem ; quædam medio modo.

*Palleant plenæ cornua lunæ*, id est, si contigerit quod pallescant et nobis obtenebrescant cornua lunæ dum plena est.[^2] Quod fit dum luna jam plena eclipsatur : cujus cornua dicuntur hic extremitates ipsius, per quas tota luna designatur quoad superficiem ejus versam ad nos. « Cornua », inquam, *infecta*, id est obscurata, *metis noctis opacæ*, id est terminis noctis tenebrosæ : cujus metæ sunt protensiones suæ caliginis, quæ usque ad lunam pertingunt, sole subtus abscondito. Et si *Phœbe confusa*, id est luna eclipsata, *detegat astra*, id est, apparere faciat stellas parvas sibi viciniores : quas suo lumine (antequam eclipsaretur) offuscavit ne apparerent. Ideo subditur : *quæ* astra *texerat*, id est, videri impedivit, *ore fulgenti*, id est superficie sua clara ac splendida. *Error publicus*, id est evidens et generalis imperitia ac falsa opinio, *commovet*, id est, turbat, sollicitat, *gentes* indoctas, puta vulgares, qui putabant eclipsim lunæ per incantationes fieri mulierum, nec esse quid naturale; *lassantque crebris ictibus, id est frequentibus percussionibus,* æra*, id est ærea instrumenta, super quæ fecerunt pulsationes intensas ad terrendum et fugandum hujusmodi incantatrices.[^3]*

Sequuntur duo exempla seu opera in quibus homines non mirantur. *Nemo miratur flamina*, id est commotiones et impulsiones, *Cauri*, id est venti impetuosi sic appellati, *tundere*, id est percutere, *littus* maris *fluctu frementi*, id est aquis impulsis usque ad littus. *Nec* quisquam miratur *molem nivis duram frigore*, id est grandem massam nivis frigore induratam, *solvier*, id est dissolvi ac liquefieri, *æstu Phœbi fervente*, id est forti solis calore. In quibus verbis « solvier » ponitur pro solvi seu resolvi, causa metri, per figuram quæ dicitur paragoge. *Hic enim*, id est in duobus istis operibus seu exemplis, *cernere* (id est cognoscere) *causas* eorum *promptum est*, id est facile ; *illic*, id est in duobus illis exemplis, causæ *latentes*, id est incognitæ, hoc est ignorantia causarum, seu desiderium cognoscendi incognita, *turbant pectora*, id est, sollicitant mentes ad inquirendum : nam omnes homines naturaliter scire desiderant, secundum Philosophum.

*Cuncta quæ ætas provehit*, id est, omnia illa quæ tempus humanæ ætatis producit, *rara*, id est raro evenientia, seu inconsueta et ardua (dicitur autem tempus facere ea quæ fiunt in tempore, ut dictum est sæpe), stupet*, id est miratur, vulgus mobile, id est instabile et inconstans, quod motibus passionum atque erroribus levitateque cordis agitatur hinc inde, subitisque*, id est, vulgus etiam stupet ex effectibus subito et inopinate fientibus, quamvis sciat quod divina fiant virtute:[^4] quoniam prima facie non satis potest considerare excellentiam causæ et efficientiam ejus. *Error nubilus inscitiæ*, id est gravis ignorantia ineruditionis, cedat, id est, recedat et deleatur, *cessant profecto*, id est, pro certo cessabunt, *videri mira*, quæ nunc indoctis mira videntur.

In præinductis tangitur duplex causa admirationis: una est ignorantia causæ; alia est novitas seu inconsuetudo magnitudove rei. Nempe, ut super Joannem asserit Augustinus: Surrexit unus mortuus, et admirati sunt omnes, quum nemo miretur quotidie generari quæ antea non fuerunt. Quotidiana autem Dei miracula (hoc est magnifici ejus effectus in regimine universi, in rerum naturis, in productionibus rerum) non eorum facilitate, sed assiduitate, hominibus viluerunt. Interea, quamvis omnium rerum causas cognosceremus, adhuc tamen effectus et opera Omnipotentis videremus esse præclara, ita quod diceremus: Non est similis tui in diis, Domine, et non est secundum opera tua.[^5]

# Articulus 3

### EXPOSITIO METRI HUJUS PRIMI.

QUOD in fine prosæ præcedentis Philosophia disseruit, se primo velle falsam felicitatem ostendere quid sit, ut vitetur, sicque veram beatitudinem declarare, ut apprehendatur, hoc in isto metro deducit rationabiliter fieri, per quædam exempla: quia in primis necesse est mala eradicare, errores abjicere, damnabilia removere, antequam virtutes, sapientia, beatitudo obtineantur. Ad quod inducit Philosophia quatuor similia.

Primum de agro. *Qui*, id est quicumque agricola, *volet*, id est desiderabit, *serere*, id est seminare, *agrum ingenuum*, id est fertilelem terram : sicut in Ezechiele terra promissionis vocatur terrarum取egria.[^1] De qua fertur in Psalmo :[^2] Pro nihilo habuerunt terram desiderabilem. *Liberat*, id est purgat, *prius arva*, id est sulcos seu terras, *fruticibus*, id est herbis nocivis, fructificationem impedientibus, *resecat* quoque, id est amputat, *falce*, id est hujuscemodi ferreo instrumento, *rubos*, id est spineta, *filicemque*, id est herbam ibi impertinentem sic nominatam, *ut Ceres gravis*, id est gravida causa frugum, seu tellus fecundata, *eat*, id est, processum habeat usque ad messem, *nova fruge*, id est recentibus bladis et fructibus quæ producit.

Consequenter ponitur secundum simile et exemplum. *Labor apium*, id est mel, quod apes laboriose producunt, colligendo ex floribus ejus materiam, *est dulcior mage*, id est magis et perceptibilius, *si sapor malus*, id est amarus, *edat*, id est, afficiat seu mordeat, *prius ora* comedentium mel : quia sic experimentalius percipiunt mellis suavitatem, eo quod opposita juxta se posita, evidentius pateant, et quia dulcedo mellis amaritudinem afflictivam expellendo, gustum relevat ampliusque delectat.

Sequitur tertium simile. *Astra nitent*, id est splendent, *gratius*, id est magis acceptabiliter, *ubi Notus*, id est quando ventus ille australis interdum intempestuosus ac pluviæ adductivus, *desinit dare*, id est, cessat emittere et causare, *sonos imbriferos*, id est commotiones imbribus junctas.

Sequitur exemplum quartum. *Ut*, id est postquam, *Lucifer*, id est stella matutina, *pepulerit*, id est expulerit, *tenebras noctis* : non quod totaliter eas removeat, sed pro parte ; suoque ortu denuntiat eas protinus expellendas per solis adventum; *dies* *pulchra agit equos roseos*, id est celeres cursus delectabilesque processus, seu rutilantem auroram; ipsos quoque equos, instar rosarum decoros atque amœnos, tunc « agit », id est, movet et excitat ad currendum, secundum quod tempus dicitur facere ea quæ fiunt in tempore, ut dictum est sæpe.

Consequenter Philosophia ad propositum applicat ista. *Tu quoque*, o Boeti, *tuens*, id est considerans, *prius bona falsa*, id est felicitatem falsam et ejus effectus, qui sunt excæcatio mentis, læsio, perditio animæ, ac totius damnatio hominis, *incipe retrahere colla*, id est mentis cervicem et arbitrii libertatem instar colli erectam (sicut in libro Job dicitur de superbo :[^3] Cucurrit adversus Deum erecto collo.[^4] Quo contra in Ecclesiastico docetur : Humilia valde spiritum tuum, quia vindicta carnis impii, ignis et vermis), *jugo*, id est a servitute iniquitatis, ac falsæ terrenæ prosperitatis. *Dehinc*, id est statim hoc facto, *vera bona*, id est virtutes et meritorii actus, *subierint*, id est ingredientur, *animum*, id est spiritum tuum seu mentem. Nec oportet quod ibi sit prioritas temporis, sed naturæ, nisi loquendo de bonis veris secundum esse perfectum. Vitia et enim et errores ac falsitates non expelluntur nisi per veram informationem et veritatis illuminationem atque virtutum adeptionem seu infusionem, sicut nec ægritudo nisi per sanitatis accessum, et peccatum per gratiam. Loquendo quoque de virtutibus acquisitis, virtutes paulatim, non instantanee, acquiruntur; et primo acquiritur dispositio, quæ successive fit habitus. Virtutes autem infusæ, in instanti desuper tribuuntur : quibus infusis, non semper protinus expelluntur vitiorum pristinorum reliquiæ, neque infectio fomitis, hoc est pronitas ad peccandum, debilitas resistendi peccatis, et difficultas bene agendi; sed quanto instantius exercet se homo in actibus bonis exercitiisque virtutum, invocando Dei auxilium, tanto plus istæ reliquiæ exstirpantur, et bona eis contraria, hoc est, robur resistendi tentationibus et peccatis, firmitas standi, facilitas et alacritas ad bene agendum, crescent, augentur et perficiuntur in eo: prout

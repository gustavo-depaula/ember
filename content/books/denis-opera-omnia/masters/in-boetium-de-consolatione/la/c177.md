# Articulus 2

### ELUCIDATIO METRI HUJUS PRIMI.

IN hoc primo hujus libri quinti metro, declarat Philosophia per quædam exempla quod in fine prosæ præcedentis dixit de casu, quod ex pluribus concurrentibus oritur causis, quæ ex uno fonte, videlicet ex divina providentia, oriuntur, et rursus reducuntur et uniuntur in illa. Sic quippe duo magni fluvii, utpote Tigris et Euphrates, ex uno fluunt fonte paradisi, quamvis interdum ex aliis locis videantur procedere, secundum quod hinc inde absorbentur a terra.[^1] Itaque ordo et sensus verborum est :

Tigris, id est flumen illud impetuosum velociterque decurrens, et Euphrates, id est alius fluvius ex paradiso emanans, resolvunt se, id est, scaturiunt et ab invicem dividunt se, ex uno fonte, scopulis, id est inter scopulos et saxa, rupis Achæmeniæ, id est rupis exsistentis in regione sic dicta, ubi sunt saxei montes, ex quorum uno fons effluit, ex quo derivantur hi fluvii, qui originaliter fluunt ex paradiso, ut in libro Geneseos patet, ubi, id est in qua Achæmenia exsistente in Chaldæa, pugna fugax, id est turba plebis illius pugnans et vulnerans fugiendo, versa, id est tergum vertens ad hostes, figit spicula, id est, infigit tela et jacula, pectoribus sequentum, id est corporibus hostium insequentium eos. Habet enim gens illa consuetudinem hanc, ut prælio imminente callide fugiant, et fugiendo retrorsum ejiciant tela et jacula, per quæ vulnerant insequentes. Et Tigris ac Euphrates dissociantur, id est, in duo flumina dividuntur, mox aquis abjunctis, id est, statim dum aquæ ex uno fonte erumpentes, incipiunt per duo currere loca.

Si coeant, id est, iterum colligantur in unum, iterumque revocentur in unum cursum, ita quod concurrendo fiant denuo unum flumen : quod raro contingit; confluat, id est, in unum currat aliquid ex utroque flumine, quod unda vadi alterni, id est aqua utriusque fluminis, trahit, id est, per semitam suam deducit; conveniant puppes, id est, naves utriusque fluminis confluant et congregentur sicut et aquæ per quas procedunt (vel, « conveniant », id est, mutuo sibi occurrant), et trunci vulsi flumine, id est, arbores vi fluminum erat- B dicatæ conveniant; undaque mixta, id est collecta ex ambobus illis fluminibus, implicet, id est, includat et intra se habeat, modos fortuitos, id est motus et inundationes varias et casuales. Quos tamen causus vagos, id est incertos fluctus et motus fortuitos, subaudi, regunt, id est, moderantur et causant, ipsa declivia, id est declivitas, terræ super quam aqua decurrit, unde et elevationes depressionesque habet, et regit defluus ordo gurgitis lapsi, id est situs fluminis deorsum currentis, exsistens non in quiete, sed in defluxu assiduo : ex quo situ seu ordine causatur motus ille aquarum fortuitus.

Sic, id est, sicut jam dictum est de varietate motuum duorum fluminum concurrentium et collectorum, fors, id est fortuna, quæ videtur fluitare, id est varios et incertos processus et actus habere, secundum quod inopinate et ex causis per accidens concurrentibus oritur, et hoc dico, habenis, id est regiminibus suæ instabilitatis ac varietatis, permissis, id est suæ naturæ relictis; patitur frenos, id est moderationes et repressiones juxta dispositionem et præordinationem divinæ providentiæ: ideo subditur, ipsaque, utpote fors seu fortuna, *meat*, id est, procedit et operatur, *lege*, id est jussione, dispositione seu præordinatione Providentiæ increatæ.

At vero posset hoc metrum mystice explanari, et pulcherrima documenta proferri : quod tamen sine grandi difficultate et prolixitate extenuationeque litteræ non videtur fieri posse, et forsan tædium magis quam fructum nondum spiritualibus generaret; idcirco pertranseo.

[^1]: Gen. II, 14.

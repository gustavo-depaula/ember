# Articulus 9

ELUCIDATIO METRI HUJUS TERTII.

IN fine præhabitæ prosæ locuta est Philosophia de spirituali et vili transformatione hominum iniquorum in bruta; hic tangit de hoc quasdam fabulas poetarum. Nempe in libro Metamorphoseon refert Ovidius, quod Ulysses princeps cum sociis suis ac servis navigans, redeundo a Troja ad Græciam terram suam natalem, appulsus est tempestate ad insulam quamdam, in qua regnavit dea nomine Circe, filia Solis : ad quam quidam ex comitiva Ulyssis missi, ab ea in bestias dicuntur conversi. Offenderant enim deam illam in Troja : propter quod redeuntibus suscitavit tempestatem in mari, ita quod compulsi sunt declinare ad domum deæ illius. Itaque sensus et ordo verborum est :

Eurus, id est ventus orientalis sic dictus, appulit, id est, vi adduxit applicareque fecit, vela, id est lintea expansa in navi, ducis Neritii, id est Ulyssis principis, originem ducentis ex terra Neritiæ regionis, et rates, id est naves, vagas pelago, id est vage hinc inde jactatas in mari ex vento et tempestate. « Appulit », inquam, insulæ qua, id est in qua, residens dea pulchra, utputa Circe, edita semine, id est nata ex semine, Solis, quia ob pulchritudinem et sapientiam suam dicebatur filia Solis : quoniam Sol, sicut Apollo, deus sapientiæ vocabatur, quemadmodum et Minerva, sapientiæ dea; miscet, id est præparat, hospitibus novis, id est advenis ad se missis, pocula tacta carmine, id est confecta cum incantatione magicæ artis.

Quos hospites, ut, id est postquam, madus, id est virtus seu actus deæ præfatæ, herbipotens, id est potens in herbis, ad agendum secreta virtute herbarum (in quarum virtutibus cognoscendis, a malis fuit instructa spiritibus), vertit in varios modos, id est diversas formas, figuras, effigies bestiales; facies apri tegit hunc : id est, dispositio vultus ipsius apri videbatur esse in uno sociorum Ulyssis transformato in aprum; ille, id est alter illorum, effectus, quantum ad exteriorem effigiem, leo Marmaricus, id est regionis quæ Marmarica nuncupatur (et ut fertur, est pars Africæ : in qua Marmarica sunt gentes feroces, et valde fortes leones), crescit dente et unguibus, id est, dentes et ungues ei succrescunt. Mox enim ut homines pocula illa biberunt, creverunt eis diversa ad bestias pertinentia, ut ungues, dentes et cornua. Hic, id est alter illorum, *superadditus lupis*, id est lupus apparenter effectus, *dum parat flere*, id est transformationem suam deplangere : quia intellectus mansit in taliter transformatis; *ululat*, id est, vocem lupi emittit. Ille, id est alter illorum, factus *ut tigris Indica*, id est ex India, in qua sunt tigrides, bestiæ velocissimæ, *obambulat tecta*, id est, incedit in domo sub tectis, *mitis*, id est mansuetus, nulli nocens instar tigrium atrocium nocivarum.

Sed licet numen, id est deus quidam, *Arcadis alitis*, puta Mercurius, *miserans ducem*, videlicet ipsum Ulyssem, cui condoluit, *obsitum malis variis*, id est circumdatum diversis periculis maris ac deæ præfatæ, *solverit*, id est, ipsum Ulyssem liberaverit, *peste hospitis*, id est a pestifera transformatione deæ illius : quam scilicet transformationem dea illa, imo trufatrix, maga et pessima, intulit aliis, suis necromanticis artibus. Ut enim fingit Ovidius, ipse Mercurius sciens quid contigerit legatis Ulyssis, imo et quid ei etiam immineret, præstitit ei album florem, cujus virtute ab illa transformatione præservaretur. *Jam tamen remiges*, id est ductores remorum Ulyssis, *traxerant ore*, id est potaverant, *pocula* illa *mala* incantationibus mixta. *Jam sues*, id est socii Ulyssis transmutati in sues seu apros secundum exteriorem effigiem, *verterant*, id est immutaverant, *pabula Cerealia*, id est facta ex bladis seu frugibus, quorum dea dicitur Ceres, *glande*: id est, pro panibus, qui sunt cibi humani, utebantur glandibus, id est alimentis porcinis. Et in illis transmutatis *nihil manet* (id est, nil mansit) *integrum* in eorum corporibus, *voce* et *corpore perditis*, id est, uniuscujusque eorum « corpore » ac « voce » a naturali dispositione « perditis », id est mutatis. *Mens sola*, id est rationalis atque superior pars animæ, *stabilis*, id est, perseverans in eis, *gemit*, id est, cum gemitu dolet, *super monstra*, id est monstruosas mutationes, *quæ patitur*, id est, tunc patiebatur.

Consequenter dicit Philosophia, quod illa transformatio levior et tolerabilior est quam præfata transformatio hominum in bruta per vitia.

O(exclamatorie) manum nimium levem, id est, vim et operationem Circes deæ dico levem « nimium », id est valde, *nec gramina* illa dico fuisse *potentia*, id est magnæ virtutis, *quæ licet valeant vertere membra*, id est corporis partes mutare in effigiem bestialem, *non tamen valent corda* vertere, id est mutare et auferre!

Intus, id est in anima, *est hominum vigor*, id est potestas et usus rationis, *conditus arce abdita*, id est absconditus in sublimitate secreta : in qua arce imago summæ Trinitatis relucet. *Hæc venena*, id est vitia, *detrahunt potentius hominem sibi*, id est, auferunt ei usum expeditum rationis, et deprimunt eum sub se ipso, ac bestiis statuunt viliorem, *dira* : quia et mentem obdurant, et obicem ponunt gratiæ Dei, nec cedunt admonitionibus bonis instinctibusque salubribus Spiritus Sancti ac angelorum. *Quæ penitus meant*, id est, transeunt usque ad intimas ac supremas animæ vires, quas obscurant ac lædunt. Ideo subditur : *nec nocentia corpori*, id est, carnem non affligentia nec vulnerantia, *sæviunt*, id est, atrociter nocent ac lædunt, *vulnere mentis*, id est ipsam animam spiritualiter occidendo : quemadmodum in libro Sapientiæ habetur, Os quod mentitur, occidit animam;[^1] et rursus in libro eodem, Homo per malitiam occidit animam suam.[^2] Ideo loquitur Isaias : Hic est omnis fructus, ut auferatur peccatum.[^3] Ecclesia quoque cantat : Nulla nocebit adversitas, si nulla dominetur iniquitas. Verumtamen quædam peccata, ut gula, luxuria, etiam corpori nocent : non tamen tam evidenter et directe ut animæ ; nec corpus est proprie subjectum peccati formaliter sumpti. De talibus animabus in Ezechiele inducitur :[^4] Vivificabant animas quæ non vivunt.

At vero horum poeticorum dictorum sensui spirituali insistere reor indignum. Quoniam tamen Philosophia hæc narrat, breviter dico, quod per Ulyssem intelligi potest intellectus seu ratio, quæ est dux, princeps et oculus mentis, et alias dirigit vires. Familia vero hujus ducis sunt inferiorum virium actus, sensitivique appetitus affectiones et passiones. Per Circen designatur mundana prosperitas, quam multi appretiantur et quærunt ac amant ut deam. Hæc prosperitas rationi insidiatur, et eam quærit subvertere ac bestialem efficere, quemadmodum actus et motus sensualitatis sibi subjugare atque allicere nititur. Porro per « numen Arcadis alitis » intelligitur auxilium gratiæ Dei, ac divinus instinctus : qui florem album, id est puritatis amorem ac gratiæ lumen et sapientiæ claritatem, menti infundit, quibus contra fallacias prosperitatis terrenæ munitur, et famulos suos deceptos reducit. Cavendum est igitur ne mundanæ prosperitatis pocula infecta, id est oblectamenta vana, gustemus, nec hauriamus, ne in bruta vertamur, nec cum filio prodigo substantiam nostram cum scortis turpiter vivendo consumamus.[^5]

JOANNES. — Ingens mihi circa præhabita oritur admiratio, an arte magica possint humana corpora in lineamenta, organizationem et figuram brutalium corporum transmutari, an etiam vere sint gesta quæ hic recitantur in littera de hominibus transformatis.

DIONYSIUS. — Ista materia a doctoribus super secundum Sententiarum tractatur. Beatus quoque Augustinus libro de Civitate Dei multa super his scribit :[^6] Nulla (inquiens) ratione crediderim, operatione dæmonum aut aliqua nefaria arte hoc veraciter fieri posse. Hinc doctores Augustinum sequendo, affirmant, quod sicut dæmones assumere possunt corpora quædam aeria seu alia, et in illis apparere, loqui ac facere multa; sic corporalibus rebus superinducere, circumdare et quasi supervestire possunt corpora quædam consimilia corporibus bestiarum aliarumve rerum : sicque homines quibus permittuntur talia facere, videntur transformati in bruta. Ad hæc quoque et consimilia peragenda possunt applicare varia rerum semina, vires herbarum ac lapidum, et consimilia naturalia agentia abdita : per quæ omnia infelix gentilitas fuit variis modis decepta. Verum hæc omnia diaboli machinamenta et deorum dearumque figmenta, per beatissimos Christi Apostolos et eorum discipulos in toto orbe sunt patefacta, confutata, et pro maxima parte destructa, in tantum quod etiam quamplures necromantici magni, videntes artes et machinas suas virtute crucis Christi ac fidei totaliter superari, sunt ad Christum conversi.

Verum de his plurima introduci hic possent : de quibus pertranseo, quoniam super secundum Sententiarum de eis plenius scripsi, plenissime tamen in tractatu contra errores Valdensium et contra magicas artes. Quæ autem in textu dicuntur de transformatione hominum in corpora bestiarum, intelligenda sunt quantum ad exteriorem effigiem. Et potuit esse quod vere circumdata fuerunt hominibus illis corpora quædam brutalia : quod nihilo minus apparere sic posset per exteriorum sensuum illusionem, ac aliis modis, prout locis prætactis expressi. Denique recitat Augustinus qualiter his malis artibus imbutæ fuerunt mulieres quædam malignæ, quæ dabant hominibus caseum ad edendum : quo sumpto, videbantur versi in asinos, et onera eis superposita deferebant. Si autem illi de quibus in hoc metro narratur, amisissent realiter lineamenta et organa corporum humanorum, non potuissent in bestialibus illis corporibus uti ratione et intellectu vigere.

JOANNES. — Jam, si placet, responde quid de Nabuchodonosor rege Babylonis tenendum sit, an corpus ejus fuerit realiter in bestialem figurationem mutatum.

DIONYSIUS. — Josephus et alii quidam da præhabita dixit, vitiosos consistere impotentes : quomodo ergo nunc ait, vitia potentiora esse dea Circe et herbis ?

DIONYSIUS. — Metaphorice dicit hoc, et nomen potentiæ sumendo extense, ut in expositione prosæ illius expressi.[^7] Postremo, transformatio triplex est :[^8] una naturalis, ut quando ex uno elemento aliud generatur, ut vermis ex carne ; alia spiritualis, ut dum homo per vitia transmutatur in bestiam ; tertia magicalis, de qua hic facta est mentio.[^9]

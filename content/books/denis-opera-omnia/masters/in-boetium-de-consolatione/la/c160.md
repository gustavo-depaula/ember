# Articulus 13

ELUCIDATIO PROSÆ HUJUS QUINTÆ.

POSTQUAM Philosophia in præhabitis A prosis probavit quæ tanquam obscura ac prima facie quodammodo incredibilia introduxit, hic circa eadem facit Boetius quamdam repetitionem, et movet utilem atque difficilem quæstionem.

Sic  *ego video, inquam, id est, « ego » Boetius dico ac fateor, quod « video », id est intelligo, « sic », id est ex modo declarationum et probationum tuarum, quæ sit vel felicitas vel miseria in ipsis proborum atque improborum meritis constituta : id est, « quæ » beatitudo « constituta sit » et consistat « in meritis ipsis proborum », id est hominum virtuosorum, « vel » quæ « miseria » constituta sit in meritis, id est demeritis, « improborum ». Sed in hac ipsa fortuna populari non nihil boni malive inesse perpendo : id est, ego Boetius « perpendo », id est considero, « non nihil boni », id est aliquid bonitatis, prosperitatis seu felicitatis, « malive », id est aut mali, id est infelicitatis, « inesse », id est exsistere, « in hac ipsa fortuna populari », id est in eventibus istis fortuitis et casualibus, quos vulgares reputant eufortunia aut diffortunia. Quasi dicat : Quamvis tu Philosophia probaveris, divites et potentes qui prosperantur justosque persequuntur, esse impotentes ac miseros, ipsos quoque pauperes justos, quamvis ab illis oppressos, esse illis potentiores ac feliciores ; his consentire vix valeo, quoniam cerno in fortuna populari esse aliquid felicitatis aut calamitatis. Populares namque illos reputant eufortunatos, quibus arridet et affluit sæcularis potentia, opulentia, fama, etc. ; illos vero infortunatos, quibus eveniunt horum contraria. Nec in hoc videntur errare, sicut subjungitur.*

Hic

Neque enim sapientum quisquam, exsul, inops ignominiosusque esse malit : hoc est, « neque enim quisquam sapientum », id est, quia nec aliquis sapientum, « malit », id est, cupit aut vult, « esse exsul », id est in exsilium missus, « inops, ignominiosus », id est diffamatus, ignobilis ; potius quam pollens opibus, honore reverendus, potentia validus, in sua permanens urbe florere : id est, magis quam abundare divitiis, et esse validus potestate, ac « florere permanens in sua urbe », id est decorari multitudine propinquorum et amicorum, quemadmodum primo Machabæorum libro nuntius regis Antiochi dixit ad venerabilem Mathathiam :[^1] Princeps et clarissimus es in civitate hac, et ornatus filiis ac fratribus. Unde quum Eliseus propheta dixisset mulieri Sunamitidi, Vis ut loquar pro te ad regem aut principem? illa respondit : In medio populi mei habito. Tanquam diceret : Abundo consanguineis et amicis qui poterunt loqui pro me.

Sic enim clarius testatiusque sapientiæ tractatur officium : hoc est, « officium », id est præsidentia seu regimen, « sapientiæ », id est, quod per sapientiam dirigit et solis sapientibus merito competit, « tractatur », id est, exhibetur ac agitur, « sic », id est in ipsa opulentia, potestate, fama, honore, « clarius », id est eminentius, et « testatius », id est magis authentice ; quum in contingentes populos, regentium quodammodo beatitudo transfunditur : hoc est, dum « beatitudo regentium », id est prosperitas officiatorum ac præsidentium, « transfunditur quodammodo », id est divulgatur, « in populos contingentes », id est ad terras et gentes in circuitu com-

Quum præsertim carcer, lex, ceteraque legalium tormenta pœnarum, perniciosis potius civibus, propter quos etiam constituta sunt, debeantur: hoc est, « præsertim », id est potissime, « quum », id est ex quo, « carcer », id est incarceratio, « lex », supple punitiva, seu legis præscriptio, « ceteraque tormenta pœnarum legalium », id est instituta in legibus, « debeantur potius civibus perniciosis », id est nocivis et periculosis in communitate, « propter quos », id est propter quorum refrenationem et debitam punitionem, « constituta sunt etiam » illa tormenta: sicut testatur Apostolus, Justis non est lex posita, sed impiis et sceleratis;[^2] et rursus, Lex propter transgressiones posita est. Quod non est intelligendum de omni lege, sed de coercitiva atque prohibitiva.[^3] Quia, ut scribit Isidorus: Diversæ sunt proprietates operationesque legis; nec solum lex habet punire, sed et informare virtuosumque facere, et remunerare quæ justa sunt. Porro, ut recitat Augustinus libro de Civitate Dei ex Tullii dictis, novem erant genera tormentorum in legibus instituta, videlicet mors, exsilium, carcer, etc. Insuper, quid de hac replicatione Boetii sit tenendum, dictum est sæpe, præsertim in tertio libro, qualiter scilicet opulentia, potentia, dignitas, fama, ad felicitatem pertineant.[^4]

Consequenter Boetius quæstionem suam proponit: quæ tamen revera frequenter præhabita est et competenter soluta.[^5]

Cur hæc igitur versa vice mutentur: id est, miror et sciscitor quare « hæc » jam nominata « mutentur vice versa », id est mutatione contraria, ita quod ea quæ merito conveniunt bonis hominibus, ut præfata ad prosperitatem pertinentia, perveniunt et præstantur iniquis; scelerumque supplicia, ut sunt, exsilium, incarceratio, diffamia, servitus, bonos premant, sicut et me Boetium jam diu afflixerunt et oppresserunt; præmia virtutum mali rapiant, id est, cur injusti « rapiant », id est, consequantur, usurpent, possideant, « præmia virtutum », id est bona ad prosperitatem spectantia, quæ virtuosis debentur: hinc vehementer admiror. Istud ait Boetius in persona hominis imperfecti, sicut sæpissime dictum est. Quæque tam injustæ confusionis ratio videatur, ex te scire desidero:[^6] id est, o Philosophia, ex tua responsione discere cupio « quæ » tibi « videatur ratio confusionis tam injustæ », id est hujus deordinationis, quæ (ut apparet) contrariatur justitiæ.

Minus etenim mirarer, si misceri omnia fortuitis casibus crederem, id est, si putarem « omnia » ista temporalia « misceri », id est commixtim contingere, « casibus fortuitis », id est fortunalibus eventibus. Nunc stuporem meum Deus rector exaggerat: id est, « Deus » universorum provisor « exaggerat », id est, multiplicat et augmentat, « stuporem meum », id est vehementem admirationem meam, « nunc », quando sic credo providentiam Dei omnia usque ad minima inclusive, disponere. Sicque Deus per suos effectus fuit causa admirationis istius. Qui quum sæpe bonis jucunda, malis aspera, contraque bonis dura tribuat, malis optata concedat: id est, « qui » omnium rector « quum » concedat « sæpe bonis », id est justis, « jucunda », id est prospera et delectabilia, et « malis », id est impiis, « aspera », id est adversa, « contraque », id est econverso, « tribuat bonis » hominibus « dura », id est adversa, et « concedat malis optata », id est prospera concupita; nisi causa deprehendatur, id est, nisi horum ratio agnoscatur, quid est quod a fortuitis casibus differre videatur? id est, non videtur in aliquo differre ab eventibus fortunalibus.

Ad quod Philosophia: Nec mirum, inquit, si quid, ordinis ignorata ratione, temerarium confusumque credatur: id est, mirum non est, « si quid », id est aliquod opus, videatur « temerarium » et « confusum », quod tamen in veritate ordinatum et sapientiale consistit, « ratione ordinis », id est causa connexionis et modi seu ordinationis facti hujusmodi, « ignorata ». Admiratio namque consurgit, dum grande aut insolitum quid contingit cujus causa nescitur. Sed tu quamvis causam tantæ dispositionis ignores, id est, tu Boeti, qui docilis benevolusque consistis, licet nondum scias « causam », rationem et ordinem tam sublimis « dispositionis » provisoris altissimi; tamen, quoniam bonus mundum rector temperat, recte fieri cuncta ne dubites: id est, non ambigas omnia ista « recte » et ordinate accidere per comparationem ad providentiam Dei, « quoniam rector bonus », id est Deus essentialiter bonus, justus ac sapiens, « temperat », id est, curat, disponit et regit, « mundum », id est totum universum, specialiter rationales intellectualesque creaturas. De his jam tam frequenter præinductis pertranseo.[^7]

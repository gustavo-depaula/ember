# Articulus 27

### EXPLANATIO SEPTIMI HUJUS METRI.

HOC in metro Philosophia versibus canit quod in prosa præcedenti prosaice de vanitate gloriæ ac famæ mundanæ deprompsit.

Cujus contemptibilitatem ac modicitatem primo declarat ex parvitate habitabilis terræ respectu cœlestium corporum. Itaque ait: *Quicumque homo petit*, id est, cupit et accedit, *mente præcipiti*, id est corde inordinato, festinante, atque se ipsum præcipitante, *gloriam solam*, id est famam et reputationem humanam dumtaxat, *creditque summam* *, id est, quod ipsa sit gloria summa,* cernat*, id est inspiciat,* plagas ætheris*, id est regiones corporis cœlestis,* late patentes*, id est undique apparentes (juxta illud Psalmi, Ps. viii, 4. Quoniam videbo cœlos tuos),* situmque terrarum arctum*, id est strictum comparatione cœlestium corporum.* Pudebit nominis aucti*, id est, erubescet de sua fama vulgata: « nominis », inquam,* non valentis replere ambitum terræ brevem*, id est, non potentis devenire ad universos commorantes in terra, quæ respectu cœli tam parva est.*

Consequenter idem ostendit ex mortis consideratione. *O quid*, id est ad quid, *superbi gestiunt*, id est cupiunt, *frustra levare colla*, id est erecta cervice ex tumore incedere, *jugo mortali*, id est cum onere suæ mortalitatis, ita quod consideratio propriæ mortalitatis non humiliat eos ? juxta illud Job: Cucurrit impius adversus Deum erecto collo. Quocontra de se sanctus fatetur Hieronymus: Nihil a pueritia vitare sic studui, sicut erecta cervice incedere. Etenim in Ecclesiastico increata Sapientia protestatur: Superborum et sublimium colla propria virtute calcavi. Licet, Job xv, 26. Eccli. xxiv, 11.

id est quamvis, *fama means*, id est, diffundens se, *per populos remotos*, id est longe ab invicem distantes, *diffusa*, id est undique sparsa, *explicet*, id est, ad loquendum de se resolvat, *linguas, et domus magna fulgeat titulis claris*, id est appellationibus seu laudibus inclytis; *mors spernit gloriam altam*, id est, non parcit inhabitantibus domos tales, et ipsa mors *involvit*, id est, suæ corruptioni includit, *caput humile pariter et celsum*, id est parvos et magnos, *æquatque infima summis*, id est minimos et abjectissimos homines « summis », id est maximis hominibus, quantum ad hoc, quod indifferenter tollit universos ac singulos, sicut in versibus dicitur :

[æquam Mors fera, mors nequam, mors nulli parcit, et Cunctis dat legem, tollit cum paupere regem.

Hinc Philosophia per exempla probat hujus vitæ famæque mundanæ brevitatem et instabilitatem.

Ubi nunc ossa fidelis Fabricii manent ? quasi dicat: In tumulo jacent, aut alibi sunt dispersa. Fuit autem Fabricius consul Romanorum: qui vocatur « fidelis », non fide aut fidelitate catholicæ fidei, quia paganus fuit; sed fidelitate quæ est pars justitiæ naturalis politicæ, quoniam valde fidelis fuit reipublicæ. De quo in gestis Romanorum multa leguntur: quorum unum hoc est, quod dum quadam vice missus a Romanis, obsideret civitatem quamdam Pyrrhi regis, pædagogus nobilium puerorum civitatis illius callide pueros illos adduxit in manum Fabricii. Qui tantam infidelitatem pædagogi detestans puerisque compatiens, remisit per suos ministros, pueros ipsos suis parentibus una cum pædagogo. Quo cognito, Pyrrhus rex ait: Fabricius est qui difficilius posset a sua probitate deflecti, quam sol a suo motu impediri. *Quid Brutus, aut rigidus Cato?* id est, ubi et « quid » jam sunt viri isti Romani, olim præcipui, rectores boni communis? Brutus autem, expulso ab urbe Tarquinio Superbo, una cum Collatino factus est consul Romanorum. Cato demum « rigidus » appellatur, quoniam justus fuit et plurimum seriosus: qui et prudentissimus fuit, et milites suos, sobolem atque familiam rexit districte.

Fama eorum superstes, id est post eos manens, tenuis, id est permodica, quia paulatim est minorata, signat, id est notificat, pauculis litteris, id est per modica scripta, nomen inane, id est nomina eorum: quæ dicuntur inania, quoniam res seu personæ significatæ per ea, non subsistunt quantum ad corpora. *Sed quod novimus vocabula decora*, id est, quamvis sciamus illorum virorum nomina pulchra: quæ quamvis modo inania dicta sunt ob causam expressam, tamen nunc decora dicuntur, quia illustrium olim personarum sunt nomina; num, id est numquid, ideo datur, id est, conceditur nobis, scire consumptos, id est mortuos jamque in pulverem resolutos? Ergo, o viri præfati,acetis in sepulcris, quantum ad corpora (totum enim denominatur frequenter a parte), prorsus ignorabiles, id est omnino ignoti faciali atque sensibili cognitione; nec fama efficit vos notos, id est, ex fama vestra non potestis distincte ac perfecte cognosci.

Quod si putatis vitam vestram longius trahi, id est prolongari, aura, id est rumore, nominis mortalis, id est famæ transitoriæ; tamen quum dies sera, id est ultima, seu tarde veniens, rapiet, id est auferet, vobis etiam hoc, id est hanc famam, quæ tandem oblivione delebitur, jam manet, id est exspectat, vos mors secunda, id est damnationis miseria, quæ est privatio vitæ gloriæ. Quæ mors pro peccatis infligitur, etiam secundum veram philosophiam, et ut Pythagoras, Socrates, Plato dixerunt: quamvis mortem illam non putaverint esse æternam. Vel « mors secunda » vocatur oblivio, hoc est deletio a memoria, qua mortui in memoriis hominum aliqualiter vivunt.

Porro Pythagoras animas iniquorum asseruit descendere in infernum: quem etiam esse perhibuit in medio terræ. Plato quoque in Phædone affirmat: Procul valde sub terra, altissimum (id est profundissimum) est barathrum. Et rursus ibidem: B Quicumque (ait) non lustratus nec expiatus in Avernum abierit, in cœno jacebit. Verumtamen isti dixerunt animas post certa tempora liberari, et rursus incorporari. Avicenna vero et Algazel, animas semel separatas amplius incorporari negantes, dixerunt pœnas illas finire post competentem purgationem, quoniam nullum violentum est perpetuum; animasque purgatas intelligentiæ infimæ copulari. Quod tamen non solum est contra evangelicam legem, sed et contra Alcoranum seu legem Mahometi, in qua pœna inferni prædicatur æterna.

Præterea, sicut nos Christiani neminem dicimus veraciter religiosum, imo nec christianum, quantumlibet doctum, nisi simul sit etiam virtuosus; sic philosophi neminem reputaverunt verum philosophum neque philosophi nomine dignum, nisi virtutibus quoque intentum. Et sicut asserimus, ad vitandum vitia virtutesque acquirendas præcipue suffragari assiduam mortis memoriam, ita et ipsi. Unde in D Phædone asseruit Plato: Revera philosophantes, morti se præparant; et circa concupiscentias non obstupescere, solis philosophis competit: idcirco si videris aliquem moleste ferre quum debeat mori, nullo modo fuit philosophus. Et rursus: Meditatio philosophorum est separatio et solutio animæ a corpore. Insuper de his Seneca dixit quamplura: Philosophia, inquiens, facere docet, non dicere tantum; et hoc exigit ut ad legem suam (id est juxta philosophiæ institutionem) quisque vivat, ne sermo vitæ dissentiat. Ante omnia vide quam juveni. Hinc hortatur S. Bernardus :[^1] In omnibus tuis memorare novissima tua; mortis horrorem, metuendum judicii divini discrimen, ardentis gehennæ metum nunquam patiaris ab oculis tuæ mentis recedere : nihil sic revocat a peccatis, ut assidua et intenta meditatio mortis.

[^1]: Eccl. vii, 40.

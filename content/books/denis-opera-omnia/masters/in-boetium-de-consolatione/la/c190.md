# Articulus 9

EXPOSITIO METRI HUJUS QUARTI.

POSTQUAM in prosa præhabita docuit et probavit Philosophia, quod cognitio rerum est secundum modum et naturam cognoscentium, non cognitorum, nunc in quarto hoc metro tangit quomodo quidam philosophi dixerunt oppositum.

Porticus, id est locus talis Atheniensis, attulit quondam, id est, olim in se continebat et exhibebat, senes nimium obscuros, id est quosdam studentes antiquos valde adhuc imperitos, in quibus sapientia exstitit parva, qui credant sensus, id est sensibilium formas seu sensationes, et imagines, id est similitudines rerum imaginarias seu ipsas imaginationes, e corporibus extimis, id est ab exterioribus, sensibilibus, corporeis objectis, imprimi mentibus, id est intellectibus nostris (unde apparet quod isti fuerint de crassioribus philosophis qui inter sensum et intellectum non distinxerunt), ut quondam mos est, id est, sicut aliquando est consuetudo, figere, id est inscribere, litteras pressas, id est firmiter impressas, stilo celeri, id est graphio velociter exaranti, A *æquore paginæ*, id est in planitie tabulæ seu papyri, quæ pagina *nullas habeat notas*, id est, nullas inscriptiones habuerit ante, seu nullas figuras aut litteras.

Consequenter Philosophia opinionem hanc improbat.

Sed, o philosophi, *si mens*, id est intellectus humanus, *nihil explicat*, id est, nihil agit neque prosequitur, *vigens pro priis motibus*, id est, fortiter utens actibus et conatibus virium propriarum; *sed jacet*, id est, si dejecta est, *patiens tantum*, id est, solum passive se habens recipiendo impressiones formarum a rebus, *subdita notis corporum*, id est figuris et similitudinibus corporalium objectorum in eam agentium, et ipsa mens *reddit*, id est, repræsentat et exhibet, *imagines rerum*, id est species cognoscibiles « rerum » sensibilium, *cassas*, id est inanes, quæ in veritate non valent repræsentare essentias rerum abstracte communiterque acceptas, *in speculi vicem*, id est instar speculi, in quo apparet similitudo rei, non veritas. Hinc subditur :

Unde hæc notio cernens omnia, id est, « unde » et a quo ac qualiter « hæc notio », id est cognitio ista universalis, « cernens » ac intuens cuncta, utpote genera, species ac individua, *viget sic animis*, id est, vigorose ac valide relucet ac inexistit hominum mentibus? *Quæ vis*, id est quæ potentia animæ, *prospicit*, id est, desuper pensat atque intelligit, *singula*, id est, omnia etiam invisibilia, immaterialia, quorum similitudines non recipit directe et immediate a corporalibus rebus? *Aut quæ vis dividit cognita?* sicut ens dividitur in ens creatum et increatum, in substantiam et accidens, in ens absolutum et relativum, et sicut dividitur genus in species : quæ divisio fieri nequit per sensibiles formas et species. *Quæ etiam vis recolligit diversa* *, reducendo species multas ad unam, et plura ad unum, multaque individua ad speciem unam, ad quæ requiruntur rationes valde generales, et species abstractæ ac multum communes?[^1] Et quæ vis* legens*, id est, carpens ac eligens,* iter alternum*, id est modum procedendi et investigandi jam istum, jam illum,* nunc inserit caput *mentis, id est, verticem suæ virtutis ac considerationis infigit,* summis*, id est primæ causæ ac substantiis separatis,* nunc descendit ad infima*, id est ad considerandum temporalia et terrena, et ad providendum necessariis vitæ ac fragili carni,* tum sese referens sibi*, id est, reflectens se super se, et comparans se sibi ac propriam scrutans naturam per actus suos, sicque se immaterialem et immortalem esse cognoscens,* redarguit falsa*, id est, reprobat mendacia et errores,* veris*, id est per media vera et rationabilia argumenta?[^2]*

Hæc, id est vis ista mentis, effectiva et elicitiva actuum horum et harum abstractionum et speculationum istarum, quæ est vis intellectiva, non sensitiva, *est causa magis efficiens, longe potentior*, id est et efficacior et nobilior, *quam vis illa quæ modo* (id est instar) *materiæ patitur*, id est, passive et materialiter recipit, *notas*, id est figuras, *impressas*, sicut expositum est : quæ est vis organica.

Verum, sicut patebit, Boetius rursus videtur hic loqui juxta doctrinam Platonicorum, quod scilicet intellectus non est vis passiva, nec species rerum sumens ab extra, sed habens eas sibi inditas ab exordio ac innatas. Ideo subditur :

Præcedit tamen excitans, etc. Hic exponit Boetius mentis suæ intentionem, dicendo quod quamvis mens intra se habet, id est continet, species rerum, nihilo minus per exteriora objecta excitatur ad utendum actualiter hujusmodi speciebus. Itaque ait : *Tamen*, id est, quamvis mens actu intelligat sua vi nobiliori atque per similitudines rerum impressas actualiter et distincte, secundum Platonem, attamen *passio*, id est immutatio facta in sensu ab exteriori objecto, *in corpore vivo*, id est in corpore hominis adhuc vivente, excitans ac movens vires animi, id est interiores potentias intellectuales, præcedit cognitionem intellectualem, illam videlicet qua anima experitur, percipit et advertit se intelligere : non tamen necessario præcedit intelligere abditum quod est in nobis. Quod dico exponendo mentem et modum loquendi Platonis, quemadmodum B. Augustinus in variis libris, potissime libro de Trinitate, sæpissime tangit ac sequitur, quemadmodum et Boetius in hoc libro totali frequenter : cujus tamen dicta retorqueri possunt ad primum intellectum, ut species dicantur nobis innatæ quantum ad habitus cognoscitivos primorum principiorum in speculativis et practicis, et quantum ad aptitudinem inchoationemque aliquam, prout etiam potentia appellatur quædam inchoatio sui actus.

Itaque passio talis præcedit, quum vel lux exterior ferit, id est immutat, oculos, vel vox instrepit, id est insonat, auribus. Tum vigor mentis, id est vis intellectiva, excitus, id est excitatus per tale objectum, vocans species quas tenet intus ad motus similes, id est ad conceptiones et apprehensiones rerum quæ sensibus apprehenduntur, applicat species seu similitudines illas notis exteris, id est exterioribus signis, figuris et formis, applicatione intellectuali, considerando interiores species ut similitudines rerum quarum formas et notas conspicit foris, et mens miscet imagines, id est exteriores similitudines, formis introrsum reconditis, id est speciebus intelligibilibus in intellectu latentibus, considerando et comparando eas ad in- B vicem.

Quamvis autem secundum Aristotelem, intelligere (quemadmodum et sentire) sit quoddam pati, in quantum fit per specierum receptionem; hoc tamen accipiendum est de passione communiter tantum sumpta et perfectiva, non corruptiva. Intelectus quoque possibilis, quamvis sit potentia quodammodo passiva, in quantum recipit similitudines rerum, nihilo minus per similitudines jam receptas vere agit, active intelligendo, discernendo, inqune- C do et discurrendo.

# Articulus 24

ELUCIDATIO PROSÆ HUJUS NONÆ.

POSTQUAM Philosophia jam per multas prosas ac metra ostendit in quibus non consistat vera felicitas, nunc declarare aggreditur in quibus sit ponenda, et qualiter exquirenda.

Hactenus mendacis formam felicitatis ostendisse suffecerit: id est, satis sit « ostendisse », id est, quod ostendi et descripsi, hucusque « formam », id est rationem et speciem, « felicitatis mendacis », id est apparentis, non exsistentis: quam definivi quod sit prosperitas fallax. Quam *si perspicaciter intuearis*, id est, acute consideres, *ordo est*, id est rectus modus procedendi, *deinceps quæ sit vera* beatitudo *monstrare*, id est, docere quæ sit vera felicitas.[^1]

Ad hoc respondet Boetius: *Atqui video*, inquam, id est, ego Boetius dico, « Atqui », id est certe, « video », id est intelligo, *nec opibus sufficientiam, nec regnis potentiam, nec reverentiam dignitatibus, nec celebritatem gloria, nec lætitiam voluptatibus posse contingere*: id est, « nec sufficientiam » veram, quæ ad beatitudinem sufficiat, « opibus posse contingere », id est, non posse alicui provenire « opibus », id est per terrenas divitias, quum et divitibus multa desint; « nec potentiam » sufficientem posse contingere alicui « regnis », id est per principatus quoscumque, quum et reges indigeant subditis, sicut econtra; « nec reverentiam », id est sufficientem honorem, « dignitatibus », id est per dignitates; « nec celebritatem », id est claritatem nominis sufficientem, « gloria », id est ex hominum fama, quæ sæpe decipitur ac cito mutatur; « nec lætitiam » sufficientem, id est indesinentem, salubrem, posse accidere homini « voluptatibus », id est per oblectamenta carnalia : sicut istud jam ante diffuse ac multipliciter est probatum.[^2]

Ad hoc Philosophia subjungit: *An etiam causas cur id ita sit, deprehendisti?* id est, quæro « an etiam deprehendisti », id est considerasti, « causas » propter quas « id ita sit ». Ad quod Boetius : *Tenui quidem veluti rimula mihi videor intueri* : hoc est: « videor mihi intueri », id est, mihi ipsi apparet quod intuear causas illas, « veluti rimula tenui », id est per obscurum adspectum, sicut quod per parvam videtur fissuram; *sed ex te cognoscere malim apertius*, hoc est, « malim », id est, potius velim, « cognoscere apertius ex te », id est ex tua informatione, has causas.

Ad quod Philosophia : *Atqui*, id est pro certo, *promptissima ratio est*, id est, ratio paratissima assignari potest ad hoc, puta hæc: *quod enim simplex est indivisumque natura*, id est, « quod » ex sua « natura est simplex », non habens in se diversitatem partium aut aliarum realitatum, utputa veram felicitatem seu summum bonum, *id error humanus*, id est homo errans, *separat*, id est, divisim intelligit, *et a vero atque perfecto, ad falsum imperfectumque traducit* : id est, rationem et proprietatem summi boni adscribit rebus creatis, in se vanis ac diminutis, et uni hujusmodi bono imperfecto adscribit hanc eminentiam, alteri aliam; sicque in diversis beatitudinem quærit, quam non nisi in uno, summo, simplicissimo quæreret bono, in quo quinque prædicta, imo omnia bona, pulchra ac desiderabilia, supereminentissime, indivisim, simplicissime continentur. Quod consequenter probat Philosophia : et primo, quod in ipso sit summa et perfecta potestas.

*An tu arbitraris, quod nihilo indigeat*, id est, quod non indigeat aliqua re, *egere potentia?* — *Minime, inquam*, id est, ego

A Boetius dico, quod minime puto hoc : quia sic imbecille esset, nec posset suis adversariis prævalere. Quocontra ait per Jeremiam: Quis similis mei? Et quis sustinebit me? Et quis est iste pastor qui resistat vultui meo?[^3] Ad hæc Philosophia : *Recte tu quidem judicasti* : *nam si quid est quod in ulla re imbecillioris valentiæ sit*, id est debilioris potentiæ, *in hac præsidio necesse est egeat alieno* : hoc est, « necesse est », id est, necessario sequitur, quod « egeat præsidio » (id est auxilio) « alieno in hac », id est in ista sua imbecillitate. — *Ita est, inquam* ego Boetius.

Ex quo Philosophia concludit : *Igitur sufficientiæ potentiæque una est eademque natura*, id est, realiter idem sunt et inseparabilia, summa sufficientia et summa potentia, nec unum sine alio potest esse perfectum. Respondet Boetius : *Sic videtur*, id est, clare conspicio quod sit ita, quum istud argumentum sit demonstrativum.

Consequenter probat, quod hoc ipsum sit honorabile et reverentia omni dignissimum. *Quod vero hujusmodi sit, spernendumne esse censes*, id est, censesne et utrum judicas esse conveniens, quod hujuscemodi ens sit spernendum, *an contra*, id est, utrum potius econtrario judicas, quod sit *rerum omnium veneratione dignissimum*, utpote excellentissimum, sapientissimum, sanctissimum? — *At hoc, inquam, ne dubitari quidem potest*, id est, istud tam certum est, quod nemo sanæ mentis possit inde ambigere : intellectus namque evidentia et efficacia demonstrationis, sicut et primorum principiorum, compellitur ad consensum.

Ad hæc Philosophia : *Addamus igitur sufficientiæ potentiæque reverentiam*, id est honorabilitatem, *ut hæc tria unum esse judicemus*, videlicet ens summe sufficiens, summe potens et summe honorabile, in quo etiam sufficientia, potentia, honorabilitas realiter idem sunt, utputa divina essentia, et sola ratione distinctæ sunt : ita ut divina essentia in quantum absolute perfecta, dicatur sufficientia, in quantum principium producendi et agendi in alia, dicatur activa potentia, atque ut summa majestas in se continens omnis honorificentiæ ac venerationis et venerabilitatis causam, radicem et rationem, dicatur primum et summum honorabile. 1 Reg. u, 30. Quod ait primo Regum : Quicumque glorificaverit me, glorificabo eum ; qui autem contemnunt me, erunt ignobiles. Denique, si honorandi sunt parentes, quanto magis Pater iste cœlestis, ex quo (teste Apostolo) omnis paternitas in cœlo et in terra nominatur ac derivatur?[^4] De quo denuo loquitur ad Hebræos : Patres carnis nostræ eruditorres habuimus, et reverebamur eos : non multo magis obtemperabimus Patri spirituum, et vivemus?[^5] Hinc quoque Aristoteles duodecimo Primæ philosophiæ fatetur, quod Deus est honoratissimus intellectus. — Addamus, id est, ego Boetius dico, Placet ut addamus reverentiam sufficientiæ atque potentiæ, *siquidem vera volumus confiteri*, id est, pro certo « volumus confiteri » quod verum est, nec veritati repugnare : quod prosperum successum non sortitur, juxta illud beati Job, Quis restitit ei, et habuit pacem? — Quid igitur? inquit : id est, Philosophia ait, Quid addemus? nisi quod subditur : *Obscurumne hoc atque ignobile censes esse*, id est, an judicas hoc summum bonum esse non celebre, neque famosum, nec clarum, *an omni celebritate clarissimum? Considera vero ne*, id est numquid, seu ut non, hoc ens *quod nihilo indigere, quod potentissimum, quod honore dignissimum esse concessum est, egere claritudine videatur*, id est, an possit celebri nomine et fama præclara carere, *quam sibi præstare*, id est facere, *non possit, atque ob id aliqua ex parte videatur abjectius*. Ad quod Boetius : *Non possum, inquam*, id est, de hoc aliud dicere nequeo, *quin hoc uti est, ita etiam celeberrimum esse confitear*, id est, « quin » fatear et protester « hoc » bonum « ita etiam esse celeberrimum », id est famosissimum, « uti est », id est, sicut revera est incomparabiliter celebre, quum in omni perfectione sit infinitæ eminentiæ. Unde et Isaac Israelita philosophus, in principio libri Definitionum effatur : Fama Dei sublimis est. Hanc famam præstat et facit sibi Omnipotens, manifestando hominibus excellentiam suam, atque per opera sapientiæ, misericordiæ ac justitiæ suæ, quemadmodum in Exodo loquitur Pharaoni : Idcirco posui te, ut ostenderem in te fortitudinem meam, et narretur nomen meum in omni terra.[^6] Et enim tanta est fama Dei, quod excellentiam ejus omnis creatura miratur, nec exprimere valet nec comprehendere eam.

Ex quibus infert Philosophia : *Consequens igitur est, ut claritudinem superioribus tribus nihil differre fateamur*, id est, ut recognoscamus claritatem et famabilitatem summi boni non differre ab opulentia, omnipotentia et honorabilitate ipsius. — *Consequitur, inquam*, id est, dico ego Boetius hoc consequi.

Denique in hoc mundo famosi sunt, qui in una quacumque virtute fuerunt eximii aut in paucis, et hoc tamen finite, ut Samson in fortitudine, Absalon in pulchritudine, Salomon in sapientia, David in victoriis, et ita in consimilibus, ut in sanctitate, in miraculis, in prælaturis et principatibus : quanto magis superbeatissimus Deus infinitæ famositatis et incomparabilis celebritatis, claritate est universis et singulis præferendus? De quo aptissime dixit electus David : Quis sicut Dominus Deus noster, qui in altis habitat, et humilia respicit in cœlo et in terra? Unde et in Job habetur : Perditio et mors dixerunt, Auribus nostris audivimus famam ejus.

Ad hæc Boetius: Sed unde huic (inquam) tali mæror ullus obrepat, ne cogitare quidem possum, id est, fingere nequeo « unde » et ex qua causa possit « ullus mæror » obrepere, id est ulla tristitia accedere. Quare plenum esse lætitiæ, si quidem superiora manebunt, necesse est confiteri: id est, fateri oportet ipsum « esse plenum lætitiæ », imo essentialiter esse lætum, ac superinfinitam in se subsistentem lætitiam (cui psallit Propheta, Torrente voluptatis tuæ potabis eos), « si superiora », id est superius dicta, « manebunt », id est, stabunt in veritate.[^7] Nec his obviat, quod Deus in Scripturis dicitur pœnitere, dolere, tristari, affligi, irasci, ut dum dicitur in Genesi: Videns Deus quod multa malitia hominum esset in terra, et cuncta cogitatio cordis intenta esset ad malum omni tempore, pœnituit eum quod fecisset hominem, et dolore cordis tactus intrinsecus, Delebo, inquit, hominem a facie terræ.[^8][^9] Et per Isaiam ait: Præbuisti mihi laborem in iniquitatibus tuis. Et multa consimilia dicuntur in Scripturis: quæ omnia intelligenda sunt per similitudinem effectus, non per veritatem turbationis, mutationis aut passionis in ipso, qui per Malachiam protestatur:[^10] Ego Dominus, et non mutor; et per Jeremiam: Numquid me ad iracundiam provocant?[^11] dicit Dominus. Nonne semetipsos in confusionem vultus sui? Et in libro Sapientiæ dicitur: Tu autem dominator virtutis, cum tranquillitate judicas, et cum magna reverentia disponis nos.

Deinceps ostendit Philosophia, hæc omnia unum esse in Deo. Atqui, id est certe, illud quoque per eadem necessarium est, id est, per præhabita etiam istud necessario sequitur, sufficientiæ, potentiæ, claritudinis, reverentiæ, jucunditatis nomina quidem esse diversa, id est, quod quinque ista per distincta nomina designantur: quia ut tactum est, differunt ratione, sicut et alia varia attributa in Deo, ut sunt, sapientia, justitia, veritas, pietas; nullo vero modo discrepare substantiam, id est, essentiam significatam per ea nequaquam differre, quum sint unum simplicissimum esse Dei.

Respondet Boetius: Necesse est, inquam, sic esse. Nempe, quum Deus sublimis et gloriosus, sit ens in se omnino perfectum, non potest esse in eo compositio aut diversitas aut distinctio ulla ex natura rei, sed identitas pura ac infinita. Propter quod in libro de Causis asseritur, quod non est in prima causa distinctio ulla modorum. Omnis quippe compositio, diversitas, distinctio ex natura rei, signum est imperfectionis ac indigentiæ: quia si res totam suam perfectionem haberet in uno illorum, aliis non egeret, sed ea secluderet, quum teste Philosopho, non sit ponenda pluralitas sine necessitate. Hinc merito refutatur misera illa opinio quæ in divinis inter attributa distinctionem ponit formalem ex rei natura, quæ sit quædam non identitas: quod prorsus falsissimum est, nec solum contra Thomam, Albertum, Henricum, sed etiam contra Alexandrum, Bonaventuram, Richardum, etc. Hinc juxta Philosophum, Deus est purus actus.[^12] Et sicut per Moysen dixit, ipse est ipsum supersimplicissimum esse. Subjungit Philosophia: *Hoc igitur quod est unum simplexque natura*, id est ex sua « natura », imo et realiter est simplex essentia et quidditas sua, *pravitas humana dispertit*, id est, in multa divisit, et pluribus male attribuit: non quod aliquis homo tam pravus exstiterit, quod veram et incommutabilem deitatem adscripserit creaturis aut rebus diversis substantialiter differentibus; sed quod felicitatem, quæ in summo et solo Deo est vere et objective, quidam in rebus posuerunt creatis, et juxta Apostolum ad Romanos, servierunt et inhæserunt creaturis magis quam Creatori.[^14] *Et dum rei quæ partibus caret, partem conatur adipisci*, id est, « dum » pravitas humana, utputa pravus homo, « conatur adipisci partem » beatitudinis, « quæ partibus caret », quoniam simplex est, *nec portionem, quæ nulla est, nec ipsam, quam minime affectat, assequitur*: id est, non obtinet nec acquirit partem beatitudinis, quia non habet partem; nec obtinet totam, quia nec appetit veram beatitudinem integre et sincere, sed potius vanam, in divitiis, honoribus, aliisque præfatis.

Denique istud de increata beatitudine objectali potissime verum est. Beatitudo autem creata, quæ est status omnium bonorum aggregatione perfectus, non est penitus simplex, pertinentque ad eam non solum contemplatio, sed dilectio quoque ac delectatio: quamvis secundum Augustinum et Thomam et alios quosdam, essentialiter in actu intellectus ponatur, quia[^15]

Deinde Boetius postulat hæc clarius sibi exponi. *Quonam (inquam) modo?* id est, qualiter verum est, o Philosophia, quod dicis, hominem pravum non adipisci felicitatem nec partem ejus?

— *Qui divitias, inquit, petit penuriæ fuga*, id est, Philosophia « inquit, Qui petit », id est, quærit seu appetit, « divitias fuga », id est propter fugam, « penuriæ », *de potentia nihil laborat*, id est, non « laborat de potentia », id est pro potestate adipiscenda: nisi forsan quærat divitias ut per eas acquirat potentiam; sicque potius esset superbus seu ambitiosus, quam avarus. *Vilis obscurusque esse mavult*, id est, magis vult haberi sine reverentia tanquam ignobilis, quam pecunias perdere, in quibus sibi finem constituit. *Multas etiam sibi naturales quoque subtrahit voluptates* in esculentis et poculentis atque venereis et ornamentis, *ne pecuniam quam paravit, amittat*. Ista facilia sunt. *Sed hoc modo ne* (id est nec) *sufficientia quidem contingit ei, quem valentia* (id est potentia) *deserit*: id est, imbecilli non adest sufficientia, quum sanitas desit ei (quæ præfertur pecuniæ, juxta illud Ecclesiastici, Melius est corpus validum, quam census immensus);[^16] *quem molestia pungit, quem vilitas abjicit*, id est, quem ignobilitas reddit abjectum, *quem recondit obscuritas*, id est, qui ignotus est ex famæ carentia.

Consequenter idem ostendit de quærente finaliter potestatem. *Qui vero solum posse desiderat*, id est, principaliter quærit potentiam, *profligat opes*, id est, divitias prodigaliter consumit, ut adsistentes et fautores acquirat, non attendens quod in Ecclesiastico legitur, Qui potestatem sibi assumit injuste, odietur;[^17] *despicit voluptates*, ne propter eas vilescat: unde Antigonus dixit ad Alexandrum, Indignus es imperare propter juventutem et voluptates; *honoremque* (id est promotionem seu dignitatem) *potentia carentem, gloriam quoque*, id est famam celebrem, *nihil pendit*. Quidquid enim quis habet, parum sibi videtur, quamdiu non obtinet quod præ ceteris principaliter cupit: cujus dilatione atque carentia cruciatur, ut in Proverbiis Salomon ait: Spes quæ differtur, affligit animam;[^18] lignum vitæ, considerium veniens. *Sed huic quoque potentiam appetenti, quam multa deficiant, vides. Fit enim ut aliquando necessariis egeat*, dum opes suas dilapidaverit, *ut anxietatibus mordeatur*, ne lædatur ab his quibus dum potens fuerat nocuit; *quumque hæc depellere nequeat* (quia jam caret divitiis: unde nec habet auxilia), *etiam id quod maxime petebat*, id est, præcipue affectavit, videlicet *potens esse, desistit*.

Consequenter idem probat de aliis. *Similiter ratiocinari de honoribus, gloria, voluptatibus licet*: id est, licitum expediensque consistit « ratiocinari », id est discurrere et probare, « de honoribus, gloria » (id est fama), « voluptatibus », quod in eis non consistat felicitas. *Nam quum unumquodque horum idem quod cetera sit, quisquis horum aliquid sine ceteris petit, ne illud quidem quod desiderat, apprehendit*. Certum est quod voluptas in nobis non sit idem quod fama aut honor, nec divitiæ idem sunt quod potentia; unum quoque istorum sine altero haberi potest: quomodo ergo vera sunt hæc? Contra autem, quamvis in Deo sint idem, non tamen in creaturis: non ergo sunt idem realiter, sed consummative, ita quod unum non videtur sine alio perfecte haberi. Ideo qui unum sine altero adipisci conatur, nullum acquirit perfecte, videlicet prout ad beatitudinem pertinet.

Circa quod sciscitatur objicitque Boetius: *Quid igitur, inquam, si quis cuncta simul cupiat adipisci? Summam quidem ille beatitudinis velit*: id est, si quis conetur omnia illa quinque pariter obtinere, quæro an « ille velit summam beatitudinis », id est plenitudinem veræ felicitatis. Ad quod respondet Philosophia, quod non. *Sed num*, id est numquid, *in his eam reperiet*, id est in his quinque, *quæ demonstravimus, id quod pollicentur non posse conferre*, hoc est veram felicitatem? sicut jam supra sæpissime dictum est et probatum.[^19] — *Minime, inquam*. — *In his igitur quæ singula quæque expetendorum præstare creduntur*, id est, « in his » quinque rebus terrenis, « quæ singula quæque » illorum « expetendorum », id est, quinque illorum quæ mundanis hominibus multum expetenda videntur, « præstare creduntur », *beatitudo nullo modo investiganda est*, id est quærenda. — *Fateor, inquam*, ego Boetius; *et hoc nihil verius dici potest* de isto puncto.

Ex quibus Philosophia concludit et exhortatur: *Habes igitur* (tu Boeti), *inquit, et formam*, id est modum et speciem, *falsæ felicitatis, et causas*, sicut expositum est. *Deflecte nunc in adversum mentis intuitum*, id est, considerationem dirige ad oppositum felicitatis fallacis, hoc est ad cœlestia et divina. *Ibi enim veram, quam promisimus, statim videbis*, id est, cognosces in illis « veram » consistere felicitatem, « quam promisimus » te docere.

— *Atqui* (id est certe) *hæc, inquam, vel cæco perspicua est*, id est, ego Boetius consentio, quod vera felicitas tam clare nota est ut a cæco, id est parum intelligente, valeat sciri quantum ad aliquam ejus descriptionem; *eamque tu paulo ante monstrasti*, id est notificasti, *dum falsæ causas aperire conabaris*, id est, quum studuisti exprimere « causas falsæ » felicitatis, quæ ponitur in rebus terrenis sæpe expressis: in quibus jam et sæpius ante ostensum est beatitudinem esse non posse, quia sufficientiam veram non præstant, nec mentem quietant, nec mala felicitati contraria excludunt.[^20] Unde constat in illis beatitudinem esse ponendam, quæ mentem quietare contentareque valent, sufficientiam certam et tutam præstando. Unum namque oppositorum cognoscitur per aliud, quum oppositas habeant rationes: nam et opposita juxta se constituta et mutuo comparata, lucidius patent; et juxta Philosophum, sicut unus et idem sensus est oppositorum, ita et eadem scientia contrariorum.

Hinc quasi expositorie subditur: *Nam (ni fallor) ea vera est et perfecta felicitas, quæ sufficientem, potentem, reverendum, celebrem lætumque perficiat.*

Quod qualiter intelligendum sit, ex præhabitis clarum est, utputa: de sufficientia omnem indigentiam ac penuriam excludente; de potentia quoque cui nulla injuria, nulla læsio possit inferri, nullusque hostis violentiam molestiamve inferre; atque de reverentia illa cœlesti de qua in Evangelio ait Salvator, Si quis mihi ministraverit, honorificabit eum Pater meus qui est in cœlis;[^21] et de qua ipsemet in Apocalypsi protestatur: Qui vicerit, dabo ei sedere mecum in throno meo, sicut et ego vici, et sedi cum Patre meo in throno ejus.[^22]

Et item de celebritate de qua in Ecclesiastico dicitur: Sapientiam Sanctorum narrant populi, et laudem eorum nuntiat Ecclesia;[^23] et iterum: Non recedet memoria ejus, et nomen ejus requiretur a generatione in generationem.[^24] Hæc est fama justorum: qui teste Apostolo, sunt bonus odor Christi in omni loco; qui adhuc viventes in corpore, non solum præsentes ac intuentes, sed et longe absentes ac audientes ædificant, et demum post mortem, per exempla et memoriam, per scripta et historiam viatores ædificare non cessant. Quod totum est præcipua gratia superpiissimi Dei, qui ministerio et cooperatione unius hominis dignatur aliorum operari salutem. Unde ait Richardus de

A S. Victore: Nescio an majus gratiæ donum possit a Deo homini conferri, quam ut per ejus obsequium alii convertantur ad Deum. Imo et S. Dionysius contestatur: Omnium divinorum divinissimum est Deo cooperari in reductione animarum ad ipsum. Hæc est fama salubris, optanda, ad beatitudinem aliqualiter pertinens. De qua Unigenitus Dei Patris promisit beatissimo patri Antonio: Quia viriliter restitisti, faciam te in toto mundo nominari. De qua et in Proverbiis Salomon est locutus: Memoria justi cum laudibus;[^25] nomen autem impiorum putrescet.

Et insuper de lætitia de qua in Isaia habetur: Lætitia sempiterna super capita eorum, gaudium et lætitiam tenebunt, et fugiet dolor et gemitus.[^26] Hæc est purissima, divina et gloriosa voluptas electorum cœlesti in patria, de qua idem flos Prophetarum Isaias sanctus fatetur:[^27] Gaudium et lætitia invenietur in ea, gratiarum actio et vox laudis. De quibus et per Malachiam Deus testatur:[^28] Orietur vohis Sol justitiæ, et salietis quasi vituli de armento.

Atque ut me interius animadvertisse cognoscas, id est, diligenter attendisse certus sis, dico: quæ unum horum, quoniam idem cuncta sunt, veraciter præstare potest, hanc esse plenam beatitudinem, sine ambiguitate cognosco: id est, indubitanter scio « beatitudinem plenam hanc esse quæ unum horum veraciter præstare potest ». Imo et alia bona præstat in veræ beatitudinis patria: præstat (inquam) directe, vel concomitanter. Si enim unum horum omnia illa omnifarie seu omnimodo conferret, alia quatuor superflua essent, nec ad felicitatem exigerentur. « Quoniam idem cuncta sunt », id est, quia hæc quinque « idem sunt », non essentialiter, sed consummative, sicut expositum est, nec separabilia sunt, prout hoc loco sumuntur.

II Cor. ii, 15, 14. dem hoc (inquit) adjeceris : id est, Philosophia « inquit : O alumne », id est, Boeti a me spiritualiter enutrite moribus et doctrinis, dico « te felicem » felicitate viæ, quæ est inchoatio, via ac meritum felicitatis futuræ cœlestis et perfectæ, « hac opinione », id est ista tua firma sententia, qua recte sentis de felicitate (opinio autem proprie sumpta, vocatur assensus cum formidine de opposito; sed hic extensius sumitur pro consensu quocumque), « si quidem », id est certe, « adjeceris » verbis tuis jam dictis « hoc » quod dicam. — Quidnam? inquam : id est, ego Boetius « inquam », id est dico, Quid adjiciam ?

Ad quod Philosophia : Essene aliquid in his mortalibus caducisque rebus puta, quod hujusmodi statum possit afferre? hoc est, « puta ne aliquid esse in rebus his mortalibus » et « caducis, quod possit afferre », id est adducere seu præstare, « statum hujusmodi », id est perfectionem seu consistentiam talem, videlicet tam beatam? — Minime (inquam) puto, id est, ego Boetius « inquam, Puto » hoc « minime », id est nullatenus; idque a te, nihil ut amplius desideretur, ostensum est : hoc est, « idque ostensum » (id est demonstratum) « est a te, ut », id est quod, « nihil » rerum terrenarum « desideretur amplius », id est de cetero, nisi in quantum necessarium aut expediens est ad beatitudinem obtinendam, sicut medium appetitur propter finem, quoniam finis, ut ait Philosophus, necessitatem imponit his quæ sunt ad finem : necessitatem dico conditionatam, non absolutam.

Ex quibus Philosophia concludit : Hæc igitur quinque terrena præfata, vel imagines veri boni, vel imperfecta quædam dare bona mortalibus videntur : hoc est, « videntur dare mortalibus » hominibus « vel imagines veri boni », id est apparentias quasdam, non exsistentias beatitudinis, « vel bona quædam imperfecta », quoniam corporalia et terrena sunt valde imperfecta in se, et potissime respectu veræ felicitatis, quamvis carnalibus hominibus videatur quod in ipsis exsistat felicitas; verum autem atque perfectum bonum, puta felicitatem, conferre non possunt. — Assentior, inquam, id est, ego Boetius dico, « Assentior » (juxta antiquam grammaticam), id est, consentio tibi in his.

Deinde Philosophia declarat omnipotens Dei auxilium esse invocandum ad acquirendum beatitudinem veram.

Quoniam igitur agnovisti quæ vera illa sit, id est, quia ex dictis intellexisti « quæ sit » beatitudo « illa vera », quæ autem beatitudinem mentiantur, id est, quæ sint temporalia quæ putantur beatitudinem dare, quum ita non sit; nunc superest, id est restat, ut unde veram hanc petere possis, agnoscas, id est, « ut » scias « unde », id est a quo, « possis » de jure, id est, merito debeas, « petere », id est desiderare et rogare dari tibi, « hanc veram » felicitatem. — Id quidem, inquam, jamdudum vehementer exspecto : hoc est, « exspecto », id est præstolor, « vehementer jamdudum », id est nunc sicut et diu ante seu olim, « id quidem », id est, pro certo agnoscere a quo postulare debeam veram felicitatem.

— Sed quum, uti in Timæo Platoni (inquit) nostro placet, in minimis quoque rebus divinum præsidium debeat implorari. Ordo verborum est : « Sed quum divinum præsidium », id est Dei auxilium, « debeat implorari », id est intime exorari cum lacrimis saltem interioribus, id est suspiriis atque singultibus cordis, juxta illud :[^29] Ne avertas faciem tuam a singultu meo. Quid nunc faciendum censes, id est, « quid » tu, Boeti, « censes », id est judicas, esse « nunc » agendum, ut illius summi boni sedem recipere *mereamur, hoc est, « ut » per actus meritorios valeamus « recipere » pro mercede « sedem », id est mansionem et thronum glorificum, « boni illius summi », id est veræ beatitudinis, tam formalis, quæ est[^30]* beatifica contemplatio Dei, quam objecctalis, quæ est ipsemet Deus gloriosus ac æternalis?

— *Invocandum, inquam, rerum omnium Patrem*, id est, ego Boetius dico et censeo, « Patrem omnium rerum », id est universorum Creatorem, esse « invocandum » : *quo prætermisso*, id est non cognito nec invocato, *nullum rite fundatur exordium*, id est, nullum opus legitime inchoatur, in tantum quod et ipsa oratio oratione prævenienda est, quoniam Deum orare debemus ut det nobis gratiam efficaciter ac devote orandi, dicente Apostolo : Quid oremus, sicut oportet, nescimus ;[^31] sed ipse Spiritus postulat pro nobis gemitibus inenarrabilibus, id est, Spiritus Sanctus nos postulare facit valde suspiriose. Quumque oraturi sumus, debemus mentem simplificare in Deo, hoc est, ab aliis occupationibus, cogitationibus et distractionibus revocare, in Deo recolligere, ac sensum verborum attendere. Propter quod in Ecclesiastico scriptum est : Ante *Eccli. x* 23. orationem præpara animam tuam, et noli esse sicut homo tentans Deum.

— *Recte, inquit*, id est, Philosophia dixit, In hoc « recte » respondes; *ac simul* *ita modulata est*, id est, hoc dicendo et simul cum actu dicendi, dulciter cecinit, metro ludens, hoc est, delectabiliter proferens metrum quod sequitur.

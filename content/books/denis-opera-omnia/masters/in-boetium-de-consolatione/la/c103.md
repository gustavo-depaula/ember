# Articulus 13

Quamvis se Tyrio superbus ostro Comeret, et niveis lapillis, Invisus tamen omnibus vigebat Luxuriæ Nero sævientis. Sed quondam dabat improbus verendis Patribus indecores curules. Quis illos igitur putet beatos, Quos miseri tribuunt honores?



ELUCIDATIO METRI HUJUS QUARTI.

IN hoc metro declarat Philosophia, metrica melodia, quod prosaice in prosa probavit præhabita. Estque ordo verborum :

Quamvis *Nero* imperator *luxuriæ sævientis*, id est indomitæ, qua quasi nulli pepercit, *superbus se comeret*, id est, ornaret se, *ostro Tyrio*, id est purpurea veste (nam purpura tingitur in sanguine ostri, id est piscis sic nominati, qui in mari juxta Tyrum abundat : hinc purpura alio nomine vocatur ostrum), *et lapillis niveis*, id est gemmis candidissimis instar nivis; *tamen omnibus invisus*, id est odiosus, *vigebat*, id est, in potestate vivebat : non quod boni invidebant ei aut oderant eum ut hominem, sed in quantum tam vitiosum ac pessimum. Sic enim et ipsi Deo odio sunt impius et impietas ejus. Et hoc est odium virtuosum, quo oditur culpa, et amatur persona : de quo ait Psalmista, Perfecto odio oderam illos. Sed Ps. cxxxviii, improbus, id est pessimus ille *Nero*, *dabat* 22. quondam *patribus verendis*, id est senatoribus, *curules indecores*, id est sedes et dignitates senatorum et consulum « indecores », id est inhonestas per abusum tanti tyranni, sicut in prosa proxime præcedenti expositum est.

Igitur *quis putet* (id est, nemo rationabiliter putare judicareve potest) *illos honores* esse *beatos*, id est illas dignitates esse felices in se aut beatificantes, *quos miseri*, id est infelices et pessimi, *tribuunt*? In quibus verbis tangitur duplex ratio cur in dignitatibus non consistit felicitas : prima est, quia impii et miseri, in quibus est miseria pœnæ et culpæ, habent eas; secunda, quoniam tribuunt eas aliis, nec tamen beatificant illos.

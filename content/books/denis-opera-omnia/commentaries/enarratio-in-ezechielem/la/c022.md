2 patebit. *Hæc dicit Dominus Deus: Aquila grandis,* id est Nabuchodonosor rex Babylonis, *magnarum alarum,* id est magnos habens exercitus: qui nomine alæ signantur, juxta illud in Isaia, Erit extensio alarum ejus (videlicet regis Assyriorum) implens latitudinem terræ tuæ, o Emmanuel;[^1] *longo membrorum ductu,* id est, potentes principes possidens, qui erant quasi membra ipsius; *plena plumis,* id est divitiis, *et varietate,* id est diversis mundi ornatibus.

De aquila ista scriptum est in Osee:[^2] Quasi aquila super domum Dei. *Venit ad Libanum,* id est ad templum Jerusalem: de quo scriptum est in Zacharia, Aperi, Libane, portas tuas. Dicitur autem templum Libanus, vel propter ejus sublimitatem ac eminentiam, vel quia de lignis Libani erat partim constructum. Libanus quippe mons fuit valde sublimis, in quo arbores pulcherrimæ nascebantur. *Et tulit medullam cedri,* id est meliora electaque bona Jerusalem.

*Summitatem frondium ejus avulsit,* id est, Jechoniam regem a regali potestate amovit, *et transportavit eam in terram Chanaan,* id est, in Chaldæam transtulit eum: quemadmodum quarto Regum plenius scribitur. Chaldæa autem secundum Hieronymum, terra Chanaan appellatur. Dicuntque aliqui, quod Chanaan in Hebræo, interdum est nomen proprium, et ita designat Judæam, in qua ante filios Israel habitaverunt Chananæi. Interdum vero est nomen appellativum, et sic mercationem significat. Sic quoque terra Babyloniæ seu Chaldæa, terra Chanaan dicitur, quoniam mercatores hanc frequentabant. *In urbe negotiatorum posuit illam,* id est, in Babylone collocavit Nabuchodonosor Jechoniam præfatum.[^3] Ibi namque posuit eum in carcere, ut legitur quarto Regum. *Et tulit de semine terræ,* id est, Sedeciam accepit pro Jechonia: qui Sedecias fuit de semine terræ Juda, quia de sanguine regio, atque avunculus Jechoniæ;[^4] *et posuit illud in terra,* id est, in Judæa constituit eum regem, *pro semine,* id est loco Jecho-

A niæ, *ut firmaret radicem,* id est, potestatem suam fundaret, *super aquas multas,* id est populum multum, quibus eum rex Babylonis præfecit.[^5][^6][^7] Aquæ enim multæ, populi multi, ut in Apocalypsi habetur. *In superficie posuit illud,* id est, Sedeciam non profundavit nec stabilivit in regno, sed cito amovit, sicut id quod solum in superficie ponitur, neque infigitur.

*Quumque germinasset,* id est, in regnum processisset, et potestatem suam dilatare cœpisset, *crevit in vineam latiorem,* pluribus dominando, *humili statura,* id est non statu libero, sed subjecto, quia sub rege Babylonis subditus fuit, *respicientibus ramis ejus ad eam,* id est, ad aquilam præinductam respicientibus principibus ac populis Sedeciæ, quoniam Chaldæis subjecti fuerunt; *et radices ejus,* id est fundamentum sive stabilitas Sedeciæ, *sub illa erant,* id est sub potestate regis Babylonis. *Facta est ergo vinea*: id est, rex iste Sedecias et populus ejus per incrementum assimilati sunt viti; *et fructificavit in palmites,* id est, in personis divitiisque profecit, *et emisit propagines,* id est, filios generavit. Quamdiu enim Sedecias cum suis mansit sub imperio regis Babylonis, bene sibi et populo successit. Denique de vinea ista et ejus propagine scriptum est in Isaia: Vinea Domini Sabaoth, domus Israel est, et vir Juda germen delectabile ejus; item in Psalmo, Extendit palmites suos usque ad mare, et usque ad flumen propagines ejus.

C Consequenter fit mentio de rege Ægyptio, ad quem Sedecias misit legatos petentes auxilium contra regem Babylonis. *Et facta est aquila altera grandis, magnis alis multisque plumis,* id est Pharao rex Ægypti. Quid autem per alas et plumas intelligatur, jam patuit. *Et ecce vinea ista,* utpote Sedecias cum majoribus suis, *quasi mittens radices suas ad eam,* id est, legatos suos ad regem Ægypti transmisit, *palmites suos extendit ad illam,* id est, populos suos destinavit ad regem præfatum.[^8] Unde et in Isaia prædictum est: Væ qui descendunt in Ægyptum ad auxilium. *Ut irrigaret eam*, id est, ut rex Ægypti vineam istam confoveret, *de areolis germinis sui*, id est de locis seu urbibus populi sui Ægyptii, destinando vineæ huic bellatores Ægyptios in succursum. Etenim per areolam, quæ est locus bene seminatus, intelliguntur urbes Ægypti bellatoribus plenæ.

*In terra bona*, videlicet in Judæa, *super aquas multas*, id est populos multos, plantata est vinea jam prædicta, scilicet Sedecias et domus ipsius a rege Babylonis, qui Sedeciam Judæis præfecit regem, *ut faciat frondes*, id est, populos augeat sui dominii, *et portet fructum* per generationem filiorum ac filiarum, *ut sit in vineam grandem* potestate et numero hominum.

Dic, o Ezechiel: *Hæc dicit Dominus Deus: Ergone prosperabitur* Sedecias iste cum suis, qui regi Babylonis fidelitatem juravit, et tamen ad ejus hostem regem Ægypti pro auxilio destinavit? quasi dicat: Male ei succedet. Ideo subditur: *Nonne radices ejus evellet?* id est, rex Babylonis vineam istam radicitus dissipabit; *et fructus ejus distringet*, id est, filios Sedeciæ occidet, *et siccabit omnes palmites germinis ejus*, id est, principes Sedeciæ spoliabit virtute ac vita, *et arescet* vinea ista per regiæ potestatis amissionem, procreationisque filiorum defectum, quantum ad Sedeciam. *Et non in brachio grandi*, id est magna potestate Chaldæorum, *neque in populo multo* de eorum exercitu, factum est hoc. Pauci quippe Chaldæi insecuti sunt fugientem Sedeciam ac principes ejus et filios, prævalueruntque hi pauci Chaldæi. *Ut evelleret eam radicitus*, id est, ut Nabuchodonosor vineam istam funditus demoliretur. *Ecce plantata est* vinea hæc in terra Juda a Babyloniorum rege; *ergone prosperabitur* illi repugnando? *Nonne quum tetigerit eam ventus urens*, id est fervida impugnatio Chaldæorum, *siccabitur*, vigorem perdendo, *et in areis germinis sui arescet*, id est, in terra sua deficiet? Unde Septuaginta transtulerunt: Cum gleba germinis sui arescet.

Consequenter parabola ista in textu exponitur, sicut exposita est. *Et factum est verbum Domini ad me, dicens*: *Dic ad domum exasperantem*, id est Judæorum familiam, Deum naturaliter pium ac dulcem suis perversitatibus ad diram ultionem inducentem: *Nescitis quid ista significant?* Dic, eam exponendo: *Ecce veniet rex Babylonis*, designatus per aquilam primam, *in Jerusalem; et assumet regem Jechoniam et principes ejus, et adducet eos ad semetipsum in Babylonem.* *Et tollet de semine regum*, videlicet Sedeciam patruum Jechoniæ, *ferietque cum eo fœdus*, id est, pactum amicitiæ percutiet secum; *et ab eo accipiet jusjurandum*, ita quod Sedecias juramento firmabit initum fœdus, quo se obligabit ad obediendum regi Babylonis, et ad persolvendum tributum. *Sed et fortes terræ*, id est principes atque potentes Judææ, tollet rex Babylonis, *ut sit regnum humile*, regnum videlicet Juda sub Sedecia, *et non elevetur* per rebellionem contra Chaldæos, *sed custodiat pactum ejus*, videlicet regis Babylonis in persolutione tributi ac servitutis.

Qui Sedecias *recedens ab eo*, id est, a rege Babylonis cor suum avertens, et pactum transgrediens, *misit nuntios ad Ægyptum*, id est ad regem Ægypti, *ut daret illi, scilicet Sedeciæ, equos et populum multum in auxilium contra regem Chaldææ. Numquid prosperabitur, vel consequetur salutem, prævalendo contra Chaldæos, qui fecit hæc, scilicet Sedecias? Et qui dissolvit pactum, id est, initum fœdus dirupit, numquid effugiet manum regis Babylonis? Quamvis hoc ad litteram contra Sedeciam dicatur, generaliter tamen accipi potest contra omnes inita fœdera licita confringentes: qui etsi forte hominum manus evadant, omnipotentis tamen Dei judicis manum nequaquam effugient. Ex quibus secundum Hieronymum, discimus etiam inter hostes fidem esse servandam, et non considerandum cui, sed per quem,*

D juraveris. Multo enim fidelior est ille, qui propter nomen Dei tibi credidit, et deceptus est a te, quam tu, qui per occasionem divinæ majestatis hosti tuo, imo jam amico tuo, es molitus insidias.

*Vivo ego, dicit Dominus, quia in loco regis cujus irritum fecit pactum,* id est in Babylone civitate regis Nabuchodonosor, *morietur* Sedecias in carcere : sicut et Jeremias sibi prædixit, quod non moreretur in gladio, sed in pace.[^9] *Et non in exercitu grandi, neque in populo multo faciet contra eum,* videlicet regem Babylonis, *Pharao prœlium in jactu aggeris,* id est aggerem jaciendo, *et in exstructione vallorum.* Agger autem est collectio terræ atque lignorum ad implendum fossata, quatenus obsidentes possint pugnare ad propugnacula contra obsessos. Valli quoque dicuntur fossæ, quæ fiunt extra ante portas, ne obsessi repente irruere possint super obsidentes. Est itaque sensus, quod Pharao per hæc atque similia non potuit regi Babylonis resistere, nec Sedeciæ contra regem illum opem præbere. Nam quum Ægyptii egressi essent ad auxiliandum Sedeciæ, mox audientes Chaldæorum occursum, redierunt in sua perterriti. Ut interficiat Pharao *animas multas,* id est plurimos Chaldæorum. Ponitur autem pars pro toto, quum ait, Ut interficiat animas multas : quum animæ rationales sint immortales. Ex quo etiam elucescit, quod vana ac stulta fuerat argumentatio Sadducæorum, animas humanas mortales esse dicentium atque probantium, eo quod in libris Moysis sæpe scriptum sit, animam occidi, vel aliquid simile, ut quod Judas dixit fratribus suis de Joseph, Non interficiamus animam ejus:[^10][^11] quoniam et Prophetæ, quos certum est posuisse quod animæ nostræ sint immortales, talem habent modum loquendi. Unde et Jeremiæ quadragesimo scriptum est, qualiter Johanan locutus est Godoliæ, quod Ismael quidam venturus esset percutere, id est occidere, animam ejus.[^12]

*Spreverat enim* Sedecias *juramentum regi Babyloniæ præstitum, ut solveret fœdus inter eos percussum.* *Et ecce dedit manum suam* ad manum regis Babylonis, pactum secum ineundo. *Et quum omnia hœc fecerit, non effugiet,* id est, quia tam infideliter se habuit, non evadet, nec rex Ægypti sibi succurrere poterit.

*Propterea hœc dicit Dominus :* *Quoniam juramentum quod sprevit, et fœdus quod prœvaricatus est, ponam in caput ejus,* id est, de perjurio et pacti transgressione puniam eum. *Et expandam super eum rete meum,* id est potestatem meam omnia complectentem, vel exercitum Chaldæorum, *et comprehendetur in sagena mea.* Captus est quippe ab exercitu Chaldæorum. *Et adducam eum in Babylonem, et judicabo eum ibi in prœvaricatione qua despexit me :* id est, secundum demeritum suæ prævaricationis, qua in meam injuriam juramentum ac pactum dirupit, faciam eum a rege Babylonis dijudicari, et carceri mancipari. *Et omnes profugi ejus,* id est quidam de omnibus illis, *cum universo agmine suo,* gladio Chaldæorum cadent : non utique absolute omnes, sed omnes, exceptis demendis, de quibus subjungitur : *residui autem in omnem ventum dispergentur,* id est per loca diversa ut lateant. Ista jam sæpe præhabita sunt, idcirco non immoror.

Præterea, post prænuntiationem destructionis regni Judæorum per Chaldæos, prædicitur regni ejusdem reparatio consummata per Christum. *Hœc dicit Dominus Deus :* *Et sumam ego* Dominus Deus, non Nabuchodonosor, *de medulla cedri sublimis,* id est, de semine nobiliori regiæ tribus Juda educam atque accipiam Christum : qui secundum carnem natus est ex semine David, ut dicitur ad Romanos ;[^13] *et ponam de vertice ramorum ejus,* id est, de ramis altioribus cedri præfatæ, videlicet de præclarioribus hujus regalis tribus personis, constituam Christum, *tenerum distringam,* id est, Christum tenerrimæ complexionis atque piissimum, in passione letaliter premam. Dominus enim posuit in eo iniquitatem omnium nostrum, ut loquitur Isaias.[^14] *Et plantabo super montem excelsum et eminentem*, id est, Christum regem præficiam ipsi Ecclesiæ seu synagogæ electorum Judæorum : secundum quod in Isaia habetur, Super solium David et super regnum ejus sedebit. Vel, Super montem excelsum, id est montem Sion, in quo fuerat templum, in quo oblatus est Christus, et postea sæpius illic advenit, docuit, atque miracula fecit : de quo monte scriptum est Isaiæ secundo, Erit in novissimis diebus præparatus mons domus Domini in vertice montium.

23 *In monte sublimi Israel* : de quo monte jam dictum est, quia et primitiva Ecclesia ex Judæis constabat ; *plantabo illam cedri* medullam, videlicet Christum pretiosissimum Israel semen. Unde ait in Psalmo : Ego autem constitutus sum rex ab eo, etc. *Et erumpet in germen*, multos convertendo ad Deum, qui erant spirituales filii ejus ; *et faciet fructum*, totum mundum salvando. *Et erit in cedrum magnam* : quia præ universis creaturis exaltatus est, omnemque orbem terrarum, potestate, fecunditate, et gratia sua implevit : secundum quod Danielis secundo inducitur, quod lapis præcisus de monte sine manibus, crevit in montem magnum, et implevit universam superficiem terræ. Hinc apud Isaiam Christus loquens de Patre : Glorificatus sum (inquit) in oculis Domini, et dixit : Parum est ut sis mihi ad suscitandas tribus Jacob, et fæces Israel convertendas ; dedi te in lucem gentium, ut sis salus mea usque ad ultimum terræ. *Et habitabunt sub ea omnes volucres*, id est cuncti homines per liberum usum, id est omnes in alta se erigentes sub cedro præfata : hoc est, in Christi caritate, fide et gratia quiescent ac permanebunt. 24 *Et scient omnia ligna regionis,* id est populi universi ad fidem reducti : de quibus Psalmista et Isaias loquuntur frequenter ; *quia ego Dominus humiliavi lignum sublime,* id est populum Judæorum altius in beneficiis Dei præ ceteris exaltatum, *et exaltavi lignum humile*, id est populum gentilem quondam omni Dei gratia destitutum ; *et siccavi lignum viride*, utpote Synagogam, quæ olim in lege et Prophetis fuit florens ac germinans, quæ post Christi adventum ob suam incredulitatem dejecta est, *et frondere feci lignum aridum*, id est plebem nationum, convertendo eam ad fidem, dandoque ei fructus virtutum, ornamenta donorum, et varia supernaturalia gratiæ munera.

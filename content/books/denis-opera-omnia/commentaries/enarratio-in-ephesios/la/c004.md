# Articulus 3

EXPLICATIO CAPITULI TERTII: HUJUS REI GRATIA, EGO PAULUS VINCTUS, ETC.[^1]

ORANS præterea sanctus Apostolus pro Ephesiis, ait: *Hujus rei gratia*, id est pro hac causa mihi grata, et vobis gratiosa, videlicet ut ædificemini in habitaculum Dei in Spiritu Sancto (secundum intellectum jam expressum), *ego Paulus vinctus Jesu Christi*, id est propter Christum Romæ incarceratus et vinculis strictus, *pro vobis gentibus*, id est ob hoc quod vobis gentibus evangelizo. Et hoc vobis constare potest sic esse, *si tamen audistis dispensationem gratiæ Dei quæ data est mihi*, id est gratiam mihi ex divina dispensatione seu dispositione collatam, videlicet apostolatum et cetera dona gratis data atque gratifica mihi impensa, *in vobis*, id est ad vestram salutem et instructionem.[^2] *Quoniam secundum revelationem*, id est ex supernaturali et clara illuminatione Christi, *notum mihi factum est sacramentum*, id est humanæ redempionis mysterium seu occultum Dei consilium de salvatione hominum, *sicut supra*

(videlicet in præcedenti capitulo) *scripsi in brevi* sermone, dicendo de Christo: Ipse est pax nostra, qui fecit utraque unum;[^3] *prout potestis, legentes* verba illa, *intelligere prudentiam*, id est sapientiam, *meam in mysterio Christi* cognoscendo, id est in descriptione, prædicatione, seu cognitione hujus divini secreti, seu summæ mentis consilii, utpote quod gentes per Christum salvandæ sint.

Quod mysterium *aliis,* id est præteritis, *generationibus non est agnitum,* id est revelatum, scilicet *filiis hominum* qui fuerunt, *sicut nunc,* id est tam plene, tam vulgate, et tam perfecte quam modo. *Revelatum autem sanctis Apostolis ejus et Prophetis* novi Testamenti: quorum multi nominantur in Actibus Apostolorum.[^4] Nam et omnes Apostoli fuerunt prophetæ. His ergo revelatum est *in spiritu*, id est per Spiritum Sanctum; vel, In spiritu, id est spirituali mentis excessu seu elevatione ad percipiendam revelati-

6 onem divinam; *esse gentes,* id est electos gentiles, *coheredes* quoad felicitatem futuram, *et concorporales,* id est ad idem mysticum corpus pertinentes, *et compartícipes promissionis,* id est consortes cœlestium promissionum cum nobis Apostolis ceterisque electis Judæis, ita ut eadem sit beatitudo omnium nostrum in patria, et nunc unum corpus simus Christi. Quod totum factum est *in Christo Jesu, id est virtute* et gratia, seu per incarnationem, passionem et merita Christi; item *per Evangelium,* id est evangelicæ legis prædicationem, per quam gentes ad fidem conversæ sunt, et Christi gratiam susceperunt; cujus Evangelii *factus sum ego minister,* id est obsequiosus annuntiator, *secundum donum gratiæ Dei quæ data est mihi,* id est secundum apostolatum et sapientiam mihi divinitus distributa, *secundum operationem virtutis ejus,* id est secundum influxum divinæ potentiæ, ad tantam me gratiam promoventis.

7

8 *Mihi enim* Paulo *omnium sanctorum minimo*, non simpliciter, sed secundum aliquam considerationem, videlicet quantum ad id quod sum ex me ipso, et quod feci adversus Ecclesiam.[^5] Etenim secundum diversas considerationes sui ipsius, potest homo diverso de sese judicare modo sine mendacio, sicque major ac perfectior potest se vere humiliare sub inferioribus. Nunquam enim debet aliquis propter humilitatem a veritate recedere. *Data est gratia hæc,* id est auctoritas et sapientia: *in gentibus evangelizare,* id est gentibus prædicare, *investigabiles divitias, id est imperscrutabilia* et copiosissima dona et beneficia Christi hominibus præstita vel promissa; *et illuminare* instrumentaliter, id est prædicando docere, *omnes gentes,* id est quasdam de omni genere gentium, *quæ sit dispensatio,* id est exsecutio seu dispensativa adimpletio, *sacramenti absconditi a sæculis in Deo,* id est humanæ redemptionis secreto consilio factæ, seu incarnationis Filii Dei. Quod sacramentum, absconditum seu celatum fuit in Deo, id

9 est in divinæ mentis notitia, a sæculis, id est ab omnium generationum exordiis, utpote ab origine mundi, ita ut nulli creaturæ angelicæ vel humanæ fuerit plene manifestatum. *Qui* Deus *omnia creavit.* *Ut innotescat principibus et potestatibus in cœlestibus per Ecclesiam multiformis sapientia Dei, secundum præfinitionem sæculorum, quam fecit* Deus *in Christo Jesu Domino nostro.*

11

B In horum expositione verborum maximam difficultatem habentium, S. Hieronymus et Augustinus non nihil dissonare videntur. Secundum Hieronymum enim exponitur sic: *Mihi data est gratia evangelizare in gentibus investigabiles divitias Christi, ut innotescat,* id est, ita ut notificetur, *principibus et potestatibus, id est angelorum* ordinibus qui sunt in cœlestibus mansionibus, per Ecclesiam, id est per Apostolorum in Ecclesia prædicationem, seu ex prædicatione Apostolorum in Ecclesiis facta, multiformis sapientia Dei, id est divinæ mentis sapientialis dispositio de humani generis liberatione. Quæ utique cognitio vel sapientia Dei, quamvis in se una et simplicissima sit, tamen propter diversa quæ includit, concernit et efficit, multiformis vocatur. Est enim de omnibus mysteriis Christi. — Quod autem subjungitur, Secundum præfinitionem sæculorum, etc., referri potest ad verbum, Innotescat. Eritque sensus: Ut innotescat principibus et potestatibus per Apostolorum prædicationem multiformis sapientia Dei, secundum præfinitionem sæculorum, id est secundum prædicationem dominicam ab exordio temporum præconceptam: *quam præordinationem fecit,* id est effectui mancipavit, *in Christo Jesu Domino nostro, id est per* Christi prædicationem inchoative, et per missionem ac illuminationem qua ipse Apostolos docuit, et ad prædicationem emisit. — Secundo refertur ad nomen, Multiformis. Tanquam dicat: Multiformis sapientia Dei, non in se multiformis, sed simplex; multiformis vero, secundum præfinitionem sæculorum,

C

D id est secundum ordinationem eorum quæ in sæculo fiunt, vel secundum hæc ipsa ex divina præordinatione procedentia : quam præfinitionem fecit, id est implevit, vel implere disposuit, Deus Pater in Christo Jesu Domino nostro, id est per unigenitum Filium suum, per quem facta sunt omnia;[^6] qui testatur :[^7] Pater meus usque modo operatur, et ego operor.

Secundo exponitur, juxta Augustinum, hoc modo : *Mihi data est gratia illuminare omnes, quæ sit dispensatio sacramenti absconditi a sæculis in Deo, ut innotescat*, id est, sic tamen ut innotuerit, *principibus et potestatibus*, id est angelis universis, *per Ecclesiam*, id est in Ecclesia, *multiformis sapientia Dei*.

Ponit ergo Augustinus super Genesim, quod omnes angeli, a principio sæculi præcognoverunt mysterium regni cœlestis, id est unigeniti Filii Dei incarnationem. Quod etiam Thomas in prima parte affirmat, rationem adjiciens : Quoniam incarnatio Verbi, est finis ad quem omnia angelorum ministeria ordinantur.[^8] Omnes autem sunt aliquo modo administratorii spiritus. Omnes ergo sacramentum hoc cognoverunt quantum ad substantiam ejus in generali, non autem quantum ad singulas circumstantias seu particulares conditiones ipsius. Et quantum ad hoc, profecerunt in cognitione multiformis sapientiæ Dei mysteriorumque Christi, tempore ascensionis et prædicationis Apostolorum. Porro, B. Hieronymus videtur sentire oppositum hoc loco, et in Isaia, exponens illud, Quis est iste qui venit de Edom ?[^9]

Ait itaque, quod angeli mysterium incarnationis passionisque Christi ignoraverunt, donec impleretur, a Christo quoque ascendente illud addiscerent, atque ex prædicatione Apostolorum in ejus agnitione proficerent. Verumtamen si dicta Hieronymi diligenter inspiciantur, non videntur prædictis penitus dissonare. Nam asserit, quod angelicæ dignitates non ad purum intellexerunt præmemoratum mysterium, donec completa est passio Christi, et Apostolorum prædicatio in gentes promulgata. Certum est autem dici non posse, quod angeli absolute nescierunt mysteria Christi, donec rebus essent expleta. Propheticæ autem revelationes, secundum Dionysium, angelorum ministerio fiunt. Quod ergo de Christo præcognoverunt Prophetæ, angeli prius certiusque noverunt. — De hac vero materia plenius dixi in Isaia, exponendo capitulum illud, cujus exordium est : Quis est iste qui venit de Edom ?[^10] Videtur quoque expositio gloriosi Hieronymi hoc loco magis concordare litteræ, quam expositio Augustini, ut constat inspicienti.

In quo Christo, id est cujus gratia et merito, *habemus fiduciam* futuræ felicitatis, *et accessum* ad Deum *in confidentia*, id est confidendo de bonitate Dei, meritis Christi et actibus propriis, *per fidem ejus*, quia in fide Christi omnia bona nostra fundantur. Unde et confidentia ista ex fide procedit.

Consequenter admonet Ephesios ad patientiam atque constantiam. *Propter quod obsecro*, id est, per sacra vos rogo, *ne deficiatis*, id est, ne frangamini per impatientiam, pusillanimitatem, aut tædium animi, nec a fide bonoque opere desistatis, *in tribulationibus meis*, id est ex consideratione persecutionum et adversitatum quas patior *pro vobis*, hoc est ad vestri ædificationem ac probationem; *quæ constantia, scilicet non deficere, est gloria vestra*, id est gloriosum meritum vestrum. Solent autem pusilli scandalizari, frangi, deficere, dum conspiciunt justos ab impiis opprimi aut occidi. In quorum persona scriptum est ab Habacuc : Quare, Domine, non respicis contemptores, et taces conculcante impio justiorem se ?[^11] Propter hoc lacerata est lex. Exercitati autem in via et lege divina, qui sciunt quod per multas tribulationes oportet nos intrare in regnum cœleste, et quod pœnæ justorum in hac vita non sunt nisi medicinæ atque remedia, non moventur ex hoc ;[^12] quin potius dicunt illud Salvatoris :[^13] Beati qui persecutionem patiuntur propter justitiam, quoniam ipsorum est regnum cœlorum.

*Hujus rei gratia,* puta, ne deficiatis a bono propter adversa, *flecto genua mea,* corpus in oratione humiliando, ad insinuandam vel excitandam cordis mei humiliationem, *ad Patrem Domini nostri Jesu Christi, ex quo omnis paternitas in cœlis et in terra nominatur,* id est, de cujus verissima paternitate derivatur et nomen paternitatis sortitur omnis paternitas angelorum et hominum : ita quod paternitas primo et proprie convenit Deo Patri, qui genuit Filium, non solum in natura similem, sed etiam sibi consubstantialem; ceteris vero convenit paternitas per quamdam imitationem paternitatis divinæ. *Ut det vobis secundum divitias gloriæ suæ,* id est secundum plenitudinem suæ perfectionis increatæ et opulentissimæ, *virtutem,* id est cordis constantiam, *corroborari,* id est, ut confirmemini, *per Spiritum ejus,* id est per inspirationem et opem Spiritus Sancti, *in interiori homine,* id est in anima : quod est *habitare Christum per fidem* formatam *in cordibus vestris,* id est mansionem quietam ac jugem præsidentiam habere in interioribus vestris. Sitis quoque *in caritate* Dei ac proximi *radicati,* id est radicitus fixi, seu firmiter inhærentes, quemadmodum radix terræ fortiter inest, *et fundati,* id est per firmas rationes divini amoris stabiliti, videlicet ex consideratione divinæ bonitatis in se, et caritatis ejus super nos, ex consideratione etiam beneficiorum promissionumque Christi :

*Ut possitis comprehendere,* id est sincere cognoscere, *cum omnibus sanctis,* id est, sicut sancti in via Deo revelante cognoscunt, *quæ sit latitudo* spiritualis caritatis, *et longitudo, et sublimitas, et profundum* ejus. Hæ dimensiones attribuuntur caritati, per similitudinem corporalium dimensionum. Unde latitudo caritatis est, quod ad omnes extenditur, etiam inimicos. Longitudo ejus est, quod tendit in longum atque futurum, videlicet usque in ultimum finem, seu vitam æternam, nec frangitur propter dilationem. Unde secundum Augustinum, longitudo est perseverandi longanimitas. Sublimitas vero caritatis est, quod immediate unit nos Deo, imo in Deum transformat, eique inseparabiliter colligat : quod maxime in patria adimpletur. Profundum autem caritatis est, condescensus ad proximum, vel humiliationis declivitas ex consideratione terribilium judiciorum Dei. — Possunt quoque hæc quatuor metaphorice ad divinam referri naturam : ut latitudo pertineat ad divinæ naturæ communicabilitatem, qua Deus dat omnibus affluenter, nec aliquid expers est a divinæ bonitatis participatione ;[^14] longitudo vero pertineat ad æternitatem, qua attingit a fine usque ad finem, imo universa præcedit et omnia sequitur, vel ad longanimem exspectationem qua impiorum præstolatur emendationem;[^15] sublimitas autem ad majestatis divinæ incircumscriptibilem excellentiam, vel ad promissorum supernaturalem dignitatem; profundum quoque ad incomprehensibilia divinæ naturæ, ejusque judiciorum, de quibus dicit Scriptura :[^16] Judicia tua abyssus multa; item alibi : Excelsior cœlo est, et quid facies? profundior inferno, et unde cognosces? Longior terra mensura ejus, et latior mari.[^17]

Possitis *scire etiam* scientia practica, id est sciendo imitari et juste agere, *supereminentem scientiæ caritatem Christi,* id est dilectionem illam præcipuam qua Christus secundum suam scientiam nos dilexit. Dilectio enim ex cognitione procedit. Vel sic : Possitis scire caritatem Christi supereminentem scientiæ, id est nostram notitiam sua magnitudine excedentem. *Ut impleamini,* id est, divinarum gratiarum recipiendo influxum, tendatis ac perducamini, *in omnem plenitudinem Dei,* id est ad omnia dona perfecta quæ conferuntur a Deo, quatenus nunc obtineatis plenitudinem meritorum, postmodum vero plenitudinem præmiorum.

21

*Ei autem,* scilicet Deo omnipotenti, *qui potens est omnia* sibi placentia et nobis salubria *facere,* id est implere, *superabundanter quam petimus aut intelligimus,* id est copiosius quam orare aut nosse valeamus, qui tamen plus intelligimus quam orare præsumamus, *secundum virtutem,* id est omnipotentiam suam, *quæ operatur in nobis* ut causa prima ac principalis, nobisque virtutem et gratiam operandi largitur; *ipsi* sit gloria, id est clara cum laude notitia, *in Ecclesia,* id est in cordibus fidelium qui Deum glorificant, *et in Christo Jesu,* id est propter ea quæ nobis per Christum donavit : gloria, inquam, duratura *in omnes generationes,* id est per universa generationum intervalla seu tempora, *sæculi,* id est præsentis vitæ contentivæ *sæculorum,* id est includentis in se sæcula universa, id est singulas mundi ætates. Porro, secundum Damascenum, sæculum multa significat : primo, uniuscujusque rei vitam; secundo, tempus mille annorum; tertio, totam vitam, seu durationem (ut ita loquar) præsentem; quarto, vitam futuram in patria post resurrectionem novissimam; quinto, mensuram æternorum; sexto, mensuram perpetuorum; septimo, singulas septem mundi ætates. *Amen.*

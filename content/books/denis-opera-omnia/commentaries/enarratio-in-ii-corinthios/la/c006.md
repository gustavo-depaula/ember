# Articulus 5

ELUCIDATIO CAPITULI QUINTI : SCIMUS ENIM QUONIAM SI TERRESTRIS DOMUS NOSTRA HUJUS HABITATIONIS DISSOLVATUR.

DIXIT Apostolus in fine præcedentis capituli, quod levis ac momentanea tribulatio præsentis exsilii, æternum gloriæ pondus operetur in nobis. Hujus autem nunc assignat rationem. *Scimus enim* per revelationem divinam, *quoniam si terrestris domus nostra,* id est, quod si caro nostra mortalis, *hujus habitationis,* id est præsentis mansionis, qua anima degit ac hospitatur in corpore, *dissolvatur* per mortem, vel pro Christo occidatur, *quod ædificationem,* id est habitaculum, *ex Deo,* id est a divina virtute, *habemus* in spe, et habebimus tandem in re, vide-

licet *domum non manufactam,* id est carnem impassibilem, glorificatam, non humana potentia, sed divina, *æternam in cœlis,* id est in cœlo perpetuo duraturam vel ab æterno prædestinatam. Sed quoniam hanc domum non habebimus ante diem judicii, Apostolus loqui videtur de eo quod statim post dissolutionem corporis animæ perfectorum consequuntur. Ideo alii per domum istam non manufactam, intelligunt gloriam animæ, quæ dicitur domus, propter excellentiam suam et animæ capacitatem. Unde testatur Christus : In domo Patris mei mansiones multæ sunt, id est distincti gradus præmiorum. Alii vero per domum istam intelligunt cœlum empyreum, quod est locus atque palatium Beatorum. Et dicitur non manufactum, juxta illud ad Hebræos : Non in manufacta sancta Jesus introiit, sed in ipsum cœlum.[^1]

*Nam et in hoc ingemiscimus,* id est, desiderio hujus domus et gloriæ suspiramus et flemus præ tædio dilationis :[^2] Spes enim quæ differtur, affligit animam; *habitationem nostram quæ de cœlo est,* id est hanc domum non manufactam, cœlestem, vel cœlesti virtute formatam, seu gloriæ consecutionem, *superindui,* id est ea operiri, circumdari, sive ornari, *cupientes :* quod utique desiderium ortum habet a fide, non a lumine naturali. Sumus autem veraciter et efficaciter ista cupientes, *si tamen vestiti* donis et gratiis Spiritus Sancti, *non nudi* a bonis operibus, *inveniamur* a Deo cuncta spectante.

*Nam et qui sumus in hoc tabernaculo,* id est, in hoc passibili corpore degimus, ingemiscimus, suspirando ad habitationem cœlestem, *gravati* pondere atque miseriis corruptibilis carnis.[^3] Corpus namque quod corrumpitur, aggravat animam, et deprimit terrena inhabitatio sensum multa cogitantem. Ingemiscimus autem *eo quod nolumus exspoliari,* id est a corporis unione penitus atque finaliter separari : quum naturale sit animæ corpus informare; et Sancti in patria cupiunt corporibus glorificandis conjungi; *sed supervestiri,* id est immortalitatem et glorificationem corporis adipisci, *ut absorbeatur quod mortale est,* id est, mortalitas, pœnalitas et imperfectio auferantur a corpore, *a vita,* id est ab impassibilitate et gloria superveniente, prædictam imperfectionem excludente.

*Qui autem efficit nos in hoc ipsum,* id est, qui prædictam voluntatem inspirat, vel ad hujus desiderii consummationem perducit, est Deus, non causa naturalis, *qui dedit nobis pignus Spiritus.[^4]* Hoc idem primo capitulo hujus epistolæ dictum est atque expositum. *Audentes igitur semper,* id est, incessanter audemus ex magna in Deum fiducia futuram habitationem appetere, atque in omnibus viriliter agere, *et scientes* auxilium gratiæ nobis collatum. Causa autem audaciæ subditur : *quoniam dum sumus,* id est vivimus, *in corpore* isto mortali, *peregrinamur a Domino,* id est, a patria separamur, atque a Deo distamus, conversando in valle lacrimarum, in carcere mortis, in gravi exsilio. *Per fidem enim ambulamus,* id est, per obscuram notitiam ad patriam tendimus, *et non per speciem,* id est propriam et adæquatam similitudinem, Deum non cernimus. Non enim videmus eum sicuti est, id est clare seu facie ad faciem, sed per formas creatas, quæ a repræsentatione perfecta ac faciali divinæ essentiæ in infinitum deficiunt, sicut in præcedenti epistola pertractatum est planius.[^5][^6] *Audemus autem,* id est fiducialiter quærimus, non metu mortis retracti, aut aliqua difficultate victi, *et bonam voluntatem,* id est rationabile desiderium, *habemus magis peregrinari a corpore,* id est potius a corpore per mortem separari, *et præsentes esse ad Dominum,* id est Deo immediate uniri, eumque coram et per speciem intueri. Loquitur autem de præsentia gloriæ, non de præsentia gratiæ tantum. Unde ait Psalmographus :[^7] Adimplebis me lætitia cum vultu tuo;[^8] item : Quando veniam et apparebo ante faciem Dei?

et ideo, scilicet ut Deo feliciter uniamur, *contendimus,* id est, forti conatu studemus, *sive absentes,* id est a Domino peregrinantes, et in hac vita manentes, *sive præsentes,* id est divino judicio præsentati, *placere illi,* id est, ne separemur ab ejus conspectu. Nam et in divino judicio satagemus respondere pro nobis ad ea quæ contra nos proponent diaboli. Merito autem contendimus Deo placere : *Omnes enim nos,* id est homines universos, bonos ac malos, *manifestari,* id est publice præsentari seu apparere, *oportet,* vel in judicio particulari statim post mortem, vel in judicio universali in die novissimo, vel potius in utroque, *ante tribunal Christi*, id est coram judice Christo, seu ante districtam judiciariam ejus potestatem, *ut referat unusquisque*, id est reportet, *propria corporis*, id est debitam mercedem, videlicet pœnam vel gloriam pro actibus per corpus operatis, seu tempore corporalis vitæ exhibitis, *prout gessit, sive bonum gessit, sive malum*.[^9][^10][^11] Sub peccato autem commissionis includitur peccatum omissionis, quia et arbor quæ non facit fructum bonum, in ignem mittetur, etiam si malum non gessit.[^12]

*Scientes ergo timorem Domini*, id est quam timorate atque sollicite ambulandum sit coram Deo sancto et metuendo: de quo ait beatus Job, Semper quasi tumentes super me fluctus timui Deum;[^13] et rursus, Considerans eum timore sollicitor;[^14] *hominibus suademus*, id est, consilia monitaque salutis proponimus, quatenus Deum præ omnibus timeant, non servili, sed filiali aut saltem initiali timore.[^15] Timor enim Dei expellit peccatum. *Deo autem manifesti*, id est plenissime cogniti, vel per approbationem noti, *sumus*. *Spero autem et in conscientiis vestris manifestos nos esse*, id est, confido quod conscientiæ vestræ de nobis recte vereque sentiant, quia sic viximus inter vos ut non possitis rationabiliter contra nos moveri.

*Non iterum commendamus nos vobis*, id est, ad propriam laudem ista non dicimus, sicut nec ante; *sed occasionem*, id est causam incidentalem atque materiam, *damus vobis* per commemorationem istorum, *gloriandi*, id est spiritualiter exsultandi, *pro nobis*, id est pro gratia nobis concessa, vel pro defensione nostra contra æmulos et detractores nostros, qui conantur se nobis præferre, et vos a nobis avertere; *ut habeatis* rationabilem responsionem et veram lætitiam *ad eos qui in facie*, id est de apparente et simulata justitia, *gloriantur, et non in corde*, id est non ex conscientiæ puritate, neque de veris virtutibus. Quod autem non commendemus nos ipsos inaniter, et quod vos pro nobis gloriari possitis, patet ex hoc: *Sive enim mente excedimus*, contemplando divina, et supergrediendo terrena; *Deo*, id est, hoc gratiæ Dei adscribimus, atque ad gloriam ejus referimus. *Sive sobrii sumus*, instruendo vos in moralibus, et condescendendo infirmitatibus vestris; *vobis*, id est, ad vestram utilitatem hoc facimus. Vel sic: Sive mente excedimus, id est, laudando nos ipsos insensati esse videamur (quia stultorum est, laudibus propriis inhærere); Deo, id est, ad gloriam Dei hoc agimus, ut benedicatur Deus in donis suis. Sive sobrii sumus, moderate loquendo de perfectionibus nostris, sicut ad virtuosum sapientemque pertinet, ut in his quæ propriam laudem concernunt, magis declinet ad minus quam ad majus; *vobis*, id est, pro vestri informatione et commodo hoc facimus.

*Caritas enim Christi*, id est dilectio qua Christum proximumque diligimus, *urget*, id est, incitat et vehementer inclinat, *nos* ista efficere, quoniam Christi gloriam et proximorum salutem tanto amplius zelamus, quanto in vera caritate perfectiores fuerimus; *æstimantes*, id est firmiter reputantes, *hoc, quoniam si* (pro quia) *unus*, utpote solus Christus, *pro omnibus hominibus liberandis mortuus est, ergo omnes mortui sunt*, id est vitiis mortificati merito passionis Christi, quantum est ex parte ipsius Salvatoris, qui moriendo omnia ad se traxit.[^16] Vel, Omnes mortui sunt, id est, mortem culpæ incurrerunt ex originali peccato: aliter non egerent salvatore. *Et pro omnibus mortuus est Christus, ut et qui vivunt* vita naturæ seu gratiæ, *jam non sibi vivant*, id est, non propriæ voluntati deserviant, videlicet ad honorem proprium vitam suam ordinent; *sed ei* vivant, id est, ad ejus honorem et gloriam omnia opera sua interiora exterioraque referant, *qui pro ipsis mortuus est et resurrexit*, videlicet Christi. Sic vivere Christo, est vere abnegare atque vivifice mortificare se ipsum.[^17][^18]

16

*Itaque,* id est, quia pro omnibus mortuus est Christus, nos Apostoli et viri perfecti, *ex hoc,* id est posthac, *neminem novimus* notitia approbationis, id est, nullum viatorem laudamus, secundum carnem, id est carnaliter, scilicet propter causas indignas. Vel, Neminem novimus secundum carnem, id est secundum ea quæ carnis conditionem respiciunt: talia enim non curamus neque attendimus. *Et si cognovimus secundum carnem Christum,* id est, quamvis mysteria Christi carnaliter et superficialiter intellexerimus, et Christum non nisi secundum humanam naturam noverimus sensu humano; *sed nunc jam* Spiritu Sancto recepto *non novimus* eum hoc modo, sed spiritualiter ac supernaturaliter, tanquam Deum et hominem.

17

*Si qua ergo,* id est quia aliqua, *in Christo est nova creatura,* id est, aliquis in Christi Baptismo renatus est, *vetera transierunt,* id est, pristina vitia ab illo remota sunt, pœnalitates quoque deletæ sunt, modo in spe, tandem delendæ in re; *ecce facta sunt omnia nova,* id est, per infusionem Spiritus Sancti omnia spiritualiter renovata sunt, corpus, anima, cogitatio, verbum et opera.[^19] Unde in Apocalypsi dicitur: Dixit qui sedebat in throno, Ecce nova facio omnia. *Omnia autem ex Deo* Patre vel sancta Trinitate originaliter profluxerunt et condita sunt, *qui nos reconciliavit sibi,* id est, peccata nostra nobis ignovit, *per Christum,* id est incarnatione, passione seu merito Christi hominis: imo Christus ut Deus, reconciliavit nos sibi per se ipsum, ut hominem talem; *et dedit nobis ministerium reconciliationis,* id est, officium evangelicæ

18 prædicationis, qua ista reconciliatio annuntiatur hominibus, commisit nobis suis vicariis. *Quoniam quidem Deus* Pater, vel Verbum increatum, imo et Spiritus Sanctus, hoc est Deus Trinitas, *erat in Christo* homine *mundum,* id est electos, *reconcilians sibi* (ut dictum est), *non reputans,* id est non juste ulciscens, nec in æternum reservans, *illis delicta ipsorum* originalia aut actualia. Christus namque Agnus Dei omnia tulit peccata. *Et posuit in nobis verbum reconciliationis,* id est prædicationem pacificationis inter Deum et homines factæ.

*Pro Christo ergo,* id est pro Christi amore et gloria, *legatione,* id est missione, *fungimur,* quia a Deo missi sumus annuntiare Evangelium Christi, *tanquam Deo exhortante* corda audientium *per nos, id est per* prædicationem nostram. Ipse enim loquitur per nos. *Obsecramus pro Christo,* id est vice, loco, vel amore Christi, *reconciliamini Deo,* id est, peccata vestra deflete, vitam corrigite, Deo placere contendite. *Eum qui non noverat peccatum per* approbationem vel experientiam, scilicet Christum, Pater *pro nobis, id* est pro nostra redemptione, *peccatum fecit,* id est hostiam pro peccato. Sumitur enim hic peccatum pro hostia peccati, sicut et apud Osee, ubi dicitur: Peccata populi mei comedent. Vel sic: Eum qui non noverat peccatum, pro nobis peccatum, id est culpam, fecit. Peccatum enim, præcipue originale, occasio fuit incarnationis passionisque Christi, sicque quodam modo fecit eum hominem.

*Ut nos efficeremur justitia Dei,* id est justificati a Deo, *in illo,* id est merito Christi.

# Articulus 4

ELUCIDATIO CAPITULI QUARTI: IDEO HABENTES HANC ADMINISTRATIONEM.

LAUDAVIT se sanctus Apostolus ad gloriam Dei et ædificationem audientium, in præcedenti capitulo, ratione dignitatis ministerii sibi commissi; nunc idem facit ex debito usu obsequii sui, ostendens se fructuose et optime usum gratia sibi concessa.

*Ideo,* id est, quoniam tantam claritatem a Spiritu Sancto suscepimus, *habentes hanc administrationem* novæ legis, videlicet apostolatum seu ministerium tantæ dignitatis, *juxta quod misericordiam consecuti sumus,* id est secundum mensuram divinæ pietatis nobis impensæ, *non deficimus* in adversis, nec ab exsecutione nostri cessamus officii, *sed abdicamus,* id est abjicimus, *occulta dedecoris,* id est vitia latentia, quæ non decent, sed deformant et indecorant; *non ambulantes in astutia,* id est, non dolose aut simulatorie conversantes sicut hypocritæ.[^1] Simulatores namque et callidi provocant iram Dei. Astutia autem quandoque in bono accipitur, pro quadam circumspectione, sicut in Proverbiis legitur:[^2][^3] Astutus considerat gressus suos. Nunc vero pro versutia sumitur. Unde Salomon: Vir, inquit, versutus odiosus est. *Neque adulterantes,* id est, perverse interpretantes, seu admiscentes falsitatibus, *verbum Dei,* videlicet Evangelium Christi; *sed in manifestatione veritatis* conversamur, id est, ipsam veritatem publice prædicamus et clare exponimus, *commendantes,* id est commendabiles seu laude dignos facientes, *nosmetipsos,* recte docendo et bene agendo, *ad omnem conscientiam hominum*, id est testimonia conscientiarum, vel in conscientiis hominum, ita ut nemo bona conscientia vituperare nos poterit. Et hoc facimus *coram Deo*, id est divinam præsentiam cogitando, nosque in Dei cuncta cernentis conspectu ponendo, cum omni reverentia atque custodia cordis.

*Quod si etiam opertum est Evangelium nostrum*, id est, si prædicatio nostra de Christo aliquibus absconditur, ita ut eam non audiant, vel auditam non capiant; *in his qui pereunt*, id est in cordibus reproborum, *est opertum*, id est, occultatum est hoc modo: *In quibus deus hujus sæculi*, id est diabolus dominus impiorum (de quo ait Salvator:[^4] Venit princeps hujus mundi), *excæcavit cooperative* seu suggestive *mentes infidelium*. Vel: Deus hujus sæculi, id est Deus verus omnium sæculorum, hominumque malorum creator et Deus, excæcavit mentes, id est intellectus infidelium, permissive:[^5] quemadmodum dicitur Pharaonis cor indurasse. Unde et Christus in Evangelio:[^6] In judicium, inquit, ego in hunc mundum veni, ut qui non vident, videant;[^7] et qui vident, cæci fiant. *Ut non fulgeat*, id est innotescat, *eis illuminatio Evangelii*, id est evangelica doctrina, *gloriæ*, id est majestatis, *Christi, qui est imago Dei*, id est a Patre secundum rationem similitudinis genitus. Est enim a Patre procedens, eique similis et æqualis per omnia. Propter quod ipse ait: Qui videt me, videt et Patrem.[^8] Porro quod Christus sit imago Dei, hinc liquet:

*Non enim nosmetipsos prædicamus*, quasi in nobis salus vestra consistat, *sed Jesum Christum Dominum nostrum* prædicamus esse omnium salvatorem; *nos autem servos vestros* esse prædicamus, hoc est, vobis servientes in exhibitione spiritualium alimentorum, parantes vobis mensam Domini, spiritualemque escam proponentes, *per Jesum*, id est ex commissione et per gratiam Christi, qui nobis hoc injunxit officium. *Quoniam Deus* trinus, simplex atque omnipotens, *qui dixit*, id est, interiori verbo fecit, *de tenebris*, id est post tenebras, vel, De tenebris, id est de materia obscura, *lucem* sensibilem *splendescere*, id est inchoative oriri. Unde dicitur in Genesi:[^9] In principio creavit Deus cœlum et terram, et tenebræ erant super faciem abyssi; dixitque Deus, Fiat lux; et facta est lux. *Ipse illuxit in cordibus nostris*, id est, lumen fidei atque divinæ sapientiæ mentibus nostris infudit, *ad illuminationem scientiæ claritatis Dei*, id est ad hoc ut nos illuminemur ad cognoscendum claritatem, id est nobilitatem seu excellentiam Dei; vel, Ad illuminationem, etc., id est ad hoc ut alios doceamus de notitia claritatis Dei, id est perfectionis divinæ: illuminationem, inquam, scientiæ tendentis *in faciem Jesu Christi*, id est dirigentis nos ad veram Christi notitiam, qua eum agnoscimus esse Deum et hominem. Facies autem notitiam significat, quia per faciem unusquisque potissimum cognoscitur.

*Habemus autem thesaurum istum*, id est gratiam tantæ illuminationis. Unde et Salomon:[^10] Thesaurus, inquit, desiderabilis in ore sapientis; et rursus:[^11] Pretiosior est sapientia cunctis opibus; et omnia quæ desiderantur, huic non valent comparari. *In vasis fictilibus*, id est corporibus fragilibus. Non quod corpus, quod est pars integralis hominis, sit hujus thesauri subjectum immediatum, sed anima: quoniam tamen animæ subjectum est corpus, ideo nos in corpore peregrinantes, dicimur thesaurum istum habere in vasis fictilibus. *Ut sublimitas*, id est altitudo nostræ perfectionis in vita, in signis, in documentis, *sit virtutis Dei*, id est, Deo adscribatur, non nostræ fragilitati. Ideo additur: *et non ex nobis*, id est, non ex nostra naturali potestate oriri putetur.

*In omnibus*, loco, causa et tempore, saltem in genere, *tribulationem patimur* propter justitiam; *sed non angustiamur*, id est, non opprimimur mente, quia de Dei auxilio certi sumus. *Aporiamur*, id est, temporalibus bonis privamur et pauperes sumus; *sed non destituimur*, id est, non caremus spiritualibus verisque divitiis: imo in his tanto magis abundamus, quanto in illis pauperiores propter Christum sumus.[^12] Etenim beati pauperes, quoniam ipsorum est regnum cœlorum. *Persecutionem*, id est de loco ad locum fugationem, *patimur*; *sed non derelinquimur* a Deo. *Dejicimur*, id est conculcamur; *sed non perimus*, quoniam liberamur semper a Domino corporaliter aut spiritualiter, et interim utroque modo.

*Semper mortificationem Jesu*, id est passionem dominicam, *in corpore nostro circumferentes*, per cruciformem imitationem et corporis quotidianam flagellationem. Unde alibi dicit Apostolus:[^13] In omni fiducia magnificabitur Christus in corpore meo, sive per vitam, sive per mortem;[^14] item, Ego stigmata Domini Jesu in corpore meo porto. *Ut et vita Jesu*, id est conversatio quam habuit in hoc mundo, *in corporibus nostris manifestetur*, id est, Christi vestigia in agendo sectemur; vel, Vita Jesu immortalis quam nunc habet, in corporibus nostris manifestetur in resurrectione futura, quando reformabit corpus humilitatis nostræ configuratum corpori claritatis suæ.[^15] *Semper enim*, id est in omni differentia temporis in genere, *nos* Apostoli et alii successores nostri, *qui vivimus* nunc in vita naturæ et gratiæ, *in mortem tradimur*, id est, periculis mortis afficimur, *propter Jesum*, id est ejus amore, et propter prædicationem evangelicæ veritatis:[^16] sicut et Christus prædixit, Venit hora ut omnis qui interficit vos, arbitretur obsequium se præstare Deo;[^17] et denuo, Eritis odio omnibus hominibus propter Filium hominis; *ut et vita Jesu*, quam habet jam immortalis, *manifestetur in carne nostra mortali*, id est, gloria immortalitatis nostræ carni præstetur, quando corruptibile hoc induet incorruptionem, et mortale hoc immortalitatem.[^18]

*Ergo mors,* id est passio Christi, *in nobis operatur*, id est, fructuosa est nobis, excitando nos ad sui imitationem. *Vita autem* naturæ seu culpæ, *operatur in vobis* qui Christi vestigia imitari negligitis; vel, Vita gratiæ, scilicet fides et caritas, operatur in vobis opera meritoria: quia per hoc quod nos taliter mortificamur, vos ad Deum convertimini, et vivitis coram illo.

Consequenter ostendit eamdem fuisse fidem in populo utriusque Testamenti, tractatque de diversis effectibus, meritis et actibus fidei. *Habentes autem* nos novi Testamenti ministri *eumdem spiritum fidei*, id est Spiritum Sanctum fidei datorem, quem habuerunt Sancti antiqui. Vel per spiritum fidei, intelligenda est ipsa fides, vel gratia seu motio fidei, quæ una et eadem est in his qui ante Christi adventum fuerunt, et in posterioribus, quamvis sit modo magis explicita. *Sicut scriptum est* in libro Psalmorum a David propheta:[^19] Credidi corde, *propter quod locutus sum* ore verba fidelis confessionis. Confessio namque ista est actus fidei. Unde alibi dictum est:[^20] Corde creditur ad justitiam, ore autem confessio fit ad salutem. *Et nos credimus* ea quæ illi, *propter quod et loquimur* fidem catholicam, confitendo ac prædicando; *scientes* fide certissima, *quoniam* Deus Pater seu Trinitas, *qui suscitavit Jesum* occisum a morte, *et nos electos cum Jesu*, id est sicut et Jesum, vel ad hoc ut simus cum Jesu in regno, *suscitabit* in die novissimo, *et constituet* nos vobiscum ad dexteram in patria, ubi agni ponentur.[^21]

*Omnia enim propter vos*, id est, universa ministeria nostra ad vestram ordinantur salutem, *ut gratia* Dei *abundans per multos*, id est ab uno transfusa seu ministrata in alium: secundum quod Petrus hortatur, Unusquisque sicut accepit gratiam, in alterutrum illam administrantes;[^22] *in gratiarum actione abundet*, id est, cum gratiarum actione copiose referatur et ordinetur, seu refluat ad suum principium, scilicet Deum, *in gloriam Dei,* quatenus omnes Deo gratias referant, et omne charisma gratiæ illi tribuant.[^23] *Propter quod* prosequendum, videlicet ut Deo gratiæ referantur, *non deficimus* in adversis, nec fatigamur in opere bono, nec cessamus, quoniam sola perseverantia coronatur. *Sed licet is qui foris est, noster homo,* id est caro nostra mortalis, in qua est humana effigies qua homines esse cognoscimur, *corrumpatur,* quotidie tendendo ad mortem, et sustinendo læsuras ac plagas ; *tamen is qui intus est,* id est anima nostra, in qua est summæ Trinitatis imago, *renovatur,* recipiendo nova lumina gratiarum, reflorendo in Dei cognitione, ascendendo in divino amore, *de die in diem,* id est assidue, dum spiritualiter crescimus atque proficimus. Hoc autem dicitur, non quasi in nobis sint duo homines, sed propter distinctionem essentialium partium hominis.

*Id enim quod in præsenti* exsilio seu tempore *est momentaneum et leve tribulationis nostræ,* id est tribulatio ista levis (comparatione futuræ jucunditatis ac æternitatis) quam patimur jam, *supra modum,* id est ultra conceptum et capacitatem nostri intellectus, *in sublimitate,* id est in regno cœlesti vel in liberalitate bonitatis divinæ, *æternum gloriæ pondus,* id est perpetuam felicitatis mensuram : de qua ait Salvator. Mensuram bonam et confertam et cogitatam et supereffluentem dabunt in sinum vestrum ; *operatur,* id est, meretur efficit, *in nobis,* nunc per spem, postodum vero in re, *non contemplantibus nobis,* id est, quia non principaliter adspicimus, nec finaliter intueamur, *quæ videntur,* id est visibilia et terrena, *sed quæ non videntur,* id est bona supercœlestia quæ oculus non vidit, nec auris audivit. *Quæ enim videntur* a nobis oculo corporali, *temporalia sunt,* id est transitoria et caduca ; *quæ autem non videntur,* id est spiritualia bona nobis præparata in regno, æterna sunt essentialiter vel participative.

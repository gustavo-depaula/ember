# Articulus 3

DECLARATIO CAPITULI TERTII: IGITUR SI CONSURREXISTIS, ETC.

EXPLETA informatione Apostoli de vitandis legalibus et naturalibus versutiis, jam inducitur moralis instructio. *Igitur,* id est, quia legalia cessaverunt, et vos cum Christo mortui estis, *si consurrexistis* a lapsu peccati, *cum Christo,* id est, sicut Christus surrexit a tumulo. Peccator enim jacet prostratus in vitiis, justus vero stat in virtutibus erectus. Quum autem peccator pœnitentiam agit et confitetur, resurgit per gratiam a propriis malis. *Quæ sursum sunt quærite,* id est, cœlestia præmia desiderate, et summum bonum semper intendite, illa utique quæ oculus non vidit, nec auris audivit, nec in cor hominis ascenderunt, *ubi,* id est in quo loco superiori, *Christus est in dextera Dei,* id est ad dexteram Patris, *sedens* tanquam omnium judex ac Dominus, juxta illud:[^1][^2][^3] Dominus Jesus assumptus est in cœlum, et sedet a dextris Dei. Denique Christus secundum suam divinitatem, sedet, id est consistit, ad dexteram Patris, id est in æqualitate majestatis paternæ; secundum humanitatem vero assumptam, sedet, id est, corporaliter manet, ad dexteram Dei, id est in bonis potioribus Patris. Omnia enim creata Christo homini sunt subjecta.[^4] *Quæ sursum sunt sapite,* id est, spiritualia mentis affectu gustate et corde sincero perpendite, *non quæ super terram,* id est non carnalia et terrena, ut dicere valeatis cum Isaia: Nomen tuum et memoriale tuum,[^5]

Domine, in desiderio animæ meæ; anima mea desideravit te in nocte, sed et spiritus meus in præcordiis meis. Et cum Psalmista: Quam magna multitudo dulcedinis tuæ, Domine! Itemque cum Sponsa: Indica mihi, quem diligit anima mea, ubi pascas, ubi cubes in meridie.

3

*Mortui enim estis* rebus mundanis ac vanis, id est, in talibus occupari non debetis; vel, Mortui estis, id est in Baptismo configurati morti Christi; *et vita vestra* quam habituri estis in patria, *abscondita est,* id est reposita et latenter consistens, *cum Christo in Deo,* id est in Deo Patre, in cujus corde et sinu Christus incomprehensibiliter conquiescit: quoniam nemo novit Filium, nisi Pater. Hæc autem vita æterna, est nostra felicitas, in Deo objectaliter sita, de qua dicit Salvator ad Patrem: Hæc est vita æterna: ut cognoscant te solum Deum verum, etc. Vel sic: Vita vestra, id est vita gratiæ et gloriæ, abscondita, id est ignota, est omnibus viatoribus in Deo, qui eam cognoscit atque causaliter continet. Nemo enim novit utrum dignus sit amore an odio. *Quum autem Christus apparuerit,* id est, evidenter innotuerit esse, *vita vestra objective*, id est vivificator et beatificator vester: quod maxime erit in die extremi judicii, quando in conspectu universorum, Christus electorum suorum vita monstrabitur; *tunc et vos apparebitis cum ipso in gloria,* id est, anima et corpore gloriosi eritis, atque cum Christo alta cœlorum penetrabitis, ibi cum eo in cœlesti gloria sine fine mansuri.

Præterea, docet Apostolus quomodo ad hanc beatitudinem valeamus pertingere. *Mortificate,* id est destruite, *ergo,* videlicet ut vitam hanc sempiternam mereamini adipisci, *membra vestra quæ sunt super terram,* id est vitia corporis quæ per membra explentur. Unde quasi exponens quid dixerit membra, adjecit: *fornicationem,* id est concubitum soluti cum soluta, *immunditiam,* id est peccata contra naturam, *libidinem,* id est ardorem

B

*Nunc autem deponite et vos omnia* quæ sequuntur, videlicet: *iram,* quæ inordinatus appetitus est vindictæ propter parvipensionem, *indignationem,* quæ ex superbia et ira procedit, *malitiam,* id est machinationem mali in alium corde conceptam, *blasphemiam* contra Deum et Sanctos, *turpem,* id est impudicum, *sermonem,* deponite *de ore vestro. Nolite mentiri invicem.* Os enim quod mentitur, occidit animam, ut dicitur in libro Sapientiæ.

C

*Exspoliantes vos,* id est exuentes, *veterem hominem,* id est pristinum statum, vel vosmetipsos quoad id quod fuistis per culpam, *cum actibus suis* vitiosis; *et induentes novum,* id est, per opera bona ac sacramenta et gratiam, induite hominem spiritualiter reformatum, id est, vos ipsos innovate interius, *qui novus homo renovatur* et crescit quotidie *in agnitionem Dei,* id est contemplando divina. Renovatur autem hoc modo: *secundum imaginem ejus,* id est quantum ad partem intellectivam, in qua est imago ejus *qui fecit eum,* id est summi Creatoris, cujus imago resplendet in superiori parte animæ rationalis: quæ pars potestativa renovatur quotidie recipiendo a Deo gratiæ incrementa, ornamenta virtutum et sapientiæ claritatem; *ubi,* id est in quo homine interiori ac novo, videlicet in parte animæ intellectiva, *non est masculus* ne-

10

11 *que femina,* id est discretio sexus, quæ attenditur secundum corpus, non animam; nec est ibi *gentilis et Judæus,* id est discretio generis, quoniam omnes quantum ad animam, immediate a Deo creantur, *circumcisio et præputium,* id est differentia observationis seu ritus, *Barbarus et Scytha,* id est differentia linguarum, *servus et liber,* id est distinctio conditionis. Est itaque sensus, quod propter ista non est unus dignior vel indignior coram Deo. Nam quantum ad hominem interiorem, nulla diversitas exterior sexuum, nationum, observationum, linguarum aut conditionum, præjudicat alteri. *Sed omnia et in omnibus Christus,* id est, Christus est omnia causaliter, omnibus generibus atque operibus hominum dans exsistentiam ac permanentiam. Ipse quoque in omnibus est per gratiam vel providentiam.

*Induite ergo vos sicut electi Dei,* id est a Deo prædestinati, ut speramus vel Deo revelante cognoscimus, *sancti,* id est a vitiis emundati per sacramenta Ecclesiæ, *et dilecti* a Deo, recipiendo beneficia ejus, *viscera misericordiæ,* id est internos pietatis affectus, *benignitatem,* id est animi præparationem ad benefaciendum proximis vel ipsum misericordiæ opus, *humilitatem, modestiam,* id est moderamen in verbis ac factis, *patientiam; supportantes invicem*: sicut Galatis dictum est, Alter alterius onera portate;[^6] et item Romanis, Debemus nos firmiores, imbecillitates infirmorum sustinere;[^7] *et donantes vobismetipsis,* id est mutuo ignoscentes, *si quis adversus aliquem habet querelam,* id est, si unus vestrum ab alio est offensus, seu injuriam passus. *Sicut et Dominus* Christus seu Trinitas *donavit,* id est, indulsit pure, gratis et festinanter, vobis, ita et vos vestris debitoribus indulgete. Unde dicit Salvator: Exemplum dedi vobis, ut quemadmodum ego feci vobis, ita et vos faciatis;[^8][^9] alibi quoque, Si non dimiseritis de cordibus vestris, nec Pater vester dimittet vobis peccata vestra. Denique quam enorme sit ita non agere, constat per ea quæ in Ecclesiastico scribuntur:[^10] Homo homini servat iram, et a Deo quærit medelam? In hominem sibi similem non habet misericordiam, et de peccatis suis deprecatur Altissimum? Quis exorabit pro peccatis illius?

*Super omnia autem hæc, caritatem habete,* id est, hoc præ ceteris omnibus hortor, et summe necessarium utilissimumque est, ut caritatem Dei et proximi habeatis.

Propter quod ait Salvator:[^11] Mandatum novum do vobis, ut diligatis invicem. *Quod,* id est quam caritatem habere, *est vinculum perfectionis,* id est aliarum virtutum conservatio, consummatio, nexus ac ligamentum. Caritas enim est præstantissima virtus, omnes virtutes movens, perficiens et meritorias reddens:[^12] qua subtracta, nulla virtus meritoria permanet.

Propterea beatissimus Archiapostolus in prima sua Canonica: Ante omnia, inquit, mutuam in vobis caritatem continuam habentes, quoniam caritas operit multitudinem peccatorum.[^13] *Et pax Christi,* id est interna et vera pax, scilicet tranquillitas cordis, seu quies mentis in Deo, *exsultet,* id est, redundantem lætitiam pariat, *in cordibus vestris.* Pace enim quid dulcius, quidve jucundius esse potest? *In qua pace et vocati estis in uno corpore* mystico: id est, per pacem positi estis inter membra Christi; imo ad hoc vocati estis in unam Ecclesiam, ut sempiternam sortiamini pacem. Unde dictum est alibi:[^14] In pace vocavit nos Dominus. *Et grati estote* Deo pro universis beneficiis ejus. Qui enim gratias agit, donis potioribus meretur impleri, juxta illud in Evangelio: Omni habenti dabitur, id est grato.[^15]

*Verbum Christi,* id est evangelica doctrina ex ore Christi prolata, *habitet,* id est stabiliter maneat, *in vobis,* id est in mentibus vestris per jugem memoriam et veram obedientiam: juxta illud in Psalmo, In corde meo abscondi eloquia tua, ut non peccem tibi;[^16] *in omni sapientia,* id est intellectu sapientiali totius Scripturæ sacræ, quatenus verba Christi sapienter intelligatis, *docentes et commonentes*, id est exhortantes, *vosmetipsos* ad opera perfectiora, *in psalmis*, qui ad bonam operationem hortantur, *et hymnis*, in quibus divina laus continetur, *et canticis spiritualibus*, quæ de cœlestibus bonis futurisque gaudiis agunt;[^17] *in gratia* gratificante, sine qua nihil est meritorium; vel, In gratia, id est cum gratiarum actione; vel, In gratia, id est consideratione gratuitorum beneficiorum Dei; *cantantes*, id est laudem dicentes, *in cordibus vestris*, id est cordiali affectu et cum mentali attentione, Deo: quemadmodum scriptum est, Laudabit usque ad mortem anima mea Dominum;[^18] et in Psalmo, Cantabo Domino in vita mea, psallam Deo meo quamdiu sum.[^19] Hoc dicitur contra eos qui non corde, sed labiis Deum glorificant: de quibus per Isaiam Dominus contestatur, Appropinquat populus iste ore suo, et labiis glorificat me, cor autem ejus longe est a me.[^20] *Omne quodcumque facitis in verbo*, id est prædicando, docendo, hortando, orando, cantando, *aut in opere* exteriori, *omnia in nomine Domini nostri Jesu Christi*, id est ad gloriam Christi, et cum invocatione nominis ejus, *facite, gratias agentes Deo et Patri*, id est sanctæ Trinitati, cui quotidie dicimus:[^21] Pater noster, qui es in cœlis; *per ipsum*, id est ex consideratione beneficiorum quæ Trinitas nobis largita est per mediatorem nostrum hominem Christum.[^22]

Præterea descendit Apostolus ad moralem particularium personarum instructionem. *Mulieres, subditæ estote viris*, id est maritis vestris, *sicut oportet in Domino*, id est, sicut Deus instituit, dicens mulieri: Sub viri potestate eris, et ipse dominabitur tui.[^23] Vel, Sicut oportet in Domino, id est in licitis et honestis quæ complacent Deo. *Viri, diligite uxores vestras*, non solum maritali et naturali affectu, sed spirituali dilectione, *et nolite amari esse ad illas*, sed secundum scientiam cohabitate illis, tanquam infirmioribus vasculis impertientes honorem.[^24] Unde in Ecclesiastico habetur: Noli esse sicut leo in domo tua, evertens domesticos tuos, et opprimens tibi subjectos.[^25] *Filii, obedite parentibus per omnia* quæ sunt apta materia obedientiæ, id est in cunctis bonis ac licitis, et majus bonum non impedientibus. *Hoc enim placitum est in Domino*.[^26] Nam Deus hoc jussit. *Patres, nolite ad indignationem provocare filios vestros*, habendo vos indiscrete et non paterne ad eos, *ut non pusillo animo fiant*, id est, ne per pusillanimitatem frangantur, et obedire desistant, non valentes ferre duritiam vestram. Omnia hæc ad spirituales patres eorumque filios maxime pertinent.

*Servi, obedite per omnia*, id est in omnibus bonis, *dominis carnalibus*, id est temporalibus, in corporalibus dominationem exercentibus; *non ad oculum servientes*, id est non solo servili timore et in dominorum vestrorum præsentia, *quasi hominibus placentes*, id est tanquam hoc solum optantes et intendentes, ut hominibus placeatis, et non potius Deo, *sed in simplicitate cordis*, id est, sincera intentione servite dominis illis carnalibus, etiam dyscolis, *timentes Deum* casto ac filiali timore, cujus præsentiam seu conspectum non potestis effugere.[^27] *Quodcumque facitis in obsequio dominorum vestrorum*, *ex animo*, id est cum promptitudine voluntatis, *operamini*, utpote amore justitiæ atque intuitu mercedis divinæ, non timore pœnæ et solo intuitu remunerationis humanæ: talem enim animam approbat Deus; *sicut Domino* Deo principaliter servientes, *et non hominibus* tantum: quia etsi hominibus deservitis, hoc tamen propter Deum libenter facere debetis, quasi sustinentes hanc servitutem ex ordinatione divina, pro pœna peccati cui obnoxii estis.[^28] Servitus nempe ob culpam inducta est. *Scientes* fide certissima, *quod a Domino accipietis retributionem hereditatis*, id est præmium vitæ æternæ, quæ est hereditas electorum. Retributio autem hereditatis aliud non est nisi ipsa hereditas quæ donatur. Hanc hereditatem habebitis, si præfato modo servientes fueritis. *Domino* Jesu *Christo servite* summe atque finaliter, imo et latriæ servitute, quæ soli Deo debetur.

Qui enim injuriam facit alteri, infideliter serviendo, aut alio modo, *recipiet id quod inique gessit*, id est, pro sua injustitia debitam pœnam exsolvet, juxta illud Psalmistæ: Qui custodit veritatem in sæculum, facit judicium injuriam patientibus;[^29] et alibi, Mihi vindictam, et ego retribuam, dicit Dominus.[^30] *Et non est personarum acceptio apud Deum*. Hoc jam ubertim dictum atque expositum est.[^31][^32] Deus enim neminem ad se venientem, vel quod in se est facientem, repellit; nullius etiam peccata inulta dimittit.[^33] Unde ipse Dominus in Joanne testatur:[^34] Eum qui venit

ad me, non ejiciam foras. Et alibi ait Scriptura: Deus opus hominis reddet ei, et juxta vias singulorum restituet;[^35] itemque, Si direxerit homo ad Deum cor suum, spiritum illius et flatum ad se trahet.[^36] Ex his tamen non sequitur, quin Deus justus ac sapiens ab æterno elegerit unum præ alio, etiam absque omni merito hominum.

*Domini, quod justum est* ratione obsequii vobis exhibiti, *et æquum propter conformitatem naturæ* in vobis ac servis, *servis vestris præstate*, videlicet dignam mercedem et piam subventionem ac miserationem; *scientes quoniam et vos Dominum* justum ac infallibilem judicem *habetis in cælo*, qui eadem mensura qua mensi fueritis, remetietur vobis. Sic enim facit homini, quemadmodum homo proximo suo.

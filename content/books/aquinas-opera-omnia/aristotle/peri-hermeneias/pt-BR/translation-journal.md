## Decisões

- Exemplos linguísticos traduzidos quando o argumento não depende do latim (‘homem’, ‘branco’, ‘dia’, ‘amanhã’, ‘Peixe’, ‘corre’, ‘O cão ladra’, ‘túnica’); mantidos em latim quando depende da forma (*equiferus*, *biltrix*, *sorex*/*rex*).
- Proposições indefinidas (*Homo est albus*) → ‘O homem é branco’: o português exige o artigo; o contexto deixa claro que não há sinal de quantidade. *Quidam homo* nos exemplos → ‘Algum homem’, forma corrente da particular em português. *Est homo* / *Homo est* (g3-c001) → ‘O homem é’; *Est non homo* → ‘O não-homem é’. *Est iustus homo* (lema 19b20) → ‘O homem é justo’; *Est non iustus homo* → ‘O homem é não-justo’.
- *Non omnis* → ‘nem todo’ (sinal particular negativo); *non ullus* → ‘nem um’, que espelha a formação de ‘nenhum’.
- *Videns* (g2-c010 [87]) → ‘está vendo’: ‘vidente’ sugeriria clarividência. Em g3-c002 [327] (*videns non caecum*) → ‘quem vê é não-cego’. Em [701], *Socrates est videns* → ‘Sócrates está vendo’; *caecum esse est privatio huius quod est esse videntem* → “ser cego é privação disto que é estar vendo”.
- *Homo fit albus* → ‘O homem vem a ser branco’, para conservar o par *fieri* / *factum esse* (vir a ser / ter vindo a ser) de que depende o argumento.
- *Catonis* / *Catoni* → ‘de Catão’ / ‘a Catão’: o português exprime os casos por preposição, e o argumento (só o nominativo é nome) continua legível.
- *Poenitet Socratem* / *Poenitentia habet Socratem* → ‘Pesa a Sócrates’ / ‘O pesar possui Sócrates’: o verbo impessoal *pesar* conserva o oblíquo regido pelo verbo.
- *Hoc nomen ‘lapis’ imponitur a laesione pedis* → ‘pedra’, com nota do tradutor sobre a etimologia de Isidoro (g2-c004 [45]).
- *Currere est currentem esse* (g2-c005 [77]) → ‘correr’ é ‘ser corrente’: o particípio presente, hoje raro, mantém o verbo ‘ser’, de que depende o argumento. O mesmo em g3-c002 [143] (*omnis homo est currens* → ‘Todo homem é corrente’). *Ambulans* → ‘andante’ (g3-c002 [218]ss., lema 21a7, [396]).
- 16b10 *de subiecto vel in subiecto* → “de um sujeito ou num sujeito”, segundo a distinção das *Categorias* (dito de um sujeito / estar num sujeito).
- 16b23 *purum* → “puro”; a variante grega citada por Tomás, *nudum*, → “nu”.

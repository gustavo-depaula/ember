# Questão 94

***Em seguida, deve-se considerar a idolatria. E acerca disso perguntam-se quatro coisas.***

Primeiro, se a idolatria é uma espécie de superstição.

- Segundo, se é pecado.
- Terceiro, se é o mais grave dos pecados.
- Quarto, da causa deste pecado. Se se deve ter comunhão com os idólatras, já foi dito acima, quando se tratou da infidelidade.

# Questão 8

***Da vontade, quanto ao fim***

Em seguida, devem-se considerar os próprios atos voluntários em especial. E primeiro, os atos que são imediatamente da própria vontade, como elícitos pela própria vontade; segundo, os atos imperados pela vontade.

Ora, a vontade se move tanto para o fim como para as coisas que são para o fim. Primeiro, pois, devem-se considerar os atos da vontade pelos quais ela se move para o fim; e depois, os seus atos pelos quais se move para as coisas que são para o fim. Os atos da vontade em relação ao fim parecem ser três: querer, fruir e intencionar. Primeiro, portanto, consideraremos a vontade; segundo, a fruição; terceiro, a intenção. Acerca do primeiro, devem-se considerar três coisas: primeiro, de que coisas é a vontade; segundo, por que é movida; terceiro, como é movida.

Acerca do primeiro, perguntam-se três coisas.

Primeiro, se a vontade é somente do bem.

- Segundo, se é somente do fim, ou também das coisas que são para o fim.
- Terceiro, se é de algum modo das coisas que são para o fim, se se move com um só movimento para o fim e para as coisas que são para o fim.

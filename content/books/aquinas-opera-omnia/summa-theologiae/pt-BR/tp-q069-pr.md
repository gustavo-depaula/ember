# Questão 69

***Em seguida, devem-se considerar os efeitos do Batismo. A esse respeito, investigam-se dez pontos.***

Primeiro, se pelo Batismo são tirados todos os pecados.

- Segundo, se pelo Batismo o homem é libertado de toda pena.
- Terceiro, se o Batismo tira as penalidades desta vida.
- Quarto, se pelo Batismo são conferidas ao homem graças e virtudes
- Quinto, sobre os efeitos das virtudes que são conferidos pelo Batismo.
- Sexto, se também as crianças pequenas recebem graças e virtudes no Batismo.
- Sétimo, se pelo Batismo se abre aos batizados a porta do reino celeste.
- Oitavo, se o Batismo tem igual efeito em todos os batizados.
- Nono, se o fingimento impede o efeito do Batismo.
- Décimo, se, cessando o fingimento, o Batismo produz seu efeito.

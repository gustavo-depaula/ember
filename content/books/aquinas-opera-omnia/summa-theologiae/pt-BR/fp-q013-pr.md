# Questão 13

***Sobre os nomes de Deus***

Consideradas as coisas que pertencem ao conhecimento *(*a) cognitionem.—perfectionem* PFG e edd. *a b*.)* de Deus, deve-se passar à consideração dos nomes divinos; pois cada coisa é nomeada por nós segundo o modo como a conhecemos.

A respeito disso, portanto, investigam-se doze pontos.

Primeiro, se Deus é nomeável por nós.

- Segundo, se alguns nomes ditos de Deus são predicados dele substancialmente.
- Terceiro, se alguns nomes ditos de Deus são ditos dele propriamente, ou se todos lhe são atribuídos metaforicamente.
- Quarto, se os muitos nomes ditos de Deus são sinônimos.
- Quinto, se alguns nomes são ditos de Deus e das criaturas univocamente ou equivocamente.
- Sexto, supondo que sejam ditos analogicamente, se são ditos antes de Deus ou das criaturas.
- Sétimo, se alguns nomes são ditos de Deus temporalmente.
- Oitavo, se este nome “Deus” é nome de natureza ou de operação *(*operationis. — comparationis* D.)*.
- Nono, se este nome “Deus” *(*hoc nomen Deus. -* Om. códices e ed. *a*.)* é nome comunicável.
- Décimo, se é tomado univocamente ou equivocamente, conforme significa Deus por natureza, por participação e segundo a opinião *(*secundum opinionem.—per operationem* AEFG*a, operationem* B, *per comparationem* CD.)*.
- Undécimo, se este nome “Aquele que é” é o nome mais próprio de Deus.
- Duodécimo, se se podem formar proposições afirmativas sobre Deus.

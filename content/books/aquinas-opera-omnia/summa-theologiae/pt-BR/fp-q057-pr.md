# Questão 57

Em seguida, investigam-se as coisas materiais que são conhecidas pelos anjos. E acerca disso perguntam-se cinco coisas.

Primeiro, se os anjos conhecem as naturezas das coisas materiais.

- Segundo, se conhecem os singulares.
- Terceiro, se conhecem as coisas futuras.
- Quarto, se conhecem os pensamentos dos corações.
- Quinto, se conhecem todos os mistérios da graça.

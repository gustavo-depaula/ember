# Questão 79

Em seguida, devem-se considerar os efeitos deste sacramento. A esse respeito, investigam-se oito pontos.

Primeiro, se este sacramento confere a graça.

- Segundo, se o efeito deste sacramento é a obtenção da glória.
- Terceiro, se o efeito deste sacramento é a remissão do pecado mortal.
- Quarto, se por este sacramento se perdoa o pecado venial.
- Quinto, se por este sacramento se perdoa toda a pena do pecado.
- Sexto, se este sacramento preserva o homem dos pecados futuros.
- Sétimo, se este sacramento beneficia outras pessoas além das que o recebem.
- Oitavo, sobre os impedimentos ao efeito deste sacramento.

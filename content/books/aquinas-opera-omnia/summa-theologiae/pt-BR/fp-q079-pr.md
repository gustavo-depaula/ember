# Questão 79

***Em seguida, pergunta-se sobre as potências intelectivas. Sobre isso perguntam-se treze coisas.***

Primeiro, se o intelecto é potência da alma ou a sua essência.

- Segundo, se é potência, se é potência passiva.
- Terceiro, se é potência passiva, se se deve pôr algum intelecto agente.
- Quarto, se é algo da alma.
- Quinto, se o intelecto agente é um só para todos.
- Sexto, se a memória está no intelecto.
- Sétimo, se é potência distinta do intelecto.
- Oitavo, se a razão é potência distinta do intelecto.
- Nono, se a razão superior e a inferior são potências diversas.
- Décimo, se a inteligência é outra potência além do intelecto.
- Undécimo, se o intelecto especulativo e o prático são potências diversas.
- Duodécimo, se a sindérese é alguma potência da parte intelectiva.
- Décimo terceiro, se a consciência é alguma potência da parte intelectiva.

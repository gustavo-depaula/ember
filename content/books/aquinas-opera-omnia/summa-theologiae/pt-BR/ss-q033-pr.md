# Questão 33

***Em seguida, deve-se considerar a correção fraterna. E acerca disso perguntam-se oito coisas.***

Primeiro, se a correção fraterna é ato da caridade.

- Segundo, se é de preceito.
- Terceiro, se este preceito se estende a todos, ou somente aos prelados.
- Quarto, se os súditos estão obrigados por este preceito a corrigir os prelados.
- Quinto, se o pecador pode corrigir.
- Sexto, se se deve corrigir quem se torna pior com a correção.
- Sétimo, se a correção secreta deve preceder a denúncia.
- Oitavo, se a apresentação de testemunhas deve preceder a denúncia.

# Artigo 2

***Se o conselho é somente das coisas que são para o fim, ou também do fim***

Quanto ao segundo, assim se procede. Parece que o conselho não é somente das coisas que são para o fim, mas também do fim. Com efeito, pode-se investigar sobre tudo o que admite dúvida. Mas, acerca das coisas humanas operáveis, acontece haver dúvida sobre o fim, e não só sobre as coisas que são para o fim. Como, portanto, a investigação acerca das coisas operáveis é o conselho, parece que o conselho pode ser do fim.

Além disso, a matéria do conselho são as operações humanas. Mas algumas operações humanas são fins, como se diz no livro I da *Ética*. Logo, o conselho pode ser do fim.

Mas, em sentido contrário, está o que diz Gregório de Nissa: que *o conselho não é do fim, mas das coisas que são para o fim*.

Respondo dizendo que o fim, nas coisas operáveis, tem noção de princípio, porque as razões das coisas que são para o fim tomam-se do fim. Ora, o princípio não cai sob questão, mas é preciso supor os princípios em toda investigação. Por isso, sendo o conselho uma questão, não há conselho sobre o fim, mas somente sobre as coisas que são para o fim. Contudo, acontece que aquilo que é fim em relação a algumas coisas se ordene a outro fim, assim como também aquilo que é princípio de uma demonstração é conclusão de outra. E por isso aquilo que se toma como fim numa investigação pode ser tomado como algo que é para o fim em outra investigação. E assim haverá conselho sobre ele.

Quanto ao primeiro, portanto, deve-se dizer que aquilo que se toma como fim já está determinado. Por isso, enquanto é tido como duvidoso, não é tido como fim. E por isso, se há conselho sobre ele, não será conselho sobre o fim, mas sobre aquilo que é para o fim.

Quanto ao segundo, deve-se dizer que há conselho sobre as operações enquanto se ordenam a algum fim. Por isso, se alguma operação humana é fim, não há conselho sobre ela, enquanto tal.

# Questão 60

***Em seguida, deve-se considerar o juízo. E acerca disso perguntam-se seis coisas.***

Primeiro, se o juízo é ato da justiça.

- Segundo, se é lícito julgar.
- Terceiro, se se deve julgar por suspeitas.
- Quarto, se as coisas duvidosas devem ser interpretadas no melhor sentido.
- Quinto, se o juízo deve ser sempre proferido segundo as leis escritas.
- Sexto, se o juízo é pervertido pela usurpação.

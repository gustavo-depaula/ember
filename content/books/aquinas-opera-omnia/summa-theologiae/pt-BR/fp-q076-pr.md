# Questão 76

Em seguida, deve-se considerar a união da alma com o corpo. E acerca disso perguntam-se oito coisas.

Primeiro, se o princípio intelectivo se une ao corpo como forma.

- Segundo, se o princípio intelectivo se multiplica numericamente conforme a multiplicação dos corpos, ou se há um só intelecto de todos os homens.
- Terceiro, se no corpo cuja forma é o princípio intelectivo há alguma outra alma.
- Quarto, se há nele alguma outra forma substancial.
- Quinto, como deve ser o corpo de que o princípio intelectivo é forma.
- Sexto, se se une a tal corpo mediante algum outro corpo.
- Sétimo, se mediante algum acidente.
- Oitavo, se a alma está toda em qualquer parte do corpo.

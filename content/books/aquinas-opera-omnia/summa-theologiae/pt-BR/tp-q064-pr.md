# Questão 64

Em seguida, devem-se considerar as causas dos sacramentos, seja por autoridade, seja por ministério. Sobre isso, investigam-se dez pontos.

Primeiro, se somente Deus opera interiormente nos sacramentos.

- Segundo, se a instituição dos sacramentos provém somente de Deus.
- Terceiro, sobre o poder que Cristo teve nos sacramentos.
- Quarto, se ele poderia ter comunicado esse poder a outros.
- Quinto, se o poder de ministrar os sacramentos compete aos maus.
- Sexto, se os maus pecam ao administrar os sacramentos.
- Sétimo, se os anjos podem ser ministros dos sacramentos.
- Oitavo, se a intenção do ministro é exigida nos sacramentos.
- Nono, se neles se exige a fé reta, de modo que um infiel não possa conferir um sacramento.
- Décimo, se neles se exige a intenção reta.

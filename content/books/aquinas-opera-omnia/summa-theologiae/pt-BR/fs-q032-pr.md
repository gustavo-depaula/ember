# Questão 32

***Em seguida, devem-se considerar as causas do deleite. E acerca disto perguntam-se oito coisas.***

Primeiro, se a operação é a causa própria do deleite.

- Segundo, se o movimento é causa do deleite.
- Terceiro, se o são a esperança e a memória.
- Quarto, se o é a tristeza.
- Quinto, se as ações dos outros são para nós causa de deleite.
- Sexto, se fazer bem a outro é causa de deleite.
- Sétimo, se a semelhança é causa de deleite.
- Oitavo, se a admiração é causa de deleite.

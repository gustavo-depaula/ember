# Questão 16

***Em seguida, deve-se considerar o uso. E acerca disso se perguntam quatro coisas.***

Primeiro, se usar é ato da vontade.

- Segundo, se convém aos animais brutos.
- Terceiro, se é somente das coisas que são para o fim, ou também do fim.
- Quarto, sobre a ordem do uso em relação à eleição.

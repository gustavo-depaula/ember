# Questão 68

Em seguida, devem-se considerar aqueles que recebem o Batismo. A esse respeito, investigam-se doze pontos.

Primeiro, se todos têm o dever de receber o Batismo.

- Segundo, se alguém pode ser salvo sem o Batismo.
- Terceiro, se o Batismo deve ser adiado.
- Quarto, se os pecadores devem ser batizados.
- Quinto, se devem ser impostas obras satisfatórias aos pecadores batizados.
- Sexto, se se requer a confissão dos pecados.
- Sétimo, se se requer intenção da parte de quem é batizado.
- Oitavo, se se requer fé.
- Nono, se as crianças devem ser batizadas.
- Décimo, se os filhos dos judeus devem ser batizados contra a vontade dos pais.
- Décimo primeiro, se devem ser batizados aqueles que se encontram no útero materno.
- Décimo segundo, se os furiosos e os privados de razão devem ser batizados.

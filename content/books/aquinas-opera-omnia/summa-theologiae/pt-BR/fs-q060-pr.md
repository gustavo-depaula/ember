# Questão 60

Em seguida, deve-se considerar a distinção das virtudes morais entre si. E acerca disso perguntam-se cinco coisas.

Primeiro, se há uma só virtude moral.

- Segundo, se as virtudes morais que versam sobre as operações se distinguem das que versam sobre as paixões.
- Terceiro, se há uma só virtude moral acerca das operações.
- Quarto, se acerca das diversas paixões há diversas virtudes morais.
- Quinto, se as virtudes morais se distinguem segundo os diversos objetos das paixões.

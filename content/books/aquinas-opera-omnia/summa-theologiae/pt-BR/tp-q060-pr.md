# Questão 60

***O que é o sacramento***

Depois de considerar o que pertence aos mistérios do Verbo encarnado, devem-se considerar os sacramentos da Igreja, que recebem sua eficácia do próprio Verbo encarnado. Primeiro, trataremos dos sacramentos em geral; depois, de cada um dos sacramentos em particular.

Quanto ao primeiro ponto, devem-se considerar cinco coisas: primeiro, o que é o sacramento; segundo, a necessidade dos sacramentos; terceiro, seus efeitos; quarto, sua causa; quinto, seu número.

A respeito do primeiro ponto, investigam-se oito questões.

Primeiro, se o sacramento pertence ao gênero dos sinais.

- Segundo, se todo sinal de uma coisa sagrada é sacramento.
- Terceiro, se o sacramento é sinal de uma só coisa ou de várias.
- Quarto, se o sacramento é um sinal que consiste numa coisa sensível.
- Quinto, se para o sacramento se requer uma coisa sensível determinada.
- Sexto, se para o sacramento se requer a significação por palavras.
- Sétimo, se se requerem palavras determinadas.
- Oitavo, se algo pode ser acrescentado a essas palavras ou retirado delas.

# Questão 187

Em seguida, deve-se considerar o que compete aos religiosos. E acerca disto perguntam-se seis coisas.

Primeiro, se lhes é lícito ensinar, pregar e fazer outras coisas semelhantes.

- Segundo, se lhes é lícito intrometer-se em negócios seculares.
- Terceiro, se estão obrigados a trabalhar com as mãos.
- Quarto, se lhes é lícito viver de esmolas.
- Quinto, se lhes é lícito mendigar.
- Sexto, se lhes é lícito usar vestes mais grosseiras que os demais.

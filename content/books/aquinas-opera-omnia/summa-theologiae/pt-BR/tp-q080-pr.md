# Questão 80

Em seguida, deve-se considerar o uso ou a recepção deste sacramento. Primeiro, em geral; segundo, como Cristo usou este sacramento.

A respeito do primeiro ponto, investigam-se doze questões.

Primeiro, se há dois modos de comer este sacramento, a saber, sacramentalmente e espiritualmente.

- Segundo, se comer espiritualmente convém apenas ao homem.
- Terceiro, se comer sacramentalmente é próprio apenas do homem justo.
- Quarto, se o pecador peca ao comer sacramentalmente.
- Quinto, sobre a gravidade desse pecado.
- Sexto, se deve ser afastado o pecador que se aproxima deste sacramento.
- Sétimo, se a polução noturna impede o homem de receber este sacramento.
- Oitavo, se ele deve ser recebido somente por quem está em jejum.
- Nono, se deve ser dado aos que não têm o uso da razão.
- Décimo, se deve ser recebido diariamente.
- Undécimo, se é lícito abster-se inteiramente dele.
- Duodécimo, se é lícito receber o corpo sem o sangue.

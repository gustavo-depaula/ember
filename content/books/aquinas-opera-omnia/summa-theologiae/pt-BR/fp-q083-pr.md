# Questão 83

***Em seguida, investiga-se o livre-arbítrio. E acerca disso investigam-se quatro coisas.***

Primeiro, se o homem tem livre-arbítrio.

- Segundo, o que é o livre-arbítrio: se é potência, ato ou hábito.
- Terceiro, se é potência, se é apetitiva ou cognitiva.
- Quarto, se é apetitiva, se é a mesma potência que a vontade, ou outra.

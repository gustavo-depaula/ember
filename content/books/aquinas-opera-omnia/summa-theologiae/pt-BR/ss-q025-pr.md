# Questão 25

Em seguida, deve-se considerar o objeto da caridade. A esse respeito ocorrem duas coisas a considerar: primeiro, o que se deve amar por caridade; segundo, a ordem do que se deve amar. Sobre o primeiro, perguntam-se doze coisas.

Primeiro, se só Deus deve ser amado por caridade, ou também o próximo.

- Segundo, se a caridade deve ser amada por caridade.
- Terceiro, se as criaturas irracionais devem ser amadas por caridade.
- Quarto, se alguém pode amar-se a si mesmo por caridade.
- Quinto, se o próprio corpo.
- Sexto, se os pecadores devem ser amados por caridade.
- Sétimo, se os pecadores se amam a si mesmos.
- Oitavo, se os inimigos devem ser amados por caridade.
- Nono, se se lhes devem mostrar sinais de amizade.
- Décimo, se os anjos devem ser amados por caridade.
- Undécimo, se os demônios.
- Duodécimo, da enumeração do que se deve amar por caridade.

# Artigo 8

***Se este nome “Deus” é nome de natureza***

Quanto ao oitavo, procede-se assim. Parece que este nome “Deus” não é nome de natureza. Pois o Damasceno diz, no livro I, que *“Deus” se diz de theein*[^1], que é correr *(*currere.—curare* PABCDEG*b*.)* e acalentar todas as coisas; *ou de aethein, isto é, arder (pois o nosso Deus é um fogo que consome toda malícia* *(*omnem malitiam. -* Om. P*ab*.)*); *ou de theasthai*, que é considerar todas as coisas. Ora, tudo isso pertence à operação. Logo, este nome “Deus” significa operação, e não natureza *(*naturam.—divinam* acrescentam ABD.)*.

[^1]: *Nota do tradutor:* O Damasceno relaciona o grego *Theós* (“Deus”) com *théein* (“correr”), *aíthein* (“arder”) e *theâsthai* (“contemplar”), etimologias por semelhança de som, correntes entre os antigos, que o português não pode reproduzir.

Além disso, algo é nomeado por nós segundo é conhecido. Ora, a natureza divina nos é desconhecida. Logo, este nome “Deus” não significa a natureza divina.

Em sentido contrário, há o que diz Ambrósio, no livro I de *Sobre a fé*: que “Deus” é nome de natureza.

Respondo dizendo que nem sempre é o mesmo aquilo a partir do qual se impõe o nome para significar e aquilo que o nome é imposto para significar. Pois, assim como conhecemos a substância de uma coisa a partir das suas propriedades ou operações, assim às vezes denominamos a substância de uma coisa a partir de alguma operação ou propriedade sua; assim como denominamos a substância da pedra a partir de alguma ação sua, porque fere o pé; mas este nome não foi imposto para significar essa ação, e sim a substância da pedra. Já as coisas que nos são conhecidas em si mesmas, como o calor, o frio, a brancura e semelhantes, não são denominadas a partir de outras. Por isso, em tais coisas, é o mesmo o que o nome significa e aquilo a partir do qual se impõe o nome para significar *(*a quo... significandum.—ad quod nomen significandum (significandum nomen* CEsA*) imponitur* ABCDE.)*.

Portanto, como Deus não nos é conhecido na sua natureza, mas se nos dá a conhecer a partir das suas operações ou efeitos, a partir destes podemos nomeá-lo, como foi dito acima. Por isso este nome “Deus” é nome de operação, quanto àquilo a partir do qual é imposto para significar. Pois este nome é imposto a partir da providência universal sobre as coisas; com efeito, todos os que falam de Deus pretendem chamar “Deus” *(*hoc intendunt nominare Deum.—hoc intelligunt nominare Deum* BCDEG*ab*.)* àquele que tem providência universal sobre as coisas. Por isso Dionísio diz, no cap. XII de *Sobre os nomes divinos*, que *a deidade é aquela que vê todas as coisas com providência e bondade perfeita*. E este nome “Deus”, tomado dessa operação, foi imposto para significar a natureza divina.

Quanto ao primeiro, portanto, deve-se dizer que todas *(*omnia.—illa* acrescentam CDEFG. *-* Em vez de *posuit, ponit* ABCDE.—Depois de *significandum* B acrescenta *divinam essentiam*.)* as coisas que o Damasceno apresentou pertencem à providência, a partir da qual se impõe este nome “Deus” para significar.

Quanto ao segundo, deve-se dizer que, na medida em que podemos conhecer a natureza de alguma coisa a partir das suas propriedades e efeitos, nessa medida podemos significá-la pelo nome. Por isso, como podemos conhecer a substância da pedra a partir da sua propriedade segundo ela mesma, sabendo o que é a pedra, este nome “pedra” significa a própria natureza da pedra tal como é em si; pois significa a definição da pedra, pela qual sabemos o que é a pedra. Com efeito, a razão que o nome significa é a definição, como se diz no livro IV da *Metafísica*.

Mas a partir dos efeitos divinos não podemos conhecer a natureza divina tal como é em si, de modo a saber dela o que é, mas por modo de eminência, de causalidade e de negação, como foi dito acima. E assim este nome “Deus” significa a natureza divina. Pois este nome foi imposto para significar algo que existe acima de todas as coisas, que é princípio de todas as coisas e está separado de todas. Pois é isso que pretendem significar os que nomeiam a Deus.

# Questão 136

***Em seguida, deve-se considerar a paciência. E sobre isso perguntam-se cinco coisas.***

Primeiro, se a paciência é virtude.

- Segundo, se é a maior das virtudes.
- Terceiro, se pode ser tida sem a graça.
- Quarto, se é parte da fortaleza.
- Quinto, se é o mesmo que a longanimidade.

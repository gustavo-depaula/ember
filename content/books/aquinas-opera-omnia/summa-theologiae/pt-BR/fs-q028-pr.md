# Questão 28

***Em seguida, devem-se considerar os efeitos do amor. E acerca disso indagam-se seis coisas.***

Primeiro, se a união é efeito do amor.

- Segundo, se o é a mútua inerência.
- Terceiro, se o êxtase é efeito do amor.
- Quarto, se o é o zelo.
- Quinto, se o amor é uma paixão lesiva do amante.
- Sexto, se o amor é causa de tudo o que o amante faz.

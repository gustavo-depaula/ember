# Questão 58

***Em seguida, deve-se considerar a justiça. Acerca dela perguntam-se doze coisas.***

Primeiro, o que é a justiça.

- Segundo, se a justiça é sempre para com outro.
- Terceiro, se é virtude.
- Quarto, se está na vontade como em seu sujeito.
- Quinto, se é virtude geral.
- Sexto, se, enquanto é geral, é a mesma em essência que toda virtude.
- Sétimo, se há alguma justiça particular.
- Oitavo, se a justiça particular tem matéria própria.
- Nono, se versa sobre as paixões ou só sobre as operações.
- Décimo, se o meio da justiça é o meio real.
- Undécimo, se o ato da justiça é dar a cada um o que é seu.
- Duodécimo, se a justiça é a principal entre as outras virtudes morais.

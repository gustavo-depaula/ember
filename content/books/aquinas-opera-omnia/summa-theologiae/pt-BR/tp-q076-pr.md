# Questão 76

Em seguida, deve-se considerar o modo pelo qual Cristo existe neste sacramento. A esse respeito, investigam-se oito pontos.

Primeiro, se Cristo inteiro está sob este sacramento.

- Segundo, se Cristo inteiro está sob cada uma das espécies do sacramento.
- Terceiro, se Cristo inteiro está sob qualquer parte das espécies.
- Quarto, se todas as dimensões do corpo de Cristo estão neste sacramento.
- Quinto, se o corpo de Cristo está neste sacramento localmente.
- Sexto, se o corpo de Cristo se move com o movimento da hóstia ou do cálice depois da consagração.
- Sétimo, se o corpo de Cristo sob este sacramento pode ser visto por algum olho.
- Oitavo, se o verdadeiro corpo de Cristo permanece neste sacramento quando aparece milagrosamente sob a espécie de uma criança ou de carne.

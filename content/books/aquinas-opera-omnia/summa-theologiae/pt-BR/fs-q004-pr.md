# Questão 4

Em seguida, deve-se considerar o que se requer para a bem-aventurança. E sobre isso perguntam-se oito coisas.

Primeiro, se o deleite se requer para a bem-aventurança.

- Segundo, o que tem primazia na bem-aventurança: o deleite ou a visão.
- Terceiro, se se requer a compreensão.
- Quarto, se se requer a retidão da vontade.
- Quinto, se o corpo se requer para a bem-aventurança do homem.
- Sexto, se a perfeição do corpo.
- Sétimo, se alguns bens exteriores.
- Oitavo, se se requer a companhia dos amigos.

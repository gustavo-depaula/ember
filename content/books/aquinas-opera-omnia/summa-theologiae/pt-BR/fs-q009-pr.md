# Questão 9

***Em seguida, deve-se considerar aquilo que move a vontade. E sobre isso perguntam-se seis coisas.***

Primeiro, se a vontade é movida pelo intelecto.

- Segundo, se é movida pelo apetite sensitivo.
- Terceiro, se a vontade move a si mesma.
- Quarto, se é movida por algum princípio exterior.
- Quinto, se é movida pelo corpo celeste.
- Sexto, se a vontade é movida somente por Deus, como por princípio exterior.

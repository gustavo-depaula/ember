# Questão 82

Em seguida, deve-se considerar o ministro deste sacramento. A esse respeito, investigam-se dez pontos.

Primeiro, se consagrar este sacramento é próprio do sacerdote.

- Segundo, se vários sacerdotes poderiam consagrar simultaneamente a mesma hóstia.
- Terceiro, se a distribuição deste sacramento pertence somente ao sacerdote.
- Quarto, se é lícito ao sacerdote que consagra abster-se da comunhão.
- Quinto, se é lícito ao sacerdote abster-se inteiramente da celebração.
- Sexto, se um sacerdote pecador pode realizar este sacramento.
- Sétimo, se a Missa de um mau sacerdote tem menos valor que a de um bom.
- Oitavo, se os hereges, os cismáticos ou os excomungados podem realizar este sacramento.
- Nono, se os degradados podem fazê-lo.
- Décimo, se pecam os que recebem a comunhão de tais pessoas.

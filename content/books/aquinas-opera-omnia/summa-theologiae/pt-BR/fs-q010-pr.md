# Questão 10

Em seguida, deve-se considerar o modo como a vontade é movida. E sobre isso perguntam-se quatro coisas.

Primeiro, se a vontade é movida naturalmente para algo.

- Segundo, se é movida necessariamente pelo seu objeto.
- Terceiro, se é movida necessariamente pelo apetite inferior.
- Quarto, se é movida necessariamente pelo motor exterior que é Deus.

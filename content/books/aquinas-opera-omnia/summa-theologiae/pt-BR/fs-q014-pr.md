# Questão 14

***Em seguida, deve-se considerar o conselho. E acerca disso se perguntam seis coisas.***

Primeiro, se o conselho é uma investigação.

- Segundo, se o conselho é do fim, ou somente das coisas que são para o fim.
- Terceiro, se o conselho é somente das coisas que são feitas por nós.
- Quarto, se o conselho é de todas as coisas que são feitas por nós.
- Quinto, se o conselho procede em ordem resolutiva.
- Sexto, se o conselho procede ao infinito.

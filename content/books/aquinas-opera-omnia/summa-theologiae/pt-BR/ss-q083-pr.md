# Questão 83

***Em seguida, cumpre considerar a oração. E acerca disto perguntam-se dezessete coisas.***

Primeiro, se a oração é ato da potência apetitiva ou da cognitiva.

- Segundo, se é conveniente orar.
- Terceiro, se a oração é ato da religião.
- Quarto, se só a Deus se deve orar.
- Quinto, se na oração se deve pedir algo determinado.
- Sexto, se, orando, devemos pedir bens temporais.
- Sétimo, se devemos orar pelos outros.
- Oitavo, se devemos orar pelos inimigos.
- Nono, sobre as sete petições da oração dominical.
- Décimo, se orar é próprio da criatura racional.
- Undécimo, se os santos na pátria oram por nós.
- Duodécimo, se a oração deve ser vocal.
- Décimo terceiro, se a atenção é requerida para a oração.
- Décimo quarto, se a oração deve ser prolongada.
- Décimo quinto, se a oração é eficaz para impetrar o que se pede.
- Décimo sexto, se é meritória.
- Décimo sétimo, sobre as espécies de oração.

# Questão 107

***Em seguida, deve-se considerar a ingratidão. E a respeito disso perguntam-se quatro coisas.***

Primeiro, se a ingratidão é sempre pecado.

- Segundo, se a ingratidão é pecado especial.
- Terceiro, se toda ingratidão é pecado mortal.
- Quarto, se se devem subtrair os benefícios ao ingrato.

# Questão 91

***Em seguida, deve-se considerar a diversidade das leis. E acerca disto se perguntam seis coisas.***

Primeiro, se existe alguma lei eterna.

- Segundo, se existe alguma lei natural.
- Terceiro, se existe alguma lei humana.
- Quarto, se existe alguma lei divina.
- Quinto, se é uma só ou várias.
- Sexto, se existe alguma lei do pecado.

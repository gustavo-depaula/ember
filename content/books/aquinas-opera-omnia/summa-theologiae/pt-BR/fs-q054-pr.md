# Questão 54

Em seguida, deve-se considerar a distinção dos hábitos. E acerca disso indagam-se quatro coisas.

Primeiro, se pode haver muitos hábitos numa só potência.

- Segundo, se os hábitos se distinguem segundo os objetos.
- Terceiro, se os hábitos se distinguem segundo o bem e o mal.
- Quarto, se um só hábito se constitui de muitos hábitos.

# Questão 89

Em seguida, devem-se considerar os atos exteriores de latria pelos quais os homens tomam para si algo divino, que é ou algum sacramento ou o próprio nome divino. Mas da recepção do sacramento haverá lugar para tratar na terceira parte desta obra. Agora se deve tratar do ato de tomar o nome divino. O nome divino é tomado pelo homem de três modos: de um modo, à maneira de juramento, para confirmar as próprias palavras; de outro modo, à maneira de adjuração, para induzir os outros; de um terceiro modo, à maneira de invocação, para orar ou louvar. Primeiro, pois, deve-se tratar do juramento. Acerca dele perguntam-se dez coisas.

Primeiro, o que é o juramento.

- Segundo, se é lícito.
- Terceiro, quais são os companheiros do juramento.
- Quarto, de que virtude é ato.
- Quinto, se deve ser desejado e frequentado, como útil e bom.
- Sexto, se é lícito jurar pela criatura.
- Sétimo, se o juramento é obrigatório.
- Oitavo, qual é a obrigação maior, a do juramento ou a do voto.
- Nono, se é possível dispensar do juramento.
- Décimo, a quem e quando é lícito jurar.

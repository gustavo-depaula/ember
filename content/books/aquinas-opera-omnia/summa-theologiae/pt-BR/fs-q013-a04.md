# Artigo 4

***Se a eleição é somente em relação aos atos humanos***

Quanto ao quarto, assim se procede. Parece que a eleição não é somente em relação aos atos humanos. Com efeito, a eleição é das coisas que são para o fim. Mas as coisas que são para o fim não são só atos, mas também instrumentos, como se diz no livro II da *Física*. Logo, as eleições não são só dos atos humanos.

Além disso, a ação distingue-se da contemplação. Mas a eleição tem lugar também na contemplação, a saber, enquanto se prefere uma opinião a outra. Logo, a eleição não é só dos atos humanos.

Além disso, os homens são eleitos para alguns ofícios, seculares ou eclesiásticos, por aqueles que nada fazem em relação a eles. Logo, a eleição não é só dos atos humanos.

Mas, em sentido contrário, está o que diz o Filósofo, no livro III da *Ética*: que *ninguém elege senão aquilo que julga ser feito por ele*.

Respondo dizendo que, assim como a intenção é do fim, assim a eleição é das coisas que são para o fim. Ora, o fim ou é uma ação ou alguma coisa. E, quando alguma coisa for o fim, é necessário que intervenha alguma ação humana: ou enquanto o homem faz essa coisa que é o fim, como o médico faz a saúde, que é o seu fim (por isso também se diz que fazer a saúde é o fim do médico); ou enquanto o homem de algum modo usa ou frui da coisa que é o fim, como para o avarento o fim é o dinheiro, ou a posse do dinheiro. E do mesmo modo se deve dizer daquilo que é para o fim. Porque é necessário que aquilo que é para o fim seja ou uma ação, ou alguma coisa com a intervenção de alguma ação, pela qual se faz aquilo que é para o fim ou se usa dele. E deste modo a eleição é sempre dos atos humanos.

Quanto ao primeiro, portanto, deve-se dizer que os instrumentos se ordenam ao fim enquanto o homem os usa por causa do fim.

Quanto ao segundo, deve-se dizer que na própria contemplação há algum ato do intelecto que assente a esta ou àquela opinião. Mas é a ação exterior que se divide em oposição à contemplação.

Quanto ao terceiro, deve-se dizer que o homem que elege o bispo ou o príncipe da cidade elege nomeá-lo para tal dignidade. Do contrário, se não houvesse nenhuma ação sua para a constituição do bispo ou do príncipe, não lhe competiria a eleição. E de modo semelhante se deve dizer que, sempre que se diz que uma coisa é preferida a outra, junta-se ali alguma operação de quem elege.

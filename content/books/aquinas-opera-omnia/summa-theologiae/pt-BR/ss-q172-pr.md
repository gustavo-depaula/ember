# Questão 172

***Em seguida, deve-se considerar a causa da profecia. E acerca disto perguntam-se seis coisas.***

Primeiro, se a profecia é natural.

- Segundo, se vem de Deus por meio dos anjos.
- Terceiro, se para a profecia se requer uma disposição natural.
- Quarto, se se requer a bondade dos costumes.
- Quinto, se há alguma profecia que venha dos demônios.
- Sexto, se os profetas dos demônios às vezes dizem a verdade.

# Questão 98

***Em seguida, deve-se considerar o perjúrio. E acerca disso perguntam-se quatro coisas.***

Primeiro, se a falsidade é requerida para o perjúrio.

- Segundo, se o perjúrio é sempre pecado.
- Terceiro, se é sempre pecado mortal.
- Quarto, se peca aquele que impõe juramento a um perjuro.

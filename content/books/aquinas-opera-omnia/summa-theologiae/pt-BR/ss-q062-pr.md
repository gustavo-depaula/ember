# Questão 62

***Em seguida, deve-se tratar da restituição. E acerca disso perguntam-se oito coisas.***

Primeiro, de que é ato.

- Segundo, se é necessário para a salvação restituir tudo o que foi tirado.
- Terceiro, se é preciso restituí-lo multiplicado.
- Quarto, se é preciso restituir o que alguém não tomou.
- Quinto, se é preciso restituir àquele de quem se tomou.
- Sexto, se é preciso que restitua aquele que tomou.
- Sétimo, se algum outro.
- Oitavo, se se deve restituir imediatamente.

# Questão 102

Em seguida, deve-se considerar o lugar do homem, que é o Paraíso. E sobre isso perguntam-se quatro coisas.

Primeiro, se o Paraíso é um lugar corpóreo.

- Segundo, se é um lugar conveniente para a habitação humana.
- Terceiro, para que o homem foi posto no Paraíso.
- Quarto, se devia ser feito no Paraíso.

# Questão 185

Em seguida, deve-se considerar o que pertence ao estado dos bispos. E acerca disto perguntam-se oito coisas.

Primeiro, se é lícito desejar o episcopado.

- Segundo, se é lícito recusar definitivamente o episcopado.
- Terceiro, se é preciso escolher para o episcopado o melhor.
- Quarto, se o bispo pode passar à vida religiosa.
- Quinto, se lhe é lícito abandonar corporalmente os seus súditos.
- Sexto, se pode ter bens próprios.
- Sétimo, se peca mortalmente não distribuindo aos pobres os bens eclesiásticos.
- Oitavo, se os religiosos que são assumidos ao episcopado estão obrigados às observâncias regulares.

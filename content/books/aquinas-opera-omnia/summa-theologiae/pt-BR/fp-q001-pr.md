# Questão 1

***Sobre a doutrina sagrada: qual é e a que se estende***

E, para que o nosso propósito se contenha dentro de certos limites, é necessário investigar primeiro a própria doutrina sagrada: qual é e a que se estende.

Acerca disso *(*Circa quae.—Circa quod* FG.)* perguntam-se dez coisas.

Primeiro, sobre a necessidade desta doutrina.

- Segundo, se é ciência.
- Terceiro, se é uma só ou várias.
- Quarto, se é especulativa ou prática.
- Quinto, sobre a sua comparação com as outras ciências.
- Sexto, se é sabedoria.
- Sétimo, qual é o seu sujeito.
- Oitavo, se é argumentativa.
- Nono, se deve usar expressões metafóricas ou simbólicas.
- Décimo, se a Sagrada Escritura desta doutrina *(*huius doctrinae*.—Om. B.—*sit* om. pB, depois de *utrum* põem ACE FGpD*a*, antes de *exponenda* sBD.)* deve ser exposta segundo vários sentidos.

# Capítulo 9

***Que Deus é simples***

Daí se vê também que o primeiro motor deve ser simples. Com efeito, em toda composição é preciso que haja duas coisas que se relacionem entre si como a potência e o ato. Ora, no primeiro motor, se é absolutamente imóvel, é impossível haver potência junto com ato, pois cada coisa é móvel por estar em potência. Logo, é impossível que o primeiro motor seja composto.

Ademais, a todo composto é necessariamente anterior alguma coisa, pois os componentes são naturalmente anteriores ao composto. Logo, aquilo que é o primeiro de todos os entes não pode ser composto. Vemos também, na ordem dos seres, que os simples estão acima dos compostos. Os elementos são naturalmente anteriores aos corpos mistos. Entre os próprios elementos, o primeiro é o fogo, que é o mais sutil. E anterior a todos os elementos é o corpo celeste, que está constituído em maior simplicidade, por estar isento de toda contrariedade. Resta, pois, que o primeiro dos entes deve ser absolutamente simples.

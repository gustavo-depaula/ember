# Prólogo

***Sobre a ciência de Deus***

***Primeiro, se a ciência convém a Deus.***

- Segundo, se sabe a si mesmo.
- Terceiro, se sabe as coisas distintas de si.
- Quarto, se tem conhecimento certo e determinado das coisas.
- Quinto, se conhece os singulares.
- Sexto, se o intelecto humano conhece os singulares.
- Sétimo, se Deus conhece que os singulares são ou não são agora.
- Oitavo, se Deus conhece os não entes.
- Nono, se Deus sabe coisas infinitas.
- Décimo, se Deus pode fazer coisas infinitas.
- Undécimo, se a ciência se diz equivocamente de Deus e de nós.
- Duodécimo, se Deus sabe os futuros contingentes.
- Décimo terceiro, se a ciência de Deus é variável.
- Décimo quarto, se a ciência de Deus é causa das coisas.
- Décimo quinto, se Deus sabe os males.

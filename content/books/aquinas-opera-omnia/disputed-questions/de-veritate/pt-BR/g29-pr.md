# Prólogo

***Sobre a graça de Cristo***

***E, primeiro, pergunta-se se em Cristo há graça criada.***

- Segundo, se para que a natureza humana fosse unida ao Verbo na pessoa se requer a graça habitual.
- Terceiro, se a graça de Cristo é infinita.
- Quarto, se a graça capital convém a Cristo segundo a natureza humana.
- Quinto, se em Cristo se requer alguma graça habitual para que seja cabeça.
- Sexto, se Cristo pôde merecer.
- Sétimo, se Cristo pôde merecer para os outros.
- Oitavo, se Cristo pôde merecer no primeiro instante de sua concepção.

# Prólogo

***Sobre a profecia***

***Primeiro, se a profecia é hábito ou ato.***

- Segundo, se a profecia versa sobre conclusões cognoscíveis.
- Terceiro, se a profecia é natural.
- Quarto, se para ter a profecia se requer uma disposição natural.
- Quinto, se para a profecia se requer a bondade dos costumes.
- Sexto, se os profetas veem no espelho da eternidade.
- Sétimo, se na revelação profética se imprimem por Deus na mente do profeta novas espécies das coisas ou só o lume intelectual.
- Oitavo, se toda revelação profética se dá por mediação de um anjo.
- Nono, se o profeta, sempre que é tocado pelo espírito de profecia, fica alienado dos sentidos.
- Décimo, se a profecia se divide convenientemente em profecia de predestinação, de presciência e de cominação.
- Undécimo, se na profecia se encontra verdade imutável.
- Duodécimo, se a profecia segundo a só visão intelectual é mais eminente que aquela que tem a visão intelectual juntamente com a visão imaginária.
- Décimo terceiro, se os graus de profecia se distinguem segundo a visão imaginária.
- Décimo quarto, se Moisés foi mais excelente que os outros profetas.

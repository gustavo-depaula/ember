# Artigo 61

O que se põe em sexagésimo primeiro lugar, quando se diz: *o Pai diz todas as coisas no Verbo, não se chama o Verbo princípio de dizer, mas termo*, deve entender-se da parte de quem diz; pois o Verbo não é para o Pai princípio pelo qual diga; mas é dito pelo Pai como princípio das outras coisas que são ditas por este Verbo: e assim cessa toda objeção.
